## 摘要
键值（KV）缓存是长上下文大语言模型（LLM）解码中的主要内存瓶颈：每一步都要完整读取它，因此解码受内存带宽限制。将量化的KV缓存保存在密集的片上非易失性存储器（NVM）中可以消除片外传输。然而，现有的KV量化方法是为GPU风格的内存系统设计的：KIVI附加每组元数据，使存储的KV缓存增加约25%；KVQuant保留了密集阵列无法原位容纳的稀疏全精度离群值。本文考察了当KV缓存驻留在固定范围转换器后面的NVM中时这些结构带来的代价，并设计了一种与该接口匹配的量化方案。该架构将量化后的KV缓存存储在密集的片上NVM中，仅使用一个小型静态模拟交叉开关用于固定旋转，并将注意力计算保留在片上数字逻辑中。随机旋转和每向量归一化使每个坐标具有相同的范围，因此一个用于键的固定码本和一个用于值的固定码本（每个码本在所有对应张量类型的标记之间共享）即可服务于整个KV缓存。码本阈值一次性编程为读取转换器的参考电平，从而实现固定范围数字化，无需逐token转换器重新配置。反量化是一个16项查找和一次范数乘法；唯一的每向量元数据是一个标量，约占3%。在从3B到14B的模型以及长达32k token的上下文中，四位KV缓存在存储和交叉开关噪声（在真实设备级别模拟）下保持准确性。KIVI和KVQuant在软件中仍然更准确；我们的格式的优势在于内存接口：映射到相同NVM时，KV读取能量比两者低3.1-3.6倍，元数据开销比KIVI低8倍。贡献在于与NVM内存接口协同设计的KV量化，而非创造新的准确性记录。

## Abstract
The key-value (KV) cache is the dominant memory bottleneck in long-context large language model (LLM) decoding: every step reads it entirely, so decoding is memory-bandwidth bound. Holding a quantized KV cache in dense on-chip non-volatile memory (NVM) removes the off-chip transfer. Existing KV quantization methods, however, were designed for GPU-style memory systems: KIVI attaches per-group metadata, adding about 25% to the stored KV cache; KVQuant keeps sparse full-precision outliers that a dense array cannot hold in place. This paper examines what these structures cost when the KV cache resides in NVM behind fixed-range converters, and designs a quantization scheme matched to that interface. The architecture stores the quantized KV cache in dense on-chip NVM, uses a small static analog crossbar only for the fixed rotation, and keeps attention in on-chip digital logic. A randomized rotation and per-vector normalization give every coordinate the same range, so one fixed codebook for keys and one for values, each shared across all tokens of the corresponding tensor type, serve the entire KV cache. The codebook thresholds are programmed once as the read converter's reference levels, enabling fixed-range digitization with no per-token converter reconfiguration. Dequantization is a sixteen-entry lookup and one norm multiply; the only per-vector metadata is one scalar, about 3%. Across models from 3B to 14B and contexts to 32k tokens, the four-bit KV cache maintains accuracy under storage and crossbar noise simulated at realistic device levels. KIVI and KVQuant remain more accurate in software; the advantage of our format lies at the memory interface: 3.1-3.6x lower KV read energy than both mapped to the same NVM, and 8x lower metadata overhead than KIVI. The contribution is a KV quantization co-designed with the NVM memory interface rather than a new accuracy record.

## 1. 论文的核心问题与整体含义（研究背景）

- **背景问题**：长上下文 LLM 自回归解码中，每一步都必须完整读取不断增长的 KV 缓存。注意力计算与序列长度线性相关，KV cache 主导内存流量，使解码被内存带宽束缚，而非算术吞吐。
- **已有方案**：将 KV 缓存量化（2–4 bit）减少存储和搬运，代表工作有 KIVI和 KVQuant。
- **核心矛盾**：NVM（如 RRAM）可高密度集成片上、省去片外传输（RRAM 比 SRAM 密度高约 23×），但**已有 KV 量化格式针对 GPU 内存层级设计，无法直接低成本适配固定输入范围的 NVM 数组接口**，存在结构不匹配：
  - KIVI 为每组（32维）附带全精度 scale/zero-point，元数据膨胀约 25%（等效每坐标额外一 bit），每组读时需额外 fetch + MAC。
  - KVQuant 保留稀疏全精度离群值，密集 NVM 数组无法原位容纳不规则结构，需要额外存储与每步 gather。
- **研究重要性**：这是首个意识到“NVM 存储 KV cache + 固定范围转换器”接口约束，并围绕该接口进行量化和数据路径协同设计的软硬件工作，解决方向是 LLM 基础设施走向能效型片上推理的关键环节。

## 2. 方法论：面向 NVM 接口的 KV 量化

**核心思想**：不在数值精度上追求超越——而是通过“变换-归一化-共享码本”的方式，把量化格式与存储接口在结构上匹配起来，实现密集均匀存储、固定转换阈值、最小元数据与低成本重建。

**关键技术步骤**（结合图2数据路径）：

1. **随机 Hadamard 旋转**（写/读路径）：
   - 对每个原始向量 $\mathbf{x}\in\mathbb{R}^{d}$（d为头维度，Llama为128），通过随机Hadamard矩阵 $\mathbf{H}$ 应用旋转，均匀分散能量、抑制离群坐标。
   - Hadamard 近似 $\pm1/\sqrt{d}$ 项，无需乘法器，快 $O(d \log d)$。
   - 将此旋转放在 RoPE 嵌入**之后**——因同用 H 则得分中自然抵消（$(\mathbf{H}\ \mathrm{RoPE}(\mathbf{q}))^T(\mathbf{H}\ \mathrm{RoPE}(\mathbf{k})) = \mathrm{RoPE}(\mathbf{q})^T\mathrm{RoPE}(\mathbf{k})$），读写无需逐 key 逆旋转，注意力就在旋转空间完成；输出投影离线吸收逆旋转（$W'_O = W_O \mathbf{H}^T$，类 QuaRot)。

2. **每向量归一化**：
   - $\tilde{\mathbf{x}} = \mathbf{H}\mathbf{x}/r$，$r=\lVert\mathbf{H}\mathbf{x}\rVert$
   - 使每个向量位于同一个单位球上，保证所有坐标的分布接近一致；保存向量标量范数 $r$，作为唯一每向量元数据。
   - 在固定码本上按坐标标量量化。注：键坐标在有噪声的情况下近高斯（超峰态 ≈ −0.16，KL ≈ 5×10⁻⁴）——基于关键分布 $p(x) \propto (1-x^2)^{(d-3)/2}$ 的自适应分布可解析导出 Lloyd-Max 码本，因此关键码本是“数据无关”的。

3. **键/值共享码本的混合设计**：
   - 单个键码本和单个值码本，各自跨所有 token、层、头所共享。
   - 键码本是解析推导的、无校准数据。
   - 值坐标具有更重的尾部（超峰态 ≈ 2.25，KL ≈ 1.3×10⁻²），因此用一次离线小集合（64段，每段最多512个token）拟合，与模型特定值分布匹配。
   - 阈值就是 Lloyd-Max 条件：$t_i=(c_i+c_{i+1})/2$，$c_i = \frac{\int t_{i-1}^{t_i} x\,p(x)\,dx}{\int t_{i-1}^{t_i} p(x)\,dx}$。

4. **固定范围读取转换器并持久化NVM**：
   - 码本阈值一次性编程为上读转换器的参考电平（读出比较器），无需跨 token 重新配置。
   - 只有写一次、固定宽度的 b-bit 索引进入密集 NVM；向量范数存储在小型数字 SRAM（开销约3.1%，占索引 bits 的约3.1%）。
   - 解码：恢复一个索引，16 项查表和一次标量乘（$\hat{\mathbf{x}} = r[c_{i_1},\ldots,c_{i_d}]^T$）。

5. **硬件映射**：
   - 旋转静态交叉开关（写入一次，只读；差分对表示 $\pm$，每次常数，具有二进制连接模式），注意点计算保持在片上数字逻辑并数字化。
   - 模型特有的注意偏差处理（如 Qwen2.5）：在量化和反量化中减去/加回每次投影偏差（存储的常量是 $H\beta$，离线计算）。

## 6. 主要结论与发现

- 针对 GPU 优化的 KIVI/KVQuant 结构（per-group 元数据，稀疏异常）一旦被移植到密集支持 NVM 的存储中，会转化为实质性开销（KIVI 增加的量化存储约 25%，KVQuant 在约 7.1% 辅助存储 + 指数基数稀疏单元被内联去除至……即被迫密集），从而将读取路径成本从 0.10 pJ（本文）提升到 0.37 pJ（KIVI 3.64×）和 0.31–1 pJ（KVQuant 3.11×）。

写验证到约3%的RRAM噪声时，14B/8B 模型仍能维持绝大多数任务上的准确率，3B 模型掉落更明显；这表明固定码本方案在存储非理想性面前具有一定鲁棒性，但小模型的噪声容忍度仍是后续优化重点。

- **总体判断**：本文的核心贡献并不在于提升量化精度，而在于**将 NVM 存储器接口约束纳入量化格式设计的第一性原则**；在 4-bit 等宽下，其精度弱于 KIVI/KVQuant，但其读取能量、元数据开销、面积收益显著。作者对这一“以精度换硬件适配”的取舍表述较为坦诚，未做超出实验证据的宣称。

## 7. 局限性与未解决问题

1. **精度上限受限**：论文承认其固定码本、共享码本方案在 RULER 等长上下文检索任务中明显落后于 KIVI（例如 3B 模型约低 8 个百分点），这意味着若下游任务对检索精度高度敏感，当前方案仍需配合其他补偿手段（如更高位宽、混合精度、或稀疏异常缓冲）才能作为 GPU/NVM 通用替代。

2. **值码本依赖模型校准数据**：虽然键码本是解析推导、数据无关的，但值码本仍依赖 64 段×512 token 的离线校准；该过程虽然轻量，但在任务分布漂移或持续推理场景下，码本与在线数据分布失配的风险未被实验覆盖。

3. **小模型鲁棒性不足**：3B 模型在 RRAM 噪声 3% 附近即出现明显精度退化，说明噪声容忍度与模型冗余度相关。论文未提供如何针对小模型增强鲁棒性的方法（如更细粒度的码本、误差补偿编码、或重复写后校验）。

4. **NVM 写入次数与良率问题**：虽然论文给出单次 KV 写的能量估计，但并未讨论 RRAM 耐久性在长周期 KV 写场景下的劣化效应，也未讨论交叉开关阵列中电导漂移对固定阈值参考电平的时序影响。

5. **硬件评估依赖模拟而非流片**：能量/面积数据基于 NeuroSim 22nm 建模，而非实测芯片，因此只能作为趋势估计。旋转交叉开关的静态固定电导模式能否在真实工艺下保持高精度，仍需原型验证。

6. **扩展性瓶颈未完全解决**：32k 上下文下，14B 模型的总面积估算约为 428mm²，超出单芯片合理预算；论文只是提出了多芯片模块与 3D 堆叠的方向，没有给出具体架构划分方案或通信开销分析。

## 8. 个人评价与启示

- **优点**：
  - 问题定义清晰：将量化算法与存储介质接口的“结构性匹配”作为核心矛盾，跳出了纯精度优化框架；
  - 方法论闭环：从旋转、归一化、码本设计到读取转换器映射，每一步都围绕 NVM 接口约束展开，逻辑严谨；
  - 实验设计较全面：既比较了等宽下的精度，又对比了包含元数据的有效容量情形，消融实验能清楚区分键/值码本设计的贡献；
  - 硬件噪声扫描和端到端面积/能耗估计增加了结果可信度。

- **不足**：
  - 对“为什么选择 Lloyd-Max + 共享码本”的理论优势阐述较少，部分推导停留在描述性层面；
  - 精度落后的部分缺乏更精细的分析（例如，是在长距离依赖还是短距离检索上丢失更多）；
  - 与 KIVI 的比较在有效容量对齐时仍没有完全消除实现不匹配（例如，KIVI 元数据在 NVM 中若需固定阈值量化，其元数据本身也有量化代价），该点论文没有充分展开。

- **启示**：在面向非易失性存储的 LLM 推理设计中，与其尽可能紧凑地逼近原 KV 分布，不如彻底重构 KV 的数据表示，使其在压缩性与存储介质操作模式上同时对齐。该思路也可能推广至其他 NVM 系列（如 FeFET、PCM）或其他内存计算架构。此外，共享码本、解析最优阈值的组合使其具备迁移到其他变换域量化的潜力——不同头/层共享的码本设计本质上将校准需求压缩到单模型级，这种“元数据趋零”的哲学对极低比特 KV cache 的未来设计具有借鉴意义。

## 总结

这项工作首次系统回答了“如何为 NVM 设计 KV 量化格式”这一问题。它没有尝试在纯软件精度上与最先进 GPU 侧量化方案竞争，而是提出了旋转、归一化、共享码本这一组操作，将 KV cache 变成纯 b-bit 索引流与一个范数标量，从而在存储密度、读取能量与噪声稳健性上取得结构性优势。尽管其精度并非最优，且硬件实现仍在仿真层面，但其“接口优先”的软硬件协同设计思路，为能效型长上下文推理硬件提供了清晰且有潜力的方向。
