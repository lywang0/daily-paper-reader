## 摘要
大型语言模型（LLMs）取得了显著进展，但其巨大的存储和内存带宽需求仍然阻碍了高效部署。权重量化是一种有前景的解决方案，但现有的基于量化的训练后量化（PTQ）方法通常由于隐藏开销而远超标称的1比特存储目标。为解决这一差距，我们提出了All for 1-Bit（AF1），一个用于LLMs的真正1比特PTQ框架。AF1包含两个互补组件：（1）零空间感知二元分解（NABF），通过Hessian感知的替代重参数化、零空间感知的二元分解和仅缩放全局重构来改进二元重构；（2）层次Shapley分配（HiSA），使用层次Shapley敏感性来分配结构容量。两者共同在PTQ设置下严格的1.0-BPW预算内保持模型准确性。在LLaMA、Qwen和Gemma系列上的实验表明，AF1在困惑度和零样本准确率上持续优于现有的基于量化的PTQ方法。与BF16相比，AF1在评估模型上实现了平均2.5倍的推理加速和超过90%的内存减少，为LLMs的可部署真正1比特压缩提供了实用路径。可复现性代码见https://github.com/Kishon-zzx/AF1。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

## 1. 核心问题与整体含义（研究动机和背景）

- 大型语言模型（LLM）规模不断扩大，例如 LLaMA-3.1-405B 已达到 405B 参数，Qwen3.5-397B-A17B 总参数达 397B，在 BF16/FP16 精度下仅模型权重就需约 800GB 存储，带来严重的内存和带宽瓶颈。
- 训练后量化（PTQ）是降低 LLM 部署成本的重要途径，其中权重量化因理论上可实现单比特存储和比特级计算而极具吸引力。
- 现有基于二值化的 PTQ 方法（如 BiLLM、ARB-LLM、HBLLM）虽然标称"1-bit"，但会引入大量辅助元数据（缩放因子、分组参数、离群值索引、掩码、稀疏索引等），导致端到端有效 BPW（bits per weight）实际达到 2–4 bit，并未真正实现 1-bit 存储。
- 量化感知训练（QAT）方法（如 OneBit）虽能生成真正 1-bit 表示，但依赖大规模训练数据、长优化周期和巨大算力，难以大规模部署。
- 因此，论文的核心问题是：**在 PTQ 设置下，能否在不引入沉重元数据、不需要昂贵重训练的前提下，实现真正 1.0 effective-BPW 的 LLM 压缩？**
- 论文指出两个关键障碍：
  1. 单一二值矩阵（W ≈ αB）的表达能力有限，难以捕捉 LLM 权重中复杂的幅度分布和结构相关性，PTQ 又缺乏大规模数据驱动优化来补偿这种能力不足；
  2. LLM 不同层和子模块对二值化误差的敏感性高度异质，均匀量化或固定结构预算无法匹配这种非均匀分布，导致容量分配次优。

## 2. 方法论

论文提出 **AF1（All for 1-Bit）** 框架，由两个互补模块组成：

### 2.1 NABF（零空间感知二元分解，Null-space-Aware Binary Factorization）

NABF 用于提升二值重构精度，包含三个步骤：

**（1）Hessian 感知替代重参数化**
- 基于 K-FAC 近似的对角 Hessian 估计，利用输入激活和输出梯度构造输入重要性向量 i 和输出重要性向量 o：

  \( i_j = \sqrt{E[x_j^2]}, \quad o_u = \sqrt{E[g_u^2]} \)

- 将原始权重矩阵重新参数化为 \( W' = o \odot W \odot i^\top \)，使 Hessian 加权重构问题转化为替代空间中的 Frobenius 目标，从而强调任务敏感通道。

**（2）零空间感知二元 ADMM 分解**
- 将替代权重分解为两个二进制符号矩阵和连续缩放向量的乘积：

  \( W' \approx (a \odot A_{\pm1} \odot m_1^\top)(m_2 \odot B_{\pm1} \odot b^\top) \)

- 这种"双因子"结构表达能力显著高于单二值矩阵，举例说明：即使 r=2，双因子形式也能表达非秩一幅度结构，而单因子二值受限矩阵的幅度只能是秩一的。
- 迭代优化采用 ADMM 框架：固定一个因子时更新另一个因子，连续代理解通过 SVID 投影回二值缩放域。SVID 投影会产生离散残差：
  - 左因子：\( E_A = \hat{A} - A_q \)
- NABF 的核心创新在于对投影残差进行**零空间补偿**：
  - 实际扰动是 \(E_A B\) 而非 \(E_A\) 本身；若 \(E_A\) 位于固定因子 B 的近似左零空间，则 \(E_A B \approx 0\)，误差在向前传播中得以消除；
  - 通过 \(C_B = BB^\top\) 的零特征子空间构造投影器 \(P_B = \tilde{U}\tilde{U}^\top\)，满足 \(P_B B \approx 0\)；
  - 使用自适应残差能量截止比（η=0.01）选取近似零空间基；
  - 定义补偿目标 \( A_{\text{target}} = \hat{A} - E_A P_B \)，它保持了连续代理的传播行为；
  - 通过最小二乘闭合解求解列向缩放向量 \( \gamma^* = \frac{\text{diag}(A_q^\top A_{\text{target}})}{\text{diag}(A_q^\top A_q)} \)，将补偿吸收到已有中间缩放向量 \(m_1 \leftarrow m_1 \odot \gamma^*\) 中；
  - 该操作不改变二值符号矩阵，也不增加任何推理时额外参数，保持 1-bit 参数化。

**（3）仅缩放全局重构**
- 冻结所有二值符号矩阵后，只优化连续缩放参数 \(S = \{a^{(l)}, m^{(l)}, b^{(l)}\}\)。
- 以全精度模型为教师，最小化 KL 散度：

  \( \min_S E_{X \sim D_{cal}} [D_{KL}(\text{softmax}(z_T(X)) \| \text{softmax}(z_Q(X; S)))] \)

- 每层可训练参数从 \(O(d_{out}r + rd_{in})\) 降到 \(O(d_{out} + r + d_{in})\)。

### 2.2 HiSA（层次 Shapley 分配，Hierarchical Shapley Allocation）

HiSA 用于在严格存储预算下进行全局结构容量分配，包含两个层级：

**层级别粗粒度分配（渐进式 Shapley）**
- 将层视为博弈参与者，价值函数为校准集上端到端 token 级 NLL 退化量 \(v_{NLL}(S)\)。
- 随机采样 M 个层排列，从全容量状态逐步将层退化为代理维度，记录每层被退化时 NLL 的增加量作为边际贡献，最终取平均得到层 Shapley 分数 \(\Phi_l\)。
- 通过温度控制 softmax 将 Shapley 分数转换为层预算：

  \( B_l = B_{total} \frac{\exp(\Phi_l / \tau)}{\sum_{j=1}^L \exp(\Phi_j / \tau)} \)

- 关键优势：Shapley 值通过多种不同压缩状态的边际贡献均值，捕捉跨层交互和误差传播效应。

**模块级别细粒度分配（双敏感度 Shapley）**
- 在每层内部，将所有候选子模块（如 QKV/输出投影、Gate/Up/Down）视为参与者，通过逐步退化测量层输出扰动。
- 使用两种互补失真度量（附录 A.2.7 提供了详细的数学推导）：
  - **方向失真 \(r_{dir}\)**：令牌表征之间的余弦偏差，反映注意力模式变化；
  - **幅度失真 \(r_{mag}\)**：相对激活能量偏移，反映残差流和归一化的扰动。
- 采用单调累积误差 \(\hat{E}_c(S_t) = \max(E_c(S_t), \hat{E}_c(S_{t-1}))\) 来减少误差相互抵消造成的负边际贡献。
- 两种 Shapley 分数经 MAD（中位数绝对偏差）鲁棒 Z-score 归一化后，通过 Sigmoid 映射到 (0,1)，再用 Soft-OR 规则融合：

  \( v_{base} = 1 - (1 - P_{dir})(1 - P_{mag}) \)

- 最终按"尺寸感知敏感密度"分配模块预算（公式 19），使用平滑指数 α 在"大模块主导"和"噪声敏感"之间折衷。

- **效率收益显著**：相对 BF16，AF1 平均约 90% 内存缩减、约 2.5× 解码吞吐提升；相对 GPTQ-W4 约 68% 内存缩减。
- **量化时间接近 PTQ、精度接近 QAT**：AF1 在 LLaMA-2-7B 上 1.0 BPW 达到 11.20 PPL，仅需 5.9 GPU 小时，比 LittleBit/OneBit 快约 40×/228×，而 PPL 差距仅约 1–3 个点。
- **校准需求低**：128 条序列已足够；C4 校准实验显示对样本数量（32–512）和随机种子不敏感。
