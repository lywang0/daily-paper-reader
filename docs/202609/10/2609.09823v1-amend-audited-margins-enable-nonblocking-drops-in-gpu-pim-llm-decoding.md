## 摘要
自回归大语言模型（LLM）解码在每一步都会重新读取不断增长的键值（KV）缓存，因此长上下文注意力受限于图形处理器（GPU）内存带宽。块稀疏注意力会跳过低贡献的 KV 块，但若选择器在当前查询-键（QK）乘积之后才做决定，例如最大相对块阈值法（BLASST），则仍会读取每个 K 块；而根据当前查询做决定的存内处理（PIM）过滤器会将一个串行 PIM 阶段置于关键路径上。我们提出 AMEND，一种 GPU-PIM 注意力设计，消除了这两种依赖。AMEND 根据在较早步骤审计的裕度预测每个块的 BLASST 判定，因此 GPU 仅获取预测存活的块，而高带宽内存（HBM）中的近存储体 PIM 单元同时为被省略的其余块评分。一个栈级控制器合并这两种观测结果，更新预测器，并提前生成下一步的掩码，从而在不阻塞当前 token 的情况下重新观测每个预测丢弃的块。工作点通过受约束的贝叶斯优化在误丢弃预算下离线选取。在 LongBench 和 RULER 运行中，AMEND 保持了接近基线的任务质量；在批大小为 8 的仿真中，在 8K-64K 上下文下，相比稠密注意力，它实现了 1.40–3.63 倍的端到端解码加速，动态解码能耗降低 28–66%。

## Abstract
Autoregressive large language model (LLM) decoding re-reads a growing key-value (KV) cache at every step, so long-context attention is bound by graphics processing unit (GPU) memory bandwidth. Block-sparse attention skips low-contribution KV blocks, but a selector that decides after the current query-key (QK) product, such as max-relative block thresholding (BLASST), still reads every K block, and a processing-in-memory (PIM) filter that decides from the current query places a serial PIM stage on the critical path. We present AMEND, a GPU-PIM attention design that removes both dependencies. AMEND predicts each block's BLASST verdict from margins audited at earlier steps, so the GPU fetches only predicted survivors while near-bank PIM units in high-bandwidth memory (HBM) concurrently score the omitted complement. A stack-level controller merges both observations, updates the predictor, and eagerly generates the next step's mask, so every predicted drop is re-observed without blocking the current token. Operating points are selected offline by constrained Bayesian optimization under a false-drop budget. Across LongBench and RULER runs, AMEND preserves near-baseline task quality; in simulation at batch size 8, it achieves $1.40$-$3.63\times$ end-to-end decode speedup and 28-66% lower dynamic decode energy than dense attention across 8K-64K contexts.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景瓶颈**：自回归 LLM 解码每步只处理一个 token，却要重新读取随序列增长的 KV 缓存，因此长上下文解码注意力是典型的 GPU 显存带宽受限问题。
- **现有块稀疏注意力的两类缺陷**：
  - **后置选择器（如 BLASST）**：在完成当前查询-键（QK）乘积后才依据块最大值与排他前缀最大值的比较做判定，虽然能跳过 softmax、V 读取与 PV，但**已经读入了全部 K 块**。论文量化指出，在 90% 块稀疏度下 K 仍占剩余 K+V 逻辑流量的约 91%。
  - **当前查询 PIM 过滤器**：把评分搬到近存单元，能在 GPU 取 K 前形成掩码，但掩码仍依赖当前查询，等于把一段**串行 PIM 阶段**放进 query→scores→mask→attention 的关键路径，无法利用 GPU–PIM 双引擎并行。
- **核心洞察**：相邻解码步的查询与上下文变化是增量的，注意力重要区域具有持续性（Scissorhands 等的观测）。论文测得 **89.2% 的合格 BLASST 判定在下一步保持不变**，且判定背后的连续裕度（margin）本身携带可预测信号。
- **整体含义**：AMEND 主张把"掩码生成"从当前步解耦——用**先前步骤审计过的裕度**预测当前步的 BLASST 判定，使 GPU 只取回预测存活块，同时让 PIM 并行审计被省略的补集，从而同时消除"全 K 读取"和"串行 PIM 阶段"两个依赖。

## 2. 方法论

### 2.1 核心思想：预测—审计—提前生成
- **因果预测**：仅使用截至第 t−1 步的观测状态，预测第 t 步每个 (层, KV头, 块) 单元的 BLASST 判定（DROP/KEEP）。
- **补集审计**：被预测丢弃的块在 GPU 路径上不再被观测，会形成"选择性标签"观测空洞；因此用 GPU 与 PIM 两条通道对**全部预测丢弃单元**重建 BLASST 证据。
- **提前生成下一步掩码（eager next-mask）**：审计结果折叠进预测器状态，用于生成第 t+1 步掩码，而非修复当前 token 的输出——即"当前输出永不等待当前审计"。

### 2.2 关键定义与判定参考
- 块最大值 $m^\star_{t,\ell,h,b}$，排他前缀最大值 $p^\star$，上下文偏移 $\eta_t=\log(\text{TSF}/S_t)$。
- GQA 归约后的选择裕度：$\gamma^\star_{t,\ell,g,b}=\max_{h\in G(g)}(m^\star - p^\star - \eta_t)$；$\gamma^\star<0$ 则 DROP。块 0 强制保留。

### 2.3 五步执行循环（Algorithm 1）
1. **Predict（控制器）**：用状态 $S^-_t$ 预测，形成逐 KV 头掩码 $P^{keep}_t$、物理并集 $U_t$、补集 $A_t$。
2. **GPU 注意力**：只读并集 K 块，算存活 QK 与块最大值，用 survivor BLASST 收紧 V/PV 保留集（K 读取集不变），完成 softmax 与 PV 得 $O_t$。
3. **补集 QK（PIM，与 2 并发）**：对全局被省略块算 QK，仅返回块最大值。
4. **重建（控制器）**：按块序合并 GPU/PIM 最大值，做排他前缀与 GQA 归约，得到 $A_t$ 上每个单元的全缓存裕度与判定。
5. **折叠（控制器）**：把两通道观测写入 $S^-_{t+1}$，供第 t+1 步生成掩码。

### 2.4 预测器设计（读侧）
- 每单元状态：裕度 EMA $\mu$、二阶矩 $M_2$、丢弃游程年龄 $a$、2-bit 计数器 $c$；波动率 $\sigma=\sqrt{\max(M_2-\mu^2,0)}$。
- 五维工作点 $\theta=(r,\delta,\alpha,R,z)$：年龄下限 $r$、截距 $\delta$、EMA 权重 $\alpha$、近端窗口 $R$、波动惩罚 $z$。
- 基础条件（式 1）：$u_t=\mathbb{1}[a\ge r]\cdot\mathbb{1}[\mu+z\sigma<-\delta]\cdot\mathbb{1}[\text{base eligible}]$；用 $q=\mu+\delta$ 与 $q^2>z^2v$ 避免开方。
- **2-bit Schmitt 计数器**抑制孤立翻转：$c^+=\text{clip}(c^-+(2u_t-1),0,3)$，仅在 $c^+=3$ 时输出丢弃。
- 硬保留（seam rules）：块 0、最后一块、部分尾块、$R$ 块近端窗口。

### 2.5 补集审计与状态更新（写侧）
- 观测集合划分：$O^{online,full}_t \cup A_t = F^{full}_t$（式 4），保证预测丢弃全部被覆盖。
- 两条观测通道：survivor BLASST 得 $\gamma^P$、物理 GPU 路径得 $\gamma^U$，且 $p^P\le p^U\le p^\star$，$\gamma^P\ge\gamma^U\ge\gamma^\star$（式 6），故 survivor BLASST 不引入额外误丢弃。
- 折叠值（式 7）：保留单元折 $\gamma^U$，预测丢弃单元折 $\gamma^\star$。
- EMA 更新（式 8）：$\mu^+=\alpha x+(1-\alpha)\mu^-$，$M_2^+=\alpha x^2+(1-\alpha)M_2^-$。

### 2.6 工作点离线选择
- 把校准建模为**混合变量黑箱约束优化**：目标最大化丢弃召回 $Q_N(\theta)$，约束误丢弃率 $F_{drop,N}(\theta)\le\tau$。
- 采用 **SCBO（Scalable Constrained Bayesian Optimization）**：GP 拟合、约束 Thompson 采样、局部信任域迭代，预算耗尽则冻结最优可行点；若无可行点则报告失败而非放松约束。

## 6. 主要结论与发现

- **质量保持**：LongBench 上 AMEND 平均分与 Dense/BLASST 相差在 0.12 分内，比 Quest 高 0.82（Llama）/0.10（Qwen）；RULER 上每设置与 BLASST 相差 ≤0.91 分，平均高 Quest 6.47 分。
- **效率提升**：批大小 8、8K–64K 上下文下，端到端解码加速 **1.40–3.63×**，动态解码能耗比 Dense 低 **28–66%**（归一化能耗从 0.72 降到 0.34）。
- **注意力路径加速**：最高达 **11.27×**（32K），显著优于 Quest-PIM 的 ≤7.05× 与 BLASST-PIM 的 ≤5.95×；原因是 AMEND 的 PIM 补集 QK 完全并发、不进入关键路径（表 6 中 AMEND 串行 PIM 阶段为 0.0 μs/token）。
- **K/V 稀疏性**：BLASST 的 GPU 侧 K 读取为 0% 稀疏，而 AMEND 实现 63–88% 的 K 字节节省（被省略的 K 由 PIM 扫描），V 节省 76–94%。
- **审计有效性**：审计折叠将滚动误丢弃率从 0.087 降至 0.028（降低 68%），打破观测空洞导致的自强化误差循环。
- **边界条件**：误丢弃目标超过约 $5\times10^{-2}$ 后 RULER 质量急剧下降（$8\times10^{-2}$ 时降至 0.335）；批大小 $N=64$ 后暴露审计停顿显现，$N=128$ 时 AMEND 与 Quest-PIM 接近持平（5.86× vs 5.89×），若隐藏停顿可达 7.18×。

## 7. 优点

- **问题定位精准**：明确指出后 QK 选择器"跳过 PV 但逃不掉 K 读取"的 K 流量缺口，并量化（K 占剩余流量约 91%），动机清晰有力。
- **依赖关系重构巧妙**：把掩码生成从当前步解耦（用历史审计裕度预测），实现"当前输出不等待当前审计"，同时保留 PIM 并行计算被省略 QK 的完整工作守恒（$QK_{surv}+QK_{omit}=QK_{full}$）。
- **理论严谨**：给出式 (6) 的裕度序关系证明 survivor BLASST 不会引入额外误丢弃；用式 (4) 形式化观测集合划分以消除选择性标签问题。
- **工程可落地性**：用 2-bit Schmitt 计数器抑制抖动、用 $q^2>z^2v$ 避免开方、控制器仅做比较/前缀归约/状态更新而无指数与 softmax 数据通路，资源预算以 AttAcc 的 1.38 mm² 软max 单元为参照。
- **校准方法合理**：将五旋钮交互的跨 token 递推视为混合变量黑箱约束问题，用 SCBO 在误丢弃预算下离线选点，并与随机搜索做了种子配对比较。
