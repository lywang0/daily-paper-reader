## 摘要
前沿语言模型正更积极地采用次二次注意力，以降低推理过程中的内存占用和计算需求，同时仍保持前沿精度。尽管现有系统围绕稠密注意力做出以注意力为中心的解聚式服务决策，我们表明，围绕次二次注意力 LLM 特有的算术强度和内存占用对推理进行解聚，可在新兴的基于 DRAM 和仅 SRAM 的异构系统上显著提升吞吐量和能效。我们提出 SQD（SubQuadratic Disaggregation，次二次解聚），一种细粒度异构解聚方案，它按二次注意力和次二次注意力而非按算子类型来划分解码，并且适用于各种次二次注意力变体。对于稀疏注意力 LLM，我们将解码解聚为 top-k 选择（必须索引完整 KV）以及 top-k 注意力加 FFN（具有静态内存占用）。对于线性注意力和滑动窗口注意力 LLM，我们将解码解聚为稠密注意力层，以及次二次注意力层加 FFN。在调整后的 8xB200 异构系统代理中，相对于最强的纯 GPU 基线，我们观察到平均 tokens/J 在 GLM 5.2 上提升 53%，在 Nemotron 3 Ultra 上提升 31%，在 Gemma 4 31B 上提升 56%。在固定功耗预算的 Rubin 加 LPX 系统分析模型中，相对于注意力-FFN 解聚的最佳基线，我们观察到可实现延迟收紧 1.2 倍至 1.5 倍，吞吐量最高提升 3.6 倍。我们的实验还揭示了面向服务次二次注意力的下一代异构系统在芯片与互连资源供给方面的架构洞见。

## Abstract
Frontier language models are more aggressively using subquadratic attention to reduce the memory footprint and compute requirements during inference while still delivering frontier accuracy. While existing systems make dense attention-centric disaggregated serving decisions, we show that disaggregating inference around the unique arithmetic intensity and memory footprint of subquadratic attention LLMs can achieve significant throughput and energy efficiency gains on emerging DRAM-based and SRAM-only heterogeneous systems.   We introduce SQD (SubQuadratic Disaggregation), a fine-grained heterogeneous disaggregation scheme that splits decode by quadratic and subquadratic attention rather than by operator type, and that applies across subquadratic attention variants. For sparse attention LLMs, we disaggregate decode into top-k selection, which must index through the full KV, and top-k attention plus FFN, which have static memory footprints. For linear and sliding-window attention LLMs, we disaggregate decode into dense attention layers and subquadratic attention layers plus FFN. In an adjusted 8xB200 heterogeneous system proxy, we observe average tokens/J improvements of 53% on GLM 5.2, 31% on Nemotron 3 Ultra, and 56% on Gemma 4 31B over the strongest GPU-only baselines. In an analytical model of a Rubin plus LPX system with fixed power budgets, we observe 1.2x to 1.5x tighter achievable latencies and up to 3.6x higher throughput over the best baseline of attention-FFN disaggregation. Our experiments also reveal architectural insights on chip and interconnect provisioning for next-generation heterogeneous systems serving subquadratic attention.

- **整体意义**：将模型架构趋势（次二次注意力占多数层）与系统解聚策略做协同设计，从而在低延迟区间同时获得更低延迟与更便宜的 token。

## 2. 方法论：SQD（SubQuadratic Disaggregation）

### 2.1 核心思想

- 将 LLM 推理分解为四个阶段：**Prefill**、**二次注意力**（KV cache 随上下文增长，如稠密注意力、top-k 索引器扫描）、**次二次注意力**（每步固定状态，如 top-k 稀疏注意力、线性循环、滑动窗口）、**FFN/MoE**（静态占用）。
- **按"二次 vs 次二次"而非按算子类型划分解码**：二次注意力与 prefill 共置于 DRAM GPU（共享 KV cache），次二次注意力与 FFN 迁移到 SRAM-only ASIC。

### 2.2 关键设计细节（分模型家族）

- **稀疏注意力（GLM-5.2）**：在注意力算子内部切分——必须扫描完整 MLA latent KV 的 **top-k 选择（indexer）留在 GPU**；**top-k 注意力 + FFN 放到 ASIC**。
- **线性/滑动窗口注意力（Nemotron 3 Ultra、Gemma4）**：按层切分——**全注意力层留 GPU**，其余层连同 FFN 一起搬到 ASIC。
- **Prefill 与二次解码注意力共置**：两者分别偏计算受限与内存受限，争用不同资源，可提高系统利用率；单步代价约为 `max(t_decode, t_prefill) + 暴露通信`，prefill 以 2048-token chunk 运行，与解码交错而非阻塞。

### 2.3 Top-k 稀疏注意力缓存机制

- **问题**：稀疏注意力选中的集合在请求到达前未知，ASIC 若持有 top-k 注意力则每步都要读全 KV；batch 32 时单层选中集合达 75.5 MB，通信会成为关键路径。
- **观察（Insight 3）**：跨 4 条 agentic trace（AgentTrove Math、τ2-bench Retail、SWE-bench Pro under Codex、TerminalBench）发现选中位置集中在少数上下文带内，且跨多个连续解码步持续；GLM-5.2 的 **IndexShare 每 4 层重算一次选择**，后续 3 层共享同一索引。
- **机制**：**IndexShare 跨组预取 + 经验秩频（ERF）淘汰**。组头（offset 1）无 slack，其注意力留在 ASIC 上并以近全驻留的 cache 兜底；offset 2–4 用前序层的执行时间隐藏通信。
- **时延预算公式（文字化）**：
  - 偏移 `j` 的预算 `budget_j = (j−1)·t_layer`；可用窗口 `slack_j = budget_j − L0`；
  - 所需命中率 `h_j ≥ 1 − slack_j·W/(B·k·e)`；
  - 实测常数：`L0 = 7 μs`（2 μs 链路跳 + 5 μs kernel dispatch），抓取带宽 `W = 141 GB/s`，单条目 `e = 1152 bytes`（MLA 512 维 latent + 64 维 RoPE，bf16）；

### 2.4 通信实现

- **单边 put + doorbell**：发送方用 copy engine 写入对端注册缓冲区，然后同流 kernel 做 system-scope fence 并写递增序号，接收方本地自旋——避免双边 send 的 rendezvous skew（实测匹配 ping-pong ~50 μs，但真实服务中约 0.8 ms/次）。
- 用**异步 post/wait 对**包裹本地计算以重叠传输；以**固定契约的 graph capture**消除 launch/调度间隙。
