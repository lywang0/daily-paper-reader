## 摘要
视觉语言模型（VLM）在边缘设备上的部署受到内存带宽的严重瓶颈，因而亟需激进的亚8比特量化。由于边缘加速器受面积和功耗的严格约束，它们需要端到端量化的模型。然而，多模态令牌之间极大的动态范围差距使标准块格式遭遇“微缩放坍缩”：单个巨大的离群值劫持共享指数，使周围元素下溢，并破坏注意力图。为打破这一瓶颈，我们提出 Micro-Inverted-Scaling（MiX），一种在数学上反转微缩放范式的新型格式：它不再将多个尾数归组于一个共享指数之下，而是将私有的逐元素指数归组于单个共享尾数之下。为处理VLM中非对称的离群值拓扑，我们引入自适应双格式（MiX-MX）推理框架。通过代数分解出共享的MiX尾数，该框架可映射到定制加速器，用高效的移位器替代乘法器。在多个VLM上进行端到端评估，我们的4.5比特MiX格式在多模态基准上相比NVFP4表现出相当或更优的准确率。同时，与NVFP4基线相比，MiX加速器将面积效率提升25%；与最先进的加速器Focus相比，在多个模型上实现2.3-4.5倍加速和1.4-2.9倍能耗降低，证明反转缩放数据通路在物理上更适合高效VLM部署。

## Abstract
The deployment of Vision-Language Models (VLMs) on edge devices is severely bottlenecked by memory bandwidth, necessitating aggressive sub-8-bit quantization. Since edge accelerators are strictly constrained by area and power, they require end-to-end quantized models. However, the extreme dynamic range gap between multi-modal tokens causes standard block formats to suffer "microscaling collapse," where a single massive outlier hijacks the shared exponent, underflowing surrounding elements and destroying attention maps. To break this bottleneck, we propose Micro-Inverted-Scaling (MiX), a novel format that mathematically inverts the microscaling paradigm: rather than grouping multiple mantissas under one shared exponent, MiX groups private, per-element exponents under a single shared mantissa. To handle asymmetric VLM outlier topologies, we introduce an adaptive dual-format (MiX-MX) inference framework. By algebraically factoring out the shared MiX mantissa, this framework maps to a custom accelerator, replacing multipliers with efficient shifters. Evaluated end-to-end on multiple VLMs, our 4.5-bit MiX formulation exhibits equivalent or superior accuracy on multi-modal benchmarks compared to NVFP4. Simultaneously, the MiX accelerator delivers a 25% improvement in area efficiency over the NVFP4 baseline and a 2.3-4.5x speedup with 1.4-2.9x energy reduction across models compared to the state-of-the-art accelerator Focus, proving the inverted-scaling datapath is physically superior for efficient VLM deployment.

## 一、核心问题与研究动机

### 研究背景
- **边缘部署瓶颈**：视觉语言模型（VLM）在边缘设备上的部署严重受限于内存带宽。自回归解码阶段，内存流量由两个复合瓶颈主导：持续读取海量模型权重，以及由数万高分辨率视觉 token 驱动的 KV Cache 爆炸式增长。
- **端到端量化需求**：边缘加速器受面积和功耗严格约束，要求模型端到端全量化。而当前主流的权重仅量化（如 W4A16）无法压缩视觉 KV Cache 和动态激活，且在微架构层面迫使 PE 使用昂贵的混合精度乘法器或动态反量化回 FP16，使硅面积和动态功耗仍绑定在 16 比特逻辑上。

### 核心科学问题：多模态阻抗失配与微缩放崩溃
- **多模态动态范围差距**：视觉 token 与文本 token 在分布和敏感度上差异巨大。实证分析显示，视觉激活的幅度范围从 −20 到 10，而文本 token 紧密集中在零附近，二者均值相差约 34 倍（μ_v = 0.312 vs μ_t = 0.0091）。
- **两类离群值拓扑**：
  1. **Q/K 矩阵的通道级离群值**：巨大而持续的垂直尖峰集中在特定通道但跨越所有 token，且随层深增长。
  2. **V 矩阵的早期 token 级尖峰**：极端水平尖峰高度集中在早期 token。
- **微缩放崩溃（Microscaling Collapse）**：标准块格式（MX、NVFP4）共享单个块指数。当 1D 块沿通道维度映射时，Q/K 的巨大通道级离群值迫使共享块指数急剧放大，使周围正常幅度的背景 token 下溢为零。实验显示，Layer 27 的 Key 矩阵在 B=32 时，MXINT4 有 44.8%、MXFP4 有 38.4%、NVFP4 有 38.3% 的矩阵背景 token 被致命下溢，注意力图精度被系统性破坏。
- **现有方案的局限**：LLM 中心算法（AWQ、SmoothQuant、SpinQuant、旋转量化）直接迁移到 VLM 会导致严重精度退化；MicroScopiQ 借用不重要元素的比特来缓解崩溃，但带来不规则数据流、深反量化树和硅重型乘法器；MXFP4+ 和 AMXFP4 通过扩展尾数块最大值或两个非对称 FP8 尺度改善精度，但增大了 PE 面积。

### 整体含义
MiX 是首个端到端低比特 VLM 加速器，通过硬件-算法协同设计，在严格边缘功耗/面积/性能（PPA）约束下，从根本上解决多模态动态范围瓶颈。

## 二、方法论

### 核心思想：反转微缩放范式
- **标准 MX 范式**：将多个尾数归组于一个共享指数之下（shared exponent, private mantissas）。
- **MiX 范式**：将多个私有逐元素指数归组于单个共享尾数之下（shared mantissa, private exponents）。通过将比特预算主要分配给逐元素指数差异，MiX 吸收极端块内动态范围，同时保留视觉离群值和细粒度文本特征。

### 两种格式变体

**Type 1: 标准 MiX（MiX-4.25b）** — 对标 MXFP4
- 块大小 B=32，由单个 4 比特最大基指数（E_max）和 3 比特共享尾数（m_shared，含隐式前导 1）锚定。
- 每个元素提取 1 比特符号（s_i）和 3 比特相对指数差（Δe_i），决定右移量；值 7 编码为零。
- 反量化公式：x̂_i = (−1)^s_i × (1.m_shared)₂ × 2^(E_max − Δe_i)
- 有效比特宽：4+3 共享比特加 1 备用比特填充至 8 比特字段，加 128 元素比特，EBW = (8+128)/32 = **4.25 比特**，精确匹配 MXFP4。

**Type 2: 子组尾数（MiX-4.5b）** — 对标 NVFP4
- 块 B=32 共享全局 4 比特 E_max，但划分为 K=4 个大小为 b=8 的子块，每个子块携带自己的 3 比特共享尾数（m_shared,k）。
- 反量化公式：x̂_i∈sub k = (−1)^s_i × (1.m_shared,k)₂ × 2^(E_max − Δe_i)
- 比特成本：4（最大指数）+ 4×3（子组尾数）+ 32×4（元素）= 144 比特，EBW = **4.5 比特**，匹配 NVFP4 但消除其对张量级缩放的依赖。

### 关键算法细节：指数精调
- **基线量化流程**（Algorithm 1）：识别块内最大绝对值提取全局 E_max 和共享尾数 m_shared；对每个元素计算朴素相对指数差 Δe_naive；然后进行**指数精调**，在 ±1 邻域内搜索最小化重建误差的候选值。
- **共享尾数选择**：设置为块最大值的尾数，优于均值、尺度加权和 MSE 替代方案，同时节省硬件复杂度。
- **硬件实现**：精调在硬件中通过单周期低延迟阈值操作实现——利用 4 比特尾数减法，比较器评估残差与 0.5 阈值，确定性输出 +1、−1 或 0 的调整。

### MiX-MX 矩阵乘法与代数分解
- **双格式点积**：A-MiX（激活）× W-MX（权重）。
- **关键分解**：由于 MiX 将多个私有指数归组于一个共享尾数，共享尾数项 (1.m_shared)₂ 和全局基指数可完全从求和中提取出来：

  y = (1.m_shared)₂ × 2^(E_max+E_w) × Σ[(−1)^(s_x,i ⊕ s_w,i) (m_w,i × 2^(−Δe_x,i))]

- **计算步骤简化为**：
  1. **移位（Shift）**：将 MX 权重尾数按 MiX 逐元素相对指数右移。
  2. **累加（Accumulate）**：将移位后的尾数求和形成单个块内部分和。
  3. **缩放（Scale）**：仅执行一次乘法，用共享激活尾数缩放累加和，同时将全局共享基指数相加。

### 硬件架构：无乘法器脉动阵列
- **整体架构**：权重和激活缓冲器分别标记为 MX Memory 和 MiX Memory，馈入 2D 脉动阵列的水平和垂直输入；输出平稳（OS）数据流；每个 PE 每周期摄取整个量化块（32 元素）。
- **PE 微架构**：
  - 符号处理：MXINT 整数根据 MiX 符号位条件反转。
  - 移位：有符号 MXINT 整数进入桶形移位器，移位量为 MiX 元素的 3 比特相对指数。
  - 整数加法树：32 个移位整数馈入并行整数加法树，产生单个未缩放部分和。
  - 标量乘法与 FP 累加：部分和乘以 4 比特共享 MiX 尾数，转入 FP 域；19 比特尾数数据通路；指数通过 E_max + E_shared 构建。
  - **子组变体适配**：MiX-4.5b @ MXINT 将 32 宽加法树划分为四个独立 8 宽子树，各馈入标量乘法器后二级加法合并；MiX-4.5b @ MXFP 额外增加 3 比特加法器求和 FP4 指数与局部差异。
- **双格式量化器**：融合单周期 MiX/MX 硬件量化器，共享特征提取前端（比较器树、舍入器）；MiX 路径包含进位传播舍入、硬件指数精调、非对称零编码（回收 −0 编码额外动态范围）；MX 路径共享比较器和舍入器，通过多路复用器动态切换格式。

### K-Smoothing 恢复技术
- 采用 SageAttention 的训练无关 K-smoothing：γ(K) = K − mean(K)，利用 softmax 对常数平移的不变性。
- 提出**静态 K-mean**：在 prefill 阶段一次性计算每通道均值并冻结用于解码，避免每步重读重量化整个 Key Cache。实验证明静态方案与动态全序列均值精度匹配（平均变化小于 1 分，无崩溃）。
