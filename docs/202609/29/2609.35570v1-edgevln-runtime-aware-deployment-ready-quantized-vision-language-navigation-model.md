## 摘要
视觉语言导航（VLN）模型性能良好，但面向计算资源丰富的平台，限制了其在内存和功耗受限的机器人边缘设备上的部署。仅靠压缩并不能确定 VLN 模型能否在保持导航行为的同时满足边缘平台的内存、延迟和能耗预算。我们提出 EdgeVLN，一种运行时感知、可部署的量化 VLN 模型，以弥合这一差距。EdgeVLN 将量化 StreamVLN 模型与 Latent Trajectory Termination Extractor（LATTE）相结合；LATTE 是一种轻量级因果 Transformer，通过预测 Stop Action 验证器排名来改进实时停止。二者均通过我们的 llama.cpp VLN 驱动程序执行，该驱动程序在板载重建流式上下文并修剪记忆 token。我们对预训练 StreamVLN 主干在 8 至 2 比特权重量化及多种推理运行时下进行了表征，以确定可行的运行点。LATTE 在量化释放的预算内复用主干隐藏状态，既不需要第二个视觉编码器，也不需要额外的主干前向传播。我们在所有 1,839 个 R2R VLN-CE val-unseen 回合上，评估了 BF16 和 IQ4 NL 下的六种主干精度与七种候选停止头。我们在仿真中测量成功率（SR），并在 NVIDIA Jetson Orin NX 16 GB 上测量延迟、能耗和常驻内存。LATTE 在部署的 4 比特模型上取得了我们最高的 SR，为 58.02%，超过 BF16 基线，且每个导航步骤仅增加 0.013 秒延迟。4 比特格式的 SR 几乎相同，但单步能耗因执行路径不同而相差 36.8 倍。只有在我们 VLN 驱动程序下的 IQ4 NL 适合该板卡，其常驻内存为 11.35 GB，同时运行速度比存储流式 BF16 快 20.8 倍，能耗低 13.3 倍。INT2 崩溃。运行时选择、记忆 token 修剪和量化对于高效的边缘部署至关重要。

## Abstract
Vision-language navigation (VLN) models perform well but target compute-rich platforms, limiting deployment on memory- and power-constrained robotic edge devices. Compression alone does not establish whether a VLN model fits the memory, latency, and energy budgets of an edge platform while preserving navigation behavior. We introduce EdgeVLN, a runtime-aware, deployment-ready quantized VLN model that closes this gap. EdgeVLN combines a quantized StreamVLN model with Latent Trajectory Termination Extractor (LATTE), a lightweight causal transformer that improves real-time stopping by predicting a Stop Action verifier rank. Both execute through our llama.cpp VLN driver, which reconstructs streaming context and prunes memory tokens on-board. We characterize a pretrained StreamVLN backbone across weight quantization from 8 to 2 bits and multiple inference runtimes to identify a feasible operating point. LATTE reuses backbone hidden states within the budget freed by quantization, requiring neither a second vision encoder nor an additional backbone forward pass. We evaluate six backbone precisions and seven candidate stop heads on BF16 and IQ4 NL across all 1,839 R2R VLN-CE val-unseen episodes. We measure success rate (SR) in simulation and latency, energy, and resident memory on an NVIDIA Jetson Orin NX 16 GB. LATTE achieves our highest SR, 58.02 percent on the deployed 4-bit model, exceeding the BF16 baseline with only 0.013 s additional latency per navigation step. Four-bit formats achieve nearly identical SR, but step energy varies 36.8 times by execution path. Only IQ4 NL under our VLN driver fits the board, using 11.35 GB resident memory while running 20.8 times faster and using 13.3 times less energy than storage-streamed BF16. INT2 collapses. Runtime selection, memory-token pruning, and quantization are essential for efficient edge deployment.

## 2. 方法论

### 2.1 基础代理：StreamVLN（冻结）

- LLaVA 式架构：SigLIP-SO400M-patch14-384 视觉塔 + 两层 MLP projector + Qwen2 语言模型（28 层，d=3584），共 **8.03 B** 参数。
- 采用快流对话上下文（滑动窗口 KV cache）+ 慢更新记忆上下文，推理时不重处理完整历史；窗口边界处重算对话上下文并以 stride 采样重填记忆 token。
- 记忆增长由**体素空间 token 剪枝**约束；在 RGB-only VLN-CE 设置下该规则不活跃（评测代理提供占位位姿与零深度图）。
- 两项贡献均附加在冻结模型上，**无需重训练主干**。

### 2.2 量化与运行时部署路径

- **量化范围**：仅量化语言模型前馈块，即 **5.70 B / 8.03 B** 参数；视觉塔、projector、注意力投影、embedding、LM head 保持 16-bit。
- **两阶段流程**：
  - 先用**伪量化（fake quantization）**扫描候选精度：按目标网格舍入权重但仍以 16-bit 存储，从而把"精度"与"运行时"解耦，任何后续板上差距可归因于部署路径而非格式本身。
  - 再用 **llama.cpp** 部署（含原生低比特 kernel），此时内存节省才真正出现。
- **自定义 llama.cpp VLN 驱动**：llama.cpp 每轮只编码一张图且无滚动上下文接口，因此驱动需导出视觉塔与 projector 到运行时的多模态格式、重实现 **27×27 → 14×14** 池化（每帧 196 token）、每 32 步清空上下文并重新注入 stride 采样早期帧为原始 embedding 批次。部署栈 = GGUF 权重 + 驱动 + 运行时，推理路径中无深度学习框架。
- **体素剪枝实现**：每个 token cell 取有效深度像素中位数，用深度与位姿流反投影到体素索引，每个时间桶内每体素仅保留最新 token；仅在视觉历史重注入时应用，普通步不增延迟，代价集中在 chunk 边界。

### 2.3 LATTE：Latent Trajectory Termination Extractor

- **输入来源**：读取主干自身**第 24 层隐藏状态**，对每帧 196 个图像 token 行做均值池化得到 3584 维特征。这些激活在导航前向传播中已产生，故**不需要第二个视觉编码器，也不增加主干前向计算**。
- **序列化处理**：决策特征累积在最多 T=256 决策步的缓冲区，时间平均 T=16 步后投影到 d=256。
- **网络结构**：投影后的决策 embedding + 学习位置嵌入 → 两层 pre-norm Transformer encoder（4 头，FFN 宽度 512），严格因果掩码、无界历史 → 最终 LayerNorm + 线性投影 → sigmoid 得到 Stop Action 验证器排名 r_t ∈ [0,1]。
- **训练目标**：回归 `goal_rank_camera_height = clip(1 − d_t/d_max, 0, 1)`，其中 d_max = 5.0 m；在最近接近步之后置零，且当目标未通过相机高度可见性测试时置零；MSE 损失。
- **训练方式**：与冻结模型分离训练，数据为 R2R VLN-CE Train split 上采集的 **3184 个成功 rollout 特征**，按 episode 级划分为 2548/318/318（train/val/test）。
- **触发机制**：因果触发 + 迟滞。跟踪分数运行最大值，当最大值超过阈值且当前分数低于该最大值一个固定 margin 时发出 STOP，从而响应"已回落的峰值"而非每个局部极大；最小步数计数抑制早期误触发。
- **精度处理**：头部保持 **FP32**，与量化主干解耦（因错误停止直接降低任务成功率）。
