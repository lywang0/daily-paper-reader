## 摘要
我们介绍了在采用 gfx90a/CDNA2 架构的 AMD Instinct MI250 GPU 上启用 DeepSeek-V4-Flash 推理、恢复正确性以及进行性能工程的工作。该系统在 SGLang 中集成了原生 safetensors 加载、张量并行与专家并行、FP4 路由混合专家计算、FP8 稠密投影、稀疏注意力、HIP 图执行以及兼容 OpenAI 的服务。最初的一条快速执行路径因路由专家 W2 布局不匹配而被发现数值不正确。我们识别出输出置换，在加载时修复权重布局，并在进一步优化前建立固定 token 和基于哈希的正确性检查。在修正后的路径上，通过打包 FP4 权重、INT8 激活量化、CDNA2 点积指令、peer-read all-reduce 以及拓扑感知内核几何，提升了解码性能。预填充则通过 CDNA2 MFMA 内核、改进的打包权重复用、降低的稀疏注意力开销、更大的 chunk 以及重新调优的专家排序得到加速。在四个 MI250 GCD 上，TP4/EP1 原生自回归解码达到约 74.5 tok/s，而 4,604 token 的提示达到 2.061–2.062 秒 TTFT，即约 2,234 输入 tok/s。结果表明，CDNA2 上高效的 DeepSeek-V4-Flash 推理不仅受内存带宽限制，还受 FP4 执行格式不匹配、低 M 利用率以及逐层同步开销的限制。

## Abstract
We present the enablement, correctness recovery, and performance engineering of DeepSeek-V4-Flash inference on AMD Instinct MI250 GPUs using the gfx90a/CDNA2 architecture. The system integrates native safetensors loading, tensor and expert parallelism, FP4 routed mixture-of-experts computation, FP8 dense projections, sparse attention, HIP graph execution, and OpenAI-compatible serving within SGLang. An initially fast execution path was found to be numerically incorrect because of a routed-expert W2 layout mismatch. We identify the output permutation, repair the weight layout at load time, and establish fixed-token and hash-based correctness checks before further optimization. On the corrected path, decode performance is improved through packed FP4 weights, INT8 activation quantization, CDNA2 dot-product instructions, peer-read all-reduce, and topology-aware kernel geometry. Prefill is accelerated using CDNA2 MFMA kernels, improved packed-weight reuse, reduced sparse-attention overhead, larger chunks, and retuned expert sorting. On four MI250 GCDs, TP4/EP1 native autoregressive decode reaches approximately 74.5 tok/s, while a 4,604-token prompt reaches 2.061-2.062 s TTFT, or approximately 2,234 input tok/s. The results show that efficient DeepSeek-V4-Flash inference on CDNA2 is limited not only by memory bandwidth, but also by FP4 execution-format mismatch, low-M utilization, and per-layer synchronization costs.

## 1. 核心问题与整体含义

- **研究动机**：DeepSeek-V4-Flash 采用混合 FP4（路由专家）/FP8（非专家）权重存储，官方实现主要面向 gfx942/gfx950 等更新架构。AMD Instinct MI250（gfx90a/CDNA2）缺乏原生 FP4 矩阵核心，需在 wave64、64 KiB LDS、INT8/BF16/FP16 矩阵指令的约束下重新适配执行路径。
- **正确性隐患**：早期一条"快速"的 AIter FP4 执行路径在数值上是错误的——路由专家 W2 的输出列存在布局置换，导致约 60 tok/s 的早期结果无效，必须作废并重建正确性基线。
- **性能瓶颈定位**：作者指出 CDNA2 上高效推理的限制不仅来自 HBM 带宽，更来自 FP4 执行格式不匹配、小 M（decode）利用率低、在线 FP4 解包与 scale 处理、专家排序以及逐层同步开销。
- **整体含义**：本文是一次**硬件特定的集成与测量研究**，而非替换 SGLang 服务框架或内核库的新系统；核心贡献在于在 CDNA2 上"先恢复正确性、再做可审计性能工程"。

## 2. 方法论：核心思想与关键技术细节

- **总体思路**：保留原始 FP4/FP8 检查点权重不变，通过形状特定的 HIP、AIter、Composable Kernel（CK）、Triton 路径实现执行；先在固定输入上建立数值正确性，再进行内核与通信优化。
- **正确性恢复（W2 置换修复）**：
  - 旧 CK FP4-by-FP4 stage-1 路径在 gfx90a 上产生零输出；切换到 CKTile BF16-by-FP4 后 stage-1 达到约 0.999996 余弦相似度，但 stage-2 W2 仅约 0.24。
  - 通过输出列指纹定位到每个 128 宽 N tile 内 16 行块的映射：fast → reference = `[0, 2, 4, 6, 1, 3, 5, 7]`。
  - 加载时对原始 W2 权重与 scale 应用逆置换 `[0, 4, 1, 5, 2, 6, 3, 7]`，恢复逻辑输出顺序；这是**一次性加载变换，无解码热路径开销**，对 top-k=1 与 top-k=6 均成立。
- **其他数值修复**：
  - 修复大 prefill BF16-CK 执行中的 E8M0 scale 布局问题（需反转运行时 AIter scale 混洗或使用匹配地址映射）。
  - 确定性索引选择：用逻辑 ID 固定 Top-K 平局，按固定顺序呈现后再做 rank-local 物理映射。
  - Prefill 平凡行快捷方式：保留真实序列长度与全部 compressor/cache 更新，仅跳过与 Top-K 无关的 score 计算。
  - 修复缺失的 C4 生命周期回调与统一 V4 池的压缩比探测。
- **解码优化（历史 TP4/EP1 路径）**：
  - 打包 4-bit FP4 权重（不离线展开）；在线 BF16 激活量化为 INT8（每 32 元素）；E2M1 nibble 映射到 `0, ±1, ±2, ±3, ±4, ±6, ±8, ±12`；CDNA2 `v_dot4_i32_i8`/mixed-dot 累加后做激活与 E8M0 scaling。
  - down projection 中用四个 16-lane 子组处理 top-6 槽位。
  - 用 AIter peer-read 自定义 all-reduce 替代高固定延迟的 RCCL 路径；TP-only mHC 启动几何不再为 Mori 进度预留 CU。
- **Prefill 优化**：
  - 打包 FP4 解包跨行复用（group8 → group32 for M≥1024）；用 `v_perm_b32` 查表替代分支式 nibble 解码；MI250 block-FP8 调优配置；CDNA2 INT8 MFMA routed gate/down 内核；稀疏分页 prefill attention 从 8 波降至 1 波；chunk 从 512/1024 增至 2048/2304；M2048 专用 MFMA 网格；专家排序块从 32 行增至 64 行（M2048 下 gate/up 7.26→5.55 ms，down 6.01→5.26 ms，组合约提升 18.5%）。
- **当前 TP8 新增优化**：
  - **空 C4 tile 守卫**：1M 逻辑池下，超过约 2048 token 阈值后许多 tile 无有效 key 但仍做 query 加载与点积；精确跳过空工作并保留定义的零存储与索引语义。
  - **恢复 C1 投影特化（wo_a GEMV）**：wave64 分量测试 30.75→6.88 μs，保留权重但改变浮点归约顺序。
  - **Down-consumer pilot（默认关闭）**：用 CTA16 consumer 替换 M32 第二段量化/down 链，在 LDS 中形成 group32 INT8 值/scale，保留原 FP32 top-k 部分与固定归约；仅限 native TP8/EP1、M32/I256、A4/R2 几何。
