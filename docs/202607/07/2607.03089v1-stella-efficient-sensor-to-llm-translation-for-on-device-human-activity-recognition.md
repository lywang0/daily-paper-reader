## 摘要
人体活动识别(HAR)越来越需要在边缘设备上持续运行，但近期基于大型语言模型(LLM)的方法仍难以部署：原始传感器提示词过长，云端推理增加延迟和隐私风险，而微调后的LLM流水线将通用模型转化为特定任务分类器。我们提出STELLA，一种面向设备端HAR的传感器到LLM高效翻译框架，将负担从LLM适应转移到传感器令牌化。一个轻量级分层令牌器将整个多通道惯性窗口压缩为固定数量的紧凑潜传感器令牌，这些令牌被投影到冻结预训练LLM的嵌入空间，并与自然语言提示结合以进行标签评分。这保留了活动相关的时间与跨通道结构，同时确保LLM侧计算在不同传感器配置下可预测。STELLA还支持设备端个性化，仅对少量用户标注数据上的轻量级令牌器进行适配，并用本地检索上下文增强推理，使LLM、用户数据和检索均保持在设备端。在七个公开HAR数据集和八个基准设置中，STELLA取得了新的最优性能，F1分数相比先前方法最高提升11.83%；设备端个性化在部署后随用户数据积累，F1分数可进一步最高提升21.91%。在相同LLM流水线下，STELLA也优于代表性时间序列令牌器，并在实际移动和边缘预算下实现实时推理，表明高效传感器令牌化是在边缘设备上实现准确、隐私保护和个性化的基于LLM的HAR的实用路径。

## Abstract
HAR is increasingly expected to run continuously on edge devices, yet recent LLM-based methods remain hard to deploy: raw sensor prompts are long, cloud inference adds latency and privacy risk, and fine-tuned LLM pipelines turn general-purpose models into task-specific classifiers. We present STELLA, an efficient sensor-to-LLM translation framework for on-device HAR that shifts the burden from LLM adaptation to sensor tokenization. A lightweight hierarchical tokenizer compresses an entire multi-channel inertial window into a fixed set of compact latent sensor tokens, which are projected into the embedding space of a frozen pretrained LLM and combined with a natural-language prompt for label scoring. This preserves activity-relevant temporal and cross-channel structure while keeping LLM-side computation predictable across sensor configurations. STELLA also supports on-device personalization, adapting only the lightweight tokenizer on small amounts of user-specific labelled data and augmenting inference with a local retrieval context, keeping the LLM, user data, and retrieval on device. Across seven public HAR datasets and eight benchmark settings, STELLA achieves new state-of-the-art performance, improving over prior methods by up to 11.83% F1; on-device personalization yields up to a further 21.91% F1 as user data accumulates after deployment. STELLA also outperforms representative time-series tokenizers under the same LLM pipeline and achieves real-time inference under practical mobile and edge budgets, showing that efficient sensor tokenization is a practical path toward accurate, private, and personalized LLM-based HAR on edge devices.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：基于大型语言模型（LLM）的人体活动识别（HAR）在边缘设备部署面临三大障碍：
    1. 原始传感器数据序列长、多通道连续浮点值，直接作为文本提示导致LLM注意力计算和KV缓存开销巨大，超出边缘设备能力；
    2. 微调LLM使其成为任务特定模型，丧失通用性，且边缘设备无法同时维护多个专用模型；
    3. 将推理卸载至云端引入网络延迟和隐私风险（行为数据流出设备）。
- **研究背景**：HAR广泛应用于健康监测、康复、健身追踪等，要求实时、连续运行，且需适应不同用户的行为差异。
- **整体含义**：本文主张LLM-based HAR的效率瓶颈不在于LLM本身，而在于传感器与LLM之间的接口。因此，应通过高效传感器分词（sensor tokenization）将计算负担从LLM侧转移到传感器侧，使一个冻结的通用LLM能作为共享后端复用，HAR作为附加模态接入。

## 2. 方法论

- **核心思想**：设计一个轻量级分层传感器分词器（STELLA-Tower），将原始多通道惯性窗口压缩为固定数量的紧凑潜令牌（默认N=16），然后通过浅投影MLP映射到冻结预训练LLM（GPT-2）的嵌入空间，与自然语言任务提示拼接后，由LLM通过计算候选活动标签的平均对数似然进行评分和分类。
- **关键技术细节**：
    - **传感器分词器（STELLA-Tower）**：
        - **卷积堆栈**：深度可分离卷积对每个通道提取局部时间模式，点卷积混合跨通道信息。
        - **分层阶段**：3个阶段，每个阶段包含一个Patch Embedding（步长下采样）和若干RepMixer块（使用深度卷积进行时间混合，代替自注意力以线性复杂度处理长序列）。
        - **晚期自注意力**：在高度下采样后的特征图上应用轻量级多头自注意力（MHSA），捕捉全局依赖。
        - **多尺度令牌聚合**：从阶段2输出H2（局部运动模式）、阶段3输出H3（活动动力学）、注意力增强输出H4（全局上下文）分别通过PoolToN模块插值到固定N个令牌，然后拼接并线性投影得到最终传感器令牌S ∈ R^(N×d)。
    - **投影模块**：两层MLP将传感器令牌从特征空间映射到LLM嵌入维度d_LLM。
    - **训练目标**：自回归语言建模损失，预测活动标签的令牌序列，LLM冻结，仅训练分词器和投影。
    - **推理**：对每个候选标签计算平均对数似然，选择得分最高的。
- **设备端个性化**：
    - 部署后，仅更新轻量级分词器（约10%参数）在少量用户标注数据上；
    - 构建本地知识库（存储用户上下文样本的传感器令牌嵌入与标签）；
    - 推理时通过余弦相似度检索top-k相关上下文，预置到LLM输入中，增强预测。

## 6. 主要结论与发现

- **性能突破**：STELLA在所有8个基准上达到新SOTA，F1最高提升11.83%（HHAR）。在低通道数据集上优势最大（USC-HAD +9.20 F1），在已近饱和的数据集仍取得小幅提升（MHEALTH +0.41 F1）。
- **LLM不是关键瓶颈**：使用冻结的GPT-2（117M）即可优于基于更大LLM（如SensorLLM用8B+710M）的方法，说明传感器分词质量比LLM容量更重要。
- **设备端可行**：在S23 Ultra GPU上推理仅41.7ms，占用预算<5%；在CPU上<400ms亦满足实时性。
- **个性化有效**：最差受试者F1从70.79%提升至92.70%（+21.91），仅需少量用户数据更新分词器。
- **设计原则验证**：多尺度融合稳定增益；RepMixer优于自注意力（尤其长序列）；冻结LLM优于微调；语义标签收益与传感器丰富度相关；NLL评分头远优于线性分类头。

## 7. 优点

- **思路创新**：将边缘LLM-based HAR的挑战重新定义为“传感器分词”问题，而非LLM压缩或提示工程，实现了计算与配置解耦。
- **高效架构**：固定令牌数（如16）使LLM侧计算与原始窗口长度/通道数无关，推理成本可预测；RepMixer代替注意力保证线性复杂度。
- **隐私保护**：所有推理和个性化完全在设备端进行，用户传感器数据从不离开设备。
- **全面实验**：涵盖7个不同性质的HAR数据集、丰富的baseline和消融，并做了详细的设备端分析，论证从理论到部署的可行性。
- **代码细节透明**：提供了prompt模板、超参数、数据预处理等（附录），便于复现。
