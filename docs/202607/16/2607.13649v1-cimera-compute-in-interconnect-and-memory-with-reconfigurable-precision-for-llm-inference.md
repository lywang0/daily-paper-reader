## 摘要
LLM对计算和内存提出了显著需求，从数据中心到功耗受限的边缘设备，为高效推理带来了挑战。权重精度在平衡推理精度、吞吐量和能耗方面起着关键作用，而现代LLM工作负载表现出显著的异构性和容错性，有利于自适应精度执行。本文提出了CIMERA，一种可重构精度的LLM推理加速器，它集成了互连与内存计算以缓解内存墙问题并实现精度感知执行。与Nvidia H100相比，CIMERA在1B和13B模型上分别提供了高达25倍和10倍的能效提升。

## Abstract
LLM impose significant computational and memory demands, creating challenges for energy-efficient inference across platforms ranging from data centers to power-constrained edge devices. Weight precision plays a critical role in balancing inference accuracy, throughput, and energy consumption, while modern LLM workloads exhibit pronounced heterogeneity and tolerance that favors adaptive precision execution. This paper presents CIMERA, a reconfigurable-precision LLM inference accelerator that integrates compute-in-interconnect and memory to mitigate the memory wall and enable precision-aware execution. Compared to Nvidia H100, CIMERA delivers up to $25\times$ and $10\times$ higher energy efficiency for 1B and 13B models, respectively.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）推理面临着巨大的计算和内存需求，导致跨数据中心到边缘设备的能效瓶颈。权重精度是平衡推理精度、吞吐量和能耗的关键参数，但传统固定精度加速器无法灵活适应LLM工作负载中的异构性和数值公差（例如预填充与解码阶段、注意力层与前馈网络层对精度的不同要求）。
- **背景**：现有研究（如LLM.int8()、层间混合精度量化）表明LLM对降低精度具有较强容忍度，但缺乏能动态匹配精度与能耗的硬件架构。CIMERA旨在通过融合计算-互连-内存（Compute-in-Interconnect and Memory）并支持可重构精度，缓解“内存墙”问题，实现精度感知的高效LLM推理。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **可重构精度计算**：在芯片级和宏单元级动态调整权重位宽（4/8/16位），以匹配不同层、不同推理阶段的计算需求，实现能效-精度灵活权衡。
- **计算-互连-内存一体化**：将乘加运算（SMAC）嵌入非易失性存储阵列（FeFET交叉杆），同时将动态数据乘加（DMAC）嵌入片上互连网络（IPCN），减少数据搬运。

### 关键技术细节

#### 硬件架构（Chiplet-2D-Mesh）
- **Processing Element (PE)**：基于氧化物半导体铁电场效应晶体管（OS FeFET）的NVM阵列。每个FeFET存储最多4位权重（QLC），位宽>4时采用空间位切片（bit-slicing）。权重一旦写入即非易失，无需重配置。PE执行静态权重乘加（SMAC），利用交叉杆模拟计算并行性。
- **ADC**：采用逐次逼近寄存器（SAR）ADC，支持通过截断SAR循环实现分辨率重配置（4/8/16位），从而在低精度时降低能耗和转换时间。共享方案：16个ADC分时复用128列（步长16）。
- **Inter-PE Computational Network (IPCN)**：2D网格拓扑，每个路由器内置可编程指令集（ISA）和SRAM暂存器。除路由外，还执行DMAC（如注意力分数计算）、部分和归约、激活函数。KV缓存存放在路由器暂存器中，以就近访问。
- **Monolithic 3D集成**：FeFET阵列垂直堆叠在CMOS逻辑（包括ADC）之上，不额外占用硅面积。

#### 映射与数据流（Mapping & Dataflow）
- **静态权重驻留**：权重矩阵（WQ, WK, WV, WO）分区映射到PE交叉杆，并保持不动。中间张量（Q, K, V, O）分配到对应路由器的暂存器，提升数据局部性。
- **通信模式**：广播（embedding → PE）、单播（DMAC注意力计算）、归约（部分和累加）。层间采用“蛇形”拓扑（serpentine topology），顺序遍历计算瓦片（tile），实现流水线。
- **外部DRAM访问**：仅预填充阶段读入输入token，解码阶段结束时写回输出token。
