## 摘要
多模态基础模型正在将边缘-云视觉智能从特定任务的特征管道重塑为基于令牌的接口，其中边缘设备将视觉输入编码为令牌，供通用云MLLM使用。然而，密集的视觉令牌序列增加了云侧推理成本。现有剪枝方法主要针对集中式推理：视觉驱动的方法可以在云执行之前运行，但通常与查询无关，而查询引导的方法通常依赖目标MLLM的内部状态，无法在传输前确定令牌相关性。紧凑的引导模型提供了一种替代方案，但现有设计可能需要昂贵的注意力聚合或辅助生成。我们提出了LAST，一种用于边缘-云协同MLLM推理中查询依赖视觉令牌剪枝的无训练框架。LAST使用紧凑的边缘侧VLM作为引导代理，并从最后查询令牌对视觉令牌的注意力中导出轻量级重要性信号。在因果注意力下，最后查询令牌可以关注完整的视觉序列和整个查询上下文，从而实现查询感知剪枝，而无需访问云模型、自回归生成或对多个查询位置进行昂贵的聚合。然后，LAST在固定令牌预算下保留一组多样化的查询相关视觉令牌。我们在11个多模态基准上，在多种令牌预算下将LAST与采用不同引导策略的剪枝方法进行了评估。实验表明，LAST始终达到最强性能，在仅保留12.5%视觉令牌的同时保持了95.4%的全令牌准确率，且边缘侧选择开销低，云侧计算减少。

## Abstract
Multimodal foundation models are reshaping edge-cloud visual intelligence from task-specific feature pipelines into token-based interfaces, where edge devices encode visual inputs into tokens for a general-purpose cloud MLLM. However, dense visual-token sequences increase cloud-side inference costs. Existing pruning methods mainly target centralized inference: vision-driven methods can operate before cloud execution but are typically query-agnostic, whereas query-guided methods often rely on internal states of the target MLLM and cannot determine token relevance before transmission. Compact guidance models offer an alternative, but existing designs may require costly attention aggregation or auxiliary generation. We propose LAST, a training-free framework for query-dependent visual token pruning in edge-cloud collaborative MLLM inference. LAST uses a compact edge-side VLM as a guidance proxy and derives a lightweight importance signal from the last query token's attention to visual tokens. Under causal attention, the last query token can attend to the full visual sequence and the entire query context, enabling query-aware pruning without cloud-model access, autoregressive generation, or costly aggregation over multiple query positions. LAST then retains a diverse set of query-relevant visual tokens under a fixed token budget. We evaluate LAST on 11 multimodal benchmarks under multiple token budgets against pruning methods with different guidance strategies. Experiments show that LAST consistently achieves the strongest performance, preserving 95.4% of the full-token accuracy while retaining only 12.5% of the visual tokens, with low edge-side selection overhead and reduced cloud-side computation.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：随着多模态基础模型的发展，边缘-云协同视觉智能正从早期的“任务特定特征管道”（如Digital Retina）向“基于令牌的统一接口”演进。在此新模式下，边缘设备将视觉输入编码为视觉令牌并传输给云端的通用多模态大模型（MLLM）进行推理。
- **核心问题**：这种令牌化接口虽然灵活通用，但视觉编码器产生的密集视觉令牌（Dense Visual Tokens）会显著增加云端推理的计算和通信成本，成为效率瓶颈。因此，**如何在传输前于边缘侧进行有效的视觉令牌剪枝**，是亟待解决的关键问题。
- **现有方法的不足**：
    - **视觉驱动方法**（如VisionZip, VisPruner）：虽然可在云执行前运行，但属于**查询无关**（Query-Agnostic）的选择，可能丢弃视觉上不突出但包含正确答案的关键区域。
    - **查询引导方法**（如FastV, SparseVLM）：依赖目标云MLLM的内部状态，只能在全量视觉序列进入云端后才能获得相关性信号，**无法在传输前进行剪枝**。
    - **现有紧凑引导模型方法**（如SGP）：要么需要跨多个查询位置进行昂贵的注意力聚合，要么需要自回归生成答案，增加了边缘侧计算负担。
- **核心挑战与论文目标**：如何在边缘端使用轻量级信号，在不访问云端模型、不进行自回归生成和高成本聚合的前提下，实现**查询感知（Query-Aware）**的视觉令牌预传输剪枝。该论文提出的**LAST**框架正是为了解决这一挑战。

### 2. 方法论：核心思想、关键技术细节与算法流程

**LAST** 是一个**免训练（Training-Free）**的框架，其核心思想是利用边缘端一个紧凑的视觉语言模型（VLM）作为“引导代理”，仅通过一次 **“免解码的预填充（Decoding-Free Prefill）”** 前向传播，从 **“最后查询令牌”** 的注意力中提取查询相关的轻量级重要性信号，并据此在固定预算下选择多样化且相关的视觉令牌。

- **核心观察**：在因果注意力（Causal Attention）机制下，多模态序列中的**最后一个查询令牌**能够关注到**完整的视觉令牌前缀**和**全部先前查询文本上下文**。因此，它对视觉令牌的注意力分布，可以作为一个简洁的、融合了完整图像与查询信息的查询条件相关性信号。

- **算法流程（文字描述）**：
    1.  **特征提取**：边缘设备使用共享的视觉编码器E将图像I编码为N个视觉令牌X。
    2.  **查询条件重要性打分（Last-Query-Token Attention Scoring）**：
        - 将视觉令牌嵌入（经过边缘侧连接器）与文本查询Q拼接，输入边缘端的紧凑代理VLM。
        - 执行**单次预填充前向传播**，提取最后一个查询令牌位置（p*）在所有层（L）和所有注意力头（H）上对N个视觉令牌的注意力权重。
        - 对提取的注意力权重进行聚合（公式7），并归一化（公式8），得到一个查询条件相关性分布 `ew`。
    3.  **预传输令牌选择（Importance-Weighted Greedy K-Center）**：
        - **初始化**：选择相关性得分最高的令牌作为第一个选中令牌。
        - **迭代选择**：在每次迭代中，计算每个未被选中令牌与当前已选中集合的最小余弦距离（覆盖率增益δ），然后选择**相关性得分（ew）**与**覆盖率增益（δ）**乘积最大的令牌，直到选满预算K个令牌。
        - **目标**：该策略在强调查询相关性的同时，通过特征空间的多样性惩罚来避免将有限的预算浪费在视觉上相似或邻近的区域。
        - 文本令牌永不剪枝。
    4.  **云端推理**：将选中的视觉令牌索引按原始顺序恢复，仅传输这些编码后的视觉令牌到云端。云端的MLLM使用其原生连接器（φc）直接消费这些令牌，无需任何特征对齐或重新编码，即可生成最终答案。

- **关键技术细节**：
    - **共享视觉编码器**：边缘和云模型使用完全相同的视觉编码器参数和令牌布局，仅连接器不同，保证了令牌接口的兼容性。
    - **轻量级信号**：仅使用单一查询位置的注意力，避免了多位置聚合（O(LHM N) vs O(LHN)）或自回归生成，边缘开销极低。
