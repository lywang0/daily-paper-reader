## 摘要
长上下文语言模型推理日益受到存储键值缓存所需的内存带宽和容量的限制，然而现有的压缩方法往往在各层或各令牌上施加统一的预算，并且在需要不同保留的词汇线索和语义状态时会导致检索质量下降。我们提出DepthWeave-KV，一种令牌自适应缓存压缩方法，它利用共享的低秩通道基对相邻Transformer层的键和值状态进行分解，同时在注意力行为敏感的地方保留轻量级的令牌特定残差。DepthWeave-KV结合了跨深度残差分解与一个令牌条件深度路由器，该路由器为包含指令和检索关键的令牌分配更高的重建秩，并使用来自注意力输出探针的免校准在线误差跟踪来在推理期间自适应压缩，无需重新训练基础模型。一个融合的CUDA实现联合执行基查找、残差反量化和注意力投影，以减少解码时的内存流量。在LongBench、Needle-in-a-Haystack、L-Eval以及长格式问答和摘要基准测试中，DepthWeave-KV在显著降低内存使用的情况下实现了接近完整缓存的任务质量，相比之前的压缩缓存提高了平均分数和检索准确率，同时在64K上下文中实现了8.3倍的KV内存压缩和每秒72.8个令牌的处理速度。

## Abstract
Long-context language model inference is increasingly limited by the memory bandwidth and capacity required to store key-value caches, yet existing compression methods often apply uniform budgets across layers or tokens and degrade retrieval when lexical cues and semantic states require different preservation. We introduce DepthWeave-KV, a token-adaptive cache compression method that factorizes key and value states across neighboring transformer layers using shared low-rank channel bases while retaining lightweight token-specific residuals where attention behavior is sensitive. DepthWeave-KV combines cross-depth residual factorization with a token-conditional depth router that allocates higher reconstruction rank to instruction-bearing and retrieval-critical tokens, and uses calibration-free online error tracking from attention-output probes to adapt compression during generation without retraining the base model. A fused CUDA implementation jointly performs basis lookup, residual dequantization, and attention projection to reduce decode-time memory traffic. Across LongBench, Needle-in-a-Haystack, L-Eval, and long-form QA and summarization benchmarks, DepthWeave-KV achieves near-full-cache task quality with substantially lower memory use, improving average score and retrieval accuracy over prior compressed caches while reaching 8.3x KV memory reduction and 72.8 tokens per second at 64K context.

## 论文核心问题与整体含义（研究动机和背景）

- **核心问题**：长上下文语言模型推理时，巨大的**键值缓存（KV Cache）** 成为主要的内存瓶颈，严重限制了批处理大小、上下文长度和吞吐量。现有压缩方案（如令牌驱逐、量化、层共享）通常对**所有层和所有令牌施加统一的压缩预算**，忽略了不同层（浅层词汇锚点 vs 深层语义抽象）和不同令牌（指令性、检索关键 vs 流畅性连续）对缓存的保真度要求差异巨大，导致**检索质量严重下降**（尤其是在Needle-in-a-Haystack、多跳QA等任务中）。
- **研究动机**：需要一种**深度感知（depth-aware）** 且**令牌自适应（token-adaptive）** 的压缩机制，能够根据注意力行为在线调整，在不牺牲检索和推理能力的前提下大幅压缩KV缓存。

## 论文提出的方法论

### 核心思想
- **跨层残差分解（Cross-Layer Residual Factorization）**：不独立存储每层的KV，而是为相邻层组成的深度窗口共享一组低秩通道基（shared low-rank channel bases）。对于每个令牌，通过轻量级的层特定系数和可选的**令牌特定残差**（gated residual）来重建精确的KV状态。
- **令牌自适应深度路由器（Token-Conditional Depth Router）**：根据令牌的**累积注意力质量、注意力尖峰、指令边界标记、以及近期注意力输出重构误差**等在线特征，动态决定每个令牌在特定深度窗口应保留的残差秩（reconstruction rank）。高重要性令牌（如检索锚点）获得更高秩，低重要性连续令牌可使用纯基重建。
- **免校准在线误差跟踪（Calibration-Free Online Error Tracking）**：利用注意力输出探针（attention-output probes）在解码阶段直接测量压缩重建后的注意力输出与真实输出的差异（相对误差）。根据误差自动调整路由器阈值，无需校准数据或重新训练基础模型。

### 关键技术细节
1. **公式表达**：对于深度窗口 \(W_m\)、头 \(h\)、令牌 \(t\)、层 \(\ell\)，重建状态为：  
   \(\hat{K}_{\ell,h,t} = A^K_{\ell,h,t} B^K_{m,h} + g^K_{\ell,h,t} R^K_{\ell,h,t}\) （对V同理）。  
   - \(B\)：共享的低秩基（维度 \(r_b \times d\)）。  
   - \(A\)：压缩系数（8-bit块量化存储）。  
   - \(R\)：量化残差（4-bit组量化）。  
   - \(g\)：轻量级门控，控制残差贡献。
2. **路由器设计**：三个秩级别（0/2/4/8），通过特征向量 \(\phi\) 和可学习参数 \(u\) 以及自适应阈值 \(\tau\) 进行决策。
3. **在线探针机制**：每 \(p\) 步解码，对部分头和查询位置用压缩缓存和临时高保真缓存计算注意力输出，计算相对误差 \(e\)，若超过容忍度则降低阈值、增加残差秩，反之亦然。

1. **预填充阶段**：为每个深度窗口初始化低秩基（基于第一块压缩数据的随机低秩草图），投影KV到系数空间，根据路由器存储量化残差，记录探针统计。
