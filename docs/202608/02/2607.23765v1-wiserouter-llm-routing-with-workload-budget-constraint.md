## 摘要
大型语言模型（LLMs）在多个领域取得了令人瞩目的性能，但在大规模场景下，对每个查询都使用最强模型是难以承受的。LLM路由通过将每个查询分配给合适的模型来利用模型能力和成本的多样性，从而平衡效用和预算。当前方法存在两个局限性：(i) 它们要么使用启发式方法，并不总是强制执行预算约束，要么施加固定的每查询预算，无法随工作负载变化而调整，导致次优性能；(ii) 它们需要在包含每个查询-模型对统计数据的密集数据集上进行监督学习，而收集这些数据成本高昂。为了解决这些挑战，我们将LLM路由建模为一个受约束的上下文多臂老虎机问题，并提出了WISERouter（简称WR），一个支持从历史交互中进行离线学习以及带探索的在线学习的框架。我们进一步证明了WR-Online在时间范围T上取得了$O(\sqrt{T})$的次线性遗憾界。在RouterBench和SWE-Bench上的实证结果表明：(i) WR-Offline在固定预算下的性能超过了现有基线，并且更严格地遵守预算约束；(ii) WR-Online取得了与基线相当的性能，同时使用的探索数据大幅减少。

## Abstract
Large language models (LLMs) achieve impressive performance across multiple domains, but using the most capable model for every query is prohibitive at scale. LLM routing exploits diversity in model capability and cost by assigning each query to a suitable model to balance utility and budget. Current methods have two limitations: (i) they either use heuristics that do not always enforce the budget constraint or impose a fixed per-query budget that cannot adapt across the workload and leads to suboptimal performance; (ii) they require supervised learning on a dense dataset with statistics for every query-model pair, which is expensive to collect. To address these challenges, we formulate LLM routing as a constrained contextual multi-armed bandit problem and introduce WISERouter (WR for short), a framework that supports offline learning from historical interactions as well as online learning with exploration. We further prove that WR-Online achieves a sublinear regret bound of $O(\sqrt{T})$ over a time horizon $T$. Empirical results on RouterBench and SWE-Bench demonstrate that (i) WR-Offline surpasses existing baselines in performance under a fixed budget and adheres more closely to budget constraints, and (ii) WR-Online achieves comparable performance to the baselines, while using substantially less exploration data.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- 随着大语言模型（LLM）能力不断增强，每次查询都使用最强模型的推理成本在规模化场景下变得极其高昂（如前沿模型GPT-5.5的单价可达小型模型GPT-5.4-mini的6.7倍）。
- 不同LLM在不同查询类型上各有优势，小型模型在部分场景可作为高效替代品，因此**推理时模型选择**（inference-time model selection）成为兼顾成本与质量的实用手段，主要分为**LLM路由**（routing，每次查询选择一个模型）和**级联**（cascading，按顺序调用多个模型）两种范式。
- 现有方法存在两大局限：
  - **预算约束粒度问题**：多数方法不施加硬预算，或仅施加**每查询预算**（per-query budget），无法在**工作负载级别**（workload-level，如月API配额、订阅费用）动态分配预算，导致次优决策。
  - **监督数据成本问题**：现有方法通常需要**稠密监督**（每个查询-模型对都需收集响应和成本），当候选模型数量或训练查询增多时，数据收集成本变得难以承担。
- 本文核心问题：(1) 如何在**工作负载级预算约束**下进行LLM路由？(2) 如何在查询-模型交互**稀疏或逐步观测**的情况下学习路由策略？

### 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

**核心思路**：将LLM路由建模为**约束上下文多臂老虎机**（Constrained Contextual Bandit, CCB）问题——每个查询嵌入为上下文（context），选择的LLM为动作（action），观测到的响应质量为奖励（reward），在最大化累计期望奖励的同时满足工作负载级期望成本预算。框架名为**WISERouter**，包含两个变体。

**总体流程分为两步**：

1. **Step 1：上下文离散化（Context Discretization）**
   - 使用预训练编码器 $g(\cdot)$（如 OpenAI TEXT-EMBEDDING-3-SMALL，d=1536）将查询映射为嵌入向量。
   - 通过K-means聚类（$J=16$）将连续高维嵌入空间离散化为有限上下文集合，并估计各簇的分布 $\pi_j$。
   - 假设同一簇内的查询对每个LLM具有相同的期望奖励和期望成本。

2. **Step 2：基于ALP的预算感知路由**

   - **WR-Offline**（数据丰富场景）：从历史数据 $D_{hist}$ 直接估计每个上下文-动作对的期望奖励 $\hat{u}_{j,k}$ 和期望成本 $\hat{c}_{j,k}$。在每个路由步骤，求解自适应线性规划（LP）将剩余预算 $b$ 和剩余轮数 $\tau$ 转化为每轮平均约束 $b/\tau$ ：
     - $\max \sum_{j}\pi_j \sum_{k} p_{j,k}u_{j,k}$
     - s.t. $\sum_{j}\pi_j\sum_{k} p_{j,k}c_{j,k} \le b/\tau$
     - $\sum_{k} p_{j,k} \le 1, \, p_{j,k}\in[0,1]$
     - 每轮重新求解LP实现动态预算分配，无需重新训练即可适应新预算。

   - **WR-Online**（数据稀缺场景）：在线联合估计奖励和成本统计，且**探索和利用共享同一个工作负载级预算**：
     - **探索阶段**（前 $\epsilon(T)$ 步）：将每个查询路由到其上下文内被调用最少的模型，保证每个 (j,k) 对至少被访问 $\lfloor\epsilon(T)/K\rfloor$ 次，更新运行均值 $\bar{u}_{j,k}$ 和 $\bar{c}_{j,k}$。
     - **利用阶段**：用估计统计量求解LP $\tau,b$，按最优概率分布采样动作。
     - 预算随每步实际/估计成本更新：$b \leftarrow b - \hat{c}_{j,A_t}$。

**理论保证**：
- 推导出充分探索条件（Lemma 5.2）：当探索长度满足特定下界时，能以高概率恢复正确的奖励-成本比率排序。
- 证明端到端遗憾界（Theorem 5.3）：非边界情形下 $O(\log T)$ 遗憾，边界情形下 $O(\sqrt{T})$ 遗憾。

- **WR-Offline 在固定预算下优于基线**：在SWE-Bench最紧预算下，质量比最佳基线提升 **14%**；多数预算水平下始终匹配或超越所有基线。

### 7. 优点

- **问题建模新颖**：首次将工作负载级预算约束的LLM路由形式化为CCB问题，弥合了理论带约束老虎机与实际LLM路由之间的鸿沟。
- **统一框架**：同一框架支持数据丰富的离线学习（WR-Offline）和数据稀缺的在线学习（WR-Online），无需为不同场景开发独立方法。
- **无需重训即可适应新预算**：WR-Offline 训练仅需1.5秒，且预算调整只在推理时重新求解LP，比需要针对每个预算级别重新训练的基线高效数个量级（5900倍+）。

- **对组件选择的鲁棒性**：消融显示对嵌入方法、聚类算法、聚类数量不敏感，实用性强。

### 8. 不足与局限

- **i.i.d.上下文假设**：假设查询独立同分布且分布稳定，若查询存在时间依赖（如多轮对话）或分布漂移，遗憾界不再适用；本文仅在附录中对缓解策略作简要讨论，未提供应对非平稳环境的正式方案。
- **成本覆盖有限**：仅探索了货币成本一种约束定义，未验证延迟、能耗等其他成本概念下的有效性。
- **数据集规模有限**：SWE-Bench仅500条查询、5个模型；RouterBench 10个模型；未在更大模型池（如20+模型）上验证可扩展性。
- **置信水平检验（CLT）实际不适用**：论文承认CLT在实践中过于保守——LLM定价层级接近导致 $\Delta^c_{\min}$ 极小，需要大量样本区分近相同成本；且需同时通过 $O(J^2K^4)$ 个比率对的测试，因此实验中使用固定探索调度而非理论指导的停止准则。
- **与理论条件的脱节**：推荐使用的探索长度设定（1×–4×训练集）与理论充分条件（式5）之间的对应关系未在实验中明确验证。
- **基线的公平性问题**：CascadeRouting在RouterBench上使用了测试集统计量，信息获取不对称；FrugalGPT和CascadeRouting的级联长度被限制为2，可能限制了其最优性能。
- **离线数据收集成本被淡化**：虽然WR-Online大幅降低了训练数据量，但WR-Offline仍然需要为每个训练查询收集所有候选模型的响应，这一前提本身的成本未被显式度量。
- **无真实部署验证**：所有实验基于公开基准数据集，未涉及真实API流量的在线部署测试。
