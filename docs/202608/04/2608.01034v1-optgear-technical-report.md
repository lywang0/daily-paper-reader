## 摘要
我们推出了 Opt.Gear，这是一个基础模型，专为高效设备端部署、实时推理和强大的任务能力而设计。它包含一个稠密模型（1M、270M 和 1B），上下文长度为 64K。我们设计了一种新的混合架构，将卷积键值门控混合器与局部-全局注意力相结合，以减少随长上下文呈指数增长趋势的 KV 缓存内存。与类似规模的模型相比，该架构在 NPU 上的预填充和解码速度最高可提升 X4.9 倍。从 2T  tokens 的候选语料库中，Opt.Gear 在没有知识蒸馏的情况下，在一个精选的 0.5T tokens 子集上进行训练。这是现有基础模型中数据效率最高的。所有模型均以开放权重和针对 ONNX、Qualcomm NPU 和 Apple ANE 的部署二进制文件发布，这使得 Opt.Gear 成为需要快速、内存高效推理和强大任务能力的边缘应用的实用基础。此外，为了扩展设备端生成语言模型的生态系统，我们推出了 Opt.Gear-1M，它可以部署在微控制器单元（MCU）上，是一种微型语言模型（TLM）。Opt.Gear-1M 是首个在 STM32H747I-DISCO 的 ARM Cortex-M7 CPU 上通过 W4A32 量化实现 20 TPS 的生成语言模型。

## Abstract
We introduce Opt.Gear, a foundation model designed for efficient on-device deployment, real-tim inference, and strong task capability. It includes a dense model (1M, 270M, and 1B) with a context length of 64K. We designed a new hybrid architecture that combines a convolutional key-value gated mixer with local-global attention to reduce the KV-cache memory that tends to increase exponentially with long context. This architecture delivers up to X4.9 faster prefill and decoding speeds on the NPUs compared to models of a similar scale models. From a 2T tokens candidate corpus, Opt.Gear is trained on a curated 0.5T tokens subset without knowledge distillation. This is the most data-efficient of the existing foundation models. All models are released with open weights and deployment binaries for ONNX, Qualcomm NPU, and Apple ANE making Opt.Gear a practical base for edge applications that need fast, memory-efficient inference and strong task capabilities. Furthermore, to expand the ecosystem of on-device generative language models, we are introducing the Opt.Gear-1M that can be deployed on Micro-Controller Units (MCUs), a Tiny Language Model (TLM). Opt.Gear-1M is the first generative language model to achieve 20 TPS with W4A32 quantization on the ARM Cortex-M7 CPU of the STM32H747I-DISCO.

- **核心问题**：大型语言模型（LLM）在服务器端性能强大，但难以直接部署到智能手机、嵌入式设备、机器人等端侧设备上。端侧部署受限于 SRAM 容量、功耗、实时延迟以及异构 SoC（CPU/GPU/NPU）的硬件约束，尤其是**注意力机制中的 KV-Cache 随上下文长度增长导致内存和带宽开销剧增**，成为端侧推理的主要瓶颈。
- **整体含义**：论文提出 **Opt.Gear**，一个面向端侧高效部署的生成式语言模型家族（1M、270M、1B 参数），通过**硬件感知的混合架构**，在保持任务能力的同时显著降低推理时的内存流量和延迟。其核心意义在于：展示无须依赖大规模算力和知识蒸馏，即可通过架构创新和高质量数据实现高效端侧 LLM 设计与部署，并扩展至 MCU 级别的生成能力。

## 2. 论文提出的方法论

### 核心思想
- 采用**混合架构**：将少量全局注意力（GQA）层与大量局部混合层（ConvKV-Gated Mixer）结合，分工处理长距离信息路由和局部上下文混合。
- 用**无注意力评分矩阵、无 softmax 的局部混合模块**替换滑动窗口注意力，降低 GQA 计算和 KV-Cache 访问开销。
- 通过**固定大小的卷积状态**替代序列长度相关的局部 KV-Cache，使持久化缓存容量不再随上下文长度增长。

### 关键技术细节
1. **ConvKV-Gated Mixer（卷积 KV 门控混合器）**：
   - 输入序列 X，每 token 投影为 query、key、value：  
     \( q_t = x_t W_q, k_t = x_t W_k, v_t = x_t W_v \)
   - 对 key 和 value 做因果深度可分离 1D 卷积，引入局部上下文：
     \[
     \tilde{k}_t = \sum_{i=0}^{L_{conv}-1} a_i \odot k_{t-i}, \quad \tilde{v}_t = \sum_{i=0}^{L_{conv}-1} b_i \odot v_{t-i}
     \]
   - 通过门控融合：  
     \[
     g_t = \sigma(q_t \odot \tilde{k}_t), \quad y_t = g_t \odot \tilde{v}_t, \quad o_t = y_t W_o
     \]
   - 不构造 token 间注意力矩阵，避免 softmax，运算均为静态线性、卷积和逐元素操作，易于映射到 NPU/CPU/GPU 等边缘运行时。

2. **内存高效缓存机制**：
   - 传统 GQA 或滑动窗口注意力缓存分别为 \( O(2Cd_{kv}) \) 和 \( O(2Wd_{kv}) \)，随上下文或窗口线性增长。
   - ConvKV-Gated Mixer 仅保留固定卷积缓冲区：  
     \[
     \mathcal{C}_K, \mathcal{C}_V \in \mathbb{R}^{d_{kv} \times L_{conv}}, \quad \text{Cache}=O(2L_{conv}d_{kv})
     \]
   - \( L_{conv} \) 通常为 3（Opt.Gear-270M/1B）或 4（Opt.Gear-1M），远小于滑动窗口大小且与上下文无关。

3. **模型配置**：
   - Opt.Gear-1B：\( d_{model}=1152 \)，26 层，GeGLU FFN，GQA（4 query heads / 1 KV head），head size 256，滑动窗口 512，全局 RoPE theta=1e6，局部 RoPE theta=1e4，上下文 65,536。
   - Opt.Gear-270M：18 层，\( d_{model}=640 \)，FFN 2048，类似设计。
   - Opt.Gear-1M：5 层，\( d_{model}=128 \)，2 个 query heads / 1 KV head，head size 64，FFN 272，ReLU6GLU，BPE tokenizer（vocab 2048），最大序列长度 512，面向 MCU 部署。
   - 使用 QK-LN（query-key normalization），未绑定词嵌入，KORMo tokenizer（125,184 vocab）支持韩英双语。

4. **量化感知训练（QAT）**：
   - 基于 **Hessian 感知的初始化**：以 GPTQ 风格层重建误差最小化确定每组 INT4 的初始量化尺度，而非简单最大绝对值。
   - 采用 **LSQ（Learned Step Size Quantization）** 微调量化步长，在训练前向中模拟 W4A16 部署格式。
   - 通过直通估计器（STE）处理不可微的取整操作，最终保证初始化、QAT 训练和实际部署的量化网格一致。

## 3. 实验设计

### 训练数据
- 初始收集约 **2T tokens** 的英/韩/数学/通用网络语料，经筛选、去重、混合重平衡后得到 **0.5T tokens** 训练集。
- 预训练混合比例：约 92% 英文、6% 韩文、2% 数学，**不包含代码数据**。
- 不使用知识蒸馏（无 teacher model）。
- Opt.Gear-1M 未使用通用预训练语料，而是使用 50,000 对 GPT 生成的 **stm32_cmd_synth** 合成数据，进行 STM32 开发板控制指令映射（LCD/LED/摄像头控制）的后训练。

### 评估基准
- 使用 **LM Evaluation Harness** 评估。
- **多学科选择题**：MMLU、MMLU-Pro、KMMLU、GPQA

- **韩国语理解与文化**：CLIcK、HAERAE、KoBEST
- 部分数据集采用困惑度（perplexity）评估。

### 对比方法

## 6. 论文的主要结论与发现

- **架构有效性**：Opt.Gear 的混合架构在 NPU 上相比类似规模模型，Prefill 和 Decode 速度最高提升 **4.9 倍**（如 Snapdragon GEN5 上 Opt.Gear-1B Prefill 7042 TPS vs Gemma3-1B 3226 TPS）。
- **数据效率**：仅用 0.5T tokens（无蒸馏）训练即可在多个基准上优于或媲美使用 2T–36T tokens 训练且使用蒸馏的同类小模型。
- **韩语优势**：Opt.Gear-1B 在 KMMLU、KoBEST、CLIcK、HAERAE 上全面超越 Gemma3-1B、Llama3.2-1B、EXAONE 4.0-1.2B；Opt.Gear-270M 在 KMMLU 和 KoBEST 上也优于 SmolLM2-135M 和 Gemma3-270M。
- **量化稳定性**：Opt.Gear 经 QAT 后，再施加 RTN/AWQ/GPTQ 等 PTQ 技术时性能下降很小（如 MMLU 41.3→39.8），优于 Gemma3-1B 等同类模型。
- **端到端可视性**：Opt.Gear-1M 在 ARM Cortex-M7 上以 W4A32 量化实现 20 TPS 的真实生成速度，静态 RAM 约 449 KB，证明生成式语言模型可实现在 MCU 上交互式运行。
- **运行时适配**：在专用 NPU 运行时（QAIRT/CoreML）表现最佳，但在 llama.cpp 的 NPU 后端中因滑动窗口注意力无法被硬件有效加速而出现性能骤降。

## 7. 优点

- **硬件感知设计突出**：将注意力中动态、不可预测的 QK 乘法和 softmax 替换为静态卷积与逐元素操作，大幅改善 NPU 上的算子亲和性和内存局部性。
- **KV-Cache 优化创新**：固定小尺寸卷积状态替代局部注意力缓存，从根源上消减长上下文解码的带宽压力。
- **数据效率与可复现性**：不使用知识蒸馏，0.5T tokens 即可达到竞争性能，降低了复现门槛。
- **量化体系完整**：从 Hessian 初始化到 LSQ 训练再到部署量化网格一致，形成闭环，PTQ 鲁棒性好。
- **部署生态扎实**：提供 Transformers、llama.cpp、ExecuTorch、vLLM 支持，并直接发布 ONNX、Qualcomm NPU、Apple ANE 二进制；MCU 端给出实测数据而非模拟，可信度高。
- **发布开放权重**：全系列模型开源，便于社区研究和落地。

## 8. 不足与局限

- **推理与任务能力受限**：0.5T tokens 训练预算限制了复杂推理和数学能力，MMLU-Pro、GPQA 等分数仍明显低于更大的蒸馏模型（如 Qwen3-1.7B）。
- **归因模糊**：未独立缩放数据规模、数据组成和模型容量，无法确定剩余推理差距主要来自模型尺寸、数据不足还是训练低效。
- **训练时间未披露**：论文只给出估算，没有实际训练时长、能耗或集群占用时间，资源消耗透明度不足。
- **部分运行时不兼容**：在 llama.cpp NPU 后端，滑动窗口注意力成为瓶颈，导致性能异常低（Prefill 290 TPS），说明架构需要专用运行时配合，通用运行时适配性有待提高。
- **评估偏向**：基准评测以英文和韩文为主，缺少代码、多语言泛化、数学专项（如 GSM8K/MATH）等更多维度的能力检验；MMLU-Pro 和 GPQA 表格中部分数据疑似存在异常（如 EXAONE 4.0-1.2B 的 MMLU-Pro 43.2 明显高于同规模其他模型，可能包含格式差异或错误）。
- **1M 模型过于专用**：Opt.Gear-1M 仅针对 STM32 板控指令，不能作为通用 MCU 助手；其在 MCU 上 20 TPS 是在较小序列长度（160 tokens）和 40 token 生成限制下测得，不能代表长上下文行为。
- **消融实验缺失**：未系统比较 ConvKV-Gated Mixer 相比纯 GQA 或纯滑窗注意力的性能/速度权衡，也未见对卷积核大小、局部/全局层比例等关键超参的消融分析。
