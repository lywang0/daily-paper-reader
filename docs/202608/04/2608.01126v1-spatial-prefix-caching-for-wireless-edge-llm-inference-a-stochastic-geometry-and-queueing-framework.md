## 摘要
前缀缓存复用共享提示前缀的键值（KV）状态，可以显著减少大语言模型（LLM）推理的首次令牌时间（TTFT）。然而，在无线边缘网络中，前缀状态分布在地理位置分离的GPU节点上。附近的节点提供较短的无线路径，但可能提供很少的复用；而较远的节点可能缓存更长的匹配前缀，但会带来额外的通信和排队延迟。此外，持久前缀和活动请求的KV状态竞争同一GPU内存，因此激进缓存会降低推理并发性并造成排队热点。本文为这种空间通信-缓存-计算权衡开发了一个随机几何与排队论框架。我们用前缀森林表示提示工作负载，并定义一个包含多个可复用前缀的祖先封闭缓存配置文件。边缘GPU节点形成泊松点过程，并独立地用缓存配置文件标记，产生解析上易处理的空间层次。我们推导了在负载感知关联策略下的配置文件关联概率、条件服务距离分布、令牌级计算分流比和TTFT覆盖概率。一个不动点公式刻画了空间关联与多服务器GPU队列之间的耦合，而外部优化在静态内存和稳定性约束下选择缓存配置文件分布。解析结果与蒙特卡洛结果吻合良好。结果表明，延迟最优节点不一定是最邻近节点，且由于GPU内存耦合，TTFT在缓存前缀深度上的变化可能是非单调的。

## Abstract
Prefix caching reuses the key--value (KV) states of shared prompt prefixes and can substantially reduce the time to first token (TTFT) of large language model (LLM) inference. In a wireless edge network, however, prefix states are distributed across geographically separated GPU nodes. A nearby node offers a short radio path but may provide little reuse, whereas a more distant node may cache a longer matching prefix but incur additional communication and queueing delay. Moreover, persistent prefixes and active-request KV states compete for the same GPU memory, so aggressive caching can reduce inference concurrency and create queueing hotspots. This paper develops a stochastic-geometry and queueing framework for this spatial communication--caching--computation tradeoff. We represent the prompt workload by a prefix forest and define an ancestor-closed cache profile that may contain multiple reusable prefixes. Edge GPU nodes form a Poisson point process and are independently marked by cache profile, yielding analytically tractable spatial tiers. We derive the profile-association probability, conditional serving-distance distribution, token-level computation-offloading ratio, and TTFT coverage probability under a load-aware association policy. A fixed-point formulation captures the coupling between spatial association and multi-server GPU queues, while an outer optimization selects the cache-profile distribution subject to static-memory and stability constraints. Analytical and Monte Carlo results agree closely. The results show that the latency-optimal node need not be the nearest node, that TTFT can be non-monotonic in cached-prefix depth because of GPU-memory coupling.

## 1. 核心问题与整体含义

- 论文聚焦**无线边缘网络中 LLM 推理的前缀缓存**问题。前缀缓存复用提示词共享前缀的键值（KV）状态，能显著减少首次令牌时间（TTFT）。
- 与传统云集群不同，无线边缘网络的 GPU 节点在地理上分散，且存在三种相互冲突的维度：
  - 附近节点无线路径短，但可能没有可复用的前缀；
  - 远端节点缓存前缀更深、计算节省更多，但引入额外通信与排队时延；
  - 持久前缀缓存与活动请求的 KV 状态竞争相同 GPU 内存，激进缓存会降低并发度、制造排队热点。
- 经典无线缓存模型假设缓存对象独立、命中是二进制的，无法刻画前缀的树状结构、部分命中收益及内存–并发耦合。
- 论文的核心目标是建立**空间通信–缓存–计算权衡的统一分析框架**，回答“应选择哪个边缘 GPU 服务请求”这一问题。

## 2. 方法论

### 核心思想

- 将提示工作负载建模为**前缀森林**，每个节点的缓存状态是**祖先封闭的缓存配置文件**（profile），即沿根到叶的一条或多条路径。
- 边缘 GPU 节点服从齐次泊松点过程（PPP），每个节点独立随机选择一种配置文件，形成可解析的**独立分层 PPP**。
- 提出**负载感知的空间关联策略**：请求选择使“通信时延 + 剩余预填时延 + 平均排队时延”最小的配置节点。
- 排队模型采用 **M/M/c 多服务器排队（Erlang-C）**，并建立**空间关联与队列负载之间的不动点方程**，刻画相互耦合。
- 外部优化问题在**静态内存、稳定性等约束**下选择配置文件分布，最大化 TTFT 覆盖概率。

### 关键技术细节

- 前缀森林表示：请求类型 $q$ 对应树中一条根到叶路径，配置 $s$ 提供的最长可复用前缀长度为 $H_{s,q}$。
- 独立标记：配置 $s$ 的节点形成强度 $\lambda_s = \lambda_b \pi_s$ 的 PPP，其中 $\pi_s$ 为配置文件选择概率。
- 通信模型：$T_{com}(r) = \xi r^\alpha$，剩余预填时延 $T_{pf}^{s,q} = g(L_q - H_{s,q})$，$g(\cdot)$ 为预填时间函数（可含线性项与二次注意力项）。
- 关联概率（定理 1）：
  $$
  A_{s,q} = \int_0^\infty 2\pi\lambda_s r \exp\left[-\pi\lambda_s r^2 - \pi\sum_{t\neq s}\lambda_t G_{s,t,q}^2(r)\right] dr
  $$
  其中 $G_{s,t,q}(r)=\left[\frac{r^\alpha + \Delta_{s,q} - \Delta_{t,q}}{\xi}\right]_+^{1/\alpha}$，$\Delta_{s,q} = \bar{W}_s + T_{pf}^{s,q}$。
- TTFT 覆盖概率（定理 2）：
  $$
  P_{cov}^{TTFT}(\tau) = \sum_q p_q \sum_s \int_0^{r_{s,q}^{max}(\tau)} f_{s,q}^{sel}(r) F_{W_s}(\tau - \xi r^\alpha - T_{pf}^{s,q}) dr
  $$
  其中 $F_{W_s}$ 是 Erlang-C 等待时间 CDF，$r_{s,q}^{max}(\tau)$ 由时延目标截断。
- 不动点迭代：使用阻尼迭代 $\bar{W}^{(i+1)} = (1-\eta)\bar{W}^{(i)} + \eta Q(A(\bar{W}^{(i)}))$，确保关联概率与队列延迟的一致解。
- 外部优化采用投影同时扰动（simultaneous perturbation）算法，并考虑候选配置文件的剪枝（存在支配配置文件时剔除）。
- 网络规划问题：可以求解最小边缘 GPU 密度以满足给定 TTFT 可靠性目标。

## 6. 主要结论与发现

- 延迟最优节点**不一定是最近节点**：较长的无线路径可以由更深的前缀复用来弥补，但仅当预填节省大于额外通信和队列时延。
- TTFT 覆盖概率随缓存前缀深度**非单调变化**：浅缓存因节省预填而改善，但过深的缓存会消耗大量 GPU 内存、降低并发度，导致排队恶化。
- **队列感知路由至关重要**：前缀感知但队列无感知的路由在请求强度高时性能大幅下降（如 TTFT 覆盖从 0.69 降至 0.23），甚至比忽略缓存的最近节点路由还差。
- 最优缓存配置文件混合**依赖于负载**：高负载下应减少深缓存、保留更多高并发 fallback 配置。
- 边缘 GPU 密度与缓存多样性存在耦合：增加密度可以改善覆盖，但如果配置分布不合理，单独增加密度无法替代缓存多样性。
- 提出设计原则：浅层公共前缀广泛复制，深层专业前缀有选择性部署，保留高并发备用容量，按端到端边际延迟节省路由。

## 7. 优点

- **理论创新**：统一了随机几何与排队论，将经典二进制内容缓存推广为**空间部分计算状态复用理论**，适用于树状前缀结构和部分命中场景。
- **建模细致**：明确刻画了持久缓存内存与活动请求并发之间的竞争，抓住了边缘 LLM 缓存区别于传统文件缓存的本质。
- **解析可处理性**：通过独立标记的 PPP 得到关联概率和覆盖概率的积分表达式，并建立不动点迭代，数值收敛稳定。
