## 摘要
本文研究了在软截止时间约束下，用于大语言模型（LLM）推理的协作移动边缘计算（MEC）服务器。在该系统中，为了提高服务质量，计算预计在其截止时间内完成。然而，由于任务或子任务之间的依赖性，任何错过截止时间的情况都可能对整个请求造成灾难性后果。在此背景下，本文提出了一种具有受限灵活性的扩展截止时间机制。主要挑战在于在严格的延迟约束下处理大规模计算，同时限制允许的截止时间扩展次数，尤其是在每个请求存在任务依赖性的情况下。为了应对这些挑战，我们开发了一个Transformer增强的近端策略优化（PPO）框架，使MEC服务器之间能够高效协作。所提出的方法旨在最大化在截止时间内完成的任务数量，同时最小化截止时间扩展的使用。通过捕获时间依赖性和跨服务器交互，Transformer改善了任务迁移的决策。仿真结果表明，所提出的方法在任务完成率和整体系统效率方面显著优于传统的PPO和基于启发式的方法。

## Abstract
This paper investigates collaborative mobile edge computing (MEC) servers for large language model (LLM) inference under soft deadline constraints. In this system, to improve the quality of service, computations are expected to be completed within their deadlines. However, due to dependencies among tasks or subtasks, any missed deadline can lead to catastrophic consequences for the entire request. In this context, this work proposes an extended deadline mechanism with constrained flexibility. The main challenges lie in handling large-scale computations under strict latency constraints while limiting the number of allowable deadline extensions, especially in the presence of task dependencies within each request. To tackle these challenges, we develop a transformer-enhanced proximal policy optimization (PPO) framework that enables efficient collaboration among MEC servers. The proposed approach aims to maximize the number of tasks completed within their deadlines while minimizing the use of deadline extensions. By capturing temporal dependencies and cross-server interactions, the transformer improves decision-making for task migration. Simulation results demonstrate that the proposed method significantly outperforms conventional PPO and heuristic-based approaches in terms of task completion rate and overall system efficiency.

- **研究背景**：随着生成式 AI（GenAI）应用（如视频生成、图像分析、基于 Avatar 的 XR 实时推荐系统、智慧交通管理）的迅猛发展，LLM 推理请求的计算负载极高，传统集中式云端处理面临网络瓶颈和高延迟问题。移动边缘计算（MEC）将计算推向网络边缘，但其有限的计算资源难以独立承载 LLM 这类高负载任务。
- **核心挑战**：
  - LLM 推理请求可建模为具有多颗子任务、且子任务间存在依赖关系的 DAG。任何子任务超过截止时间，都会导致整个请求失败，造成“灾难性后果”。
  - MEC 服务器异构、资源有限，在高负载（大量用户并发请求）下满足严格延迟约束非常困难。
  - 何时将任务迁移到哪个协作 MEC 服务器、是否使用截止时间扩展（deadline extension），是一个复杂的序贯决策问题。
- **研究含义**：本文旨在通过 MEC 服务器间的边缘-边缘协作机制，结合软截止时间约束和受限截止时间扩展机制，最大化成功按时完成的任务数、最小化截止时间扩展次数，从而在边缘侧实现高效、低延迟的 LLM 推理服务。这是下一代智能应用在边缘网络中规模化部署的必要探索。

## 2. 论文提出的方法论

### 2.1 系统建模

- **MEC 系统**：包含 |S| 个异构 MEC 服务器（计算容量 fs 各异），每个服务器配备 M 个计算资源（GPU），每资源有独立队列，采用最早截止时间优先（EDF）非抢占调度。用户按马尔可夫移动模型移动，通过 OFDMA 接入基站。
- **任务建模**：每个请求 Ri 包含 Ki 个任务，每个任务 Tk,i 由 dk,i 个子任务组成，子任务间存在依赖关系（DAG）。每个子任务有 CPU 周期需求 α、截止时间 β 和截止时间扩展次数 γ。
- **截止时间扩展机制**：子任务调度前预测到可能超期时，允许扩大截止时间，每次扩展增加一个等于其计算时间（不含排队延迟）的时长；每个任务有最大扩展次数上限，以限制排队延迟过度累积。
- **问题形式化**：构建优化问题 P1，目标为最大化完成任务总数 − η × 截止时间扩展次数，约束包含无线资源分配、子任务依赖关系、队列调度、任务唯一分配等。其中用户接入与无线资源分配用预设策略处理，本文核心优化变量为任务迁移决策 xk,i,s(t)。

### 2.2 MDP 建模

- **状态**：s(t) = {任务信息（依赖关系、子任务数、资源需求、截止时间信息）、所有 MEC 队列状态与服务器信誉、通信条件、服务器算力}。
- **动作**：a(t) ∈ S，选择某个 MEC 服务器作为任务迁移目标（即任务迁移决策）。
- **奖励**：r(t) = [ω1·Σ φk,i − ω2·Σ γ / Σ(dk,i+Γk,i)]，通过权重 ω1、ω2 与目标对齐。
- **状态转移**：系统随任务到达、用户移动、信道变化、队列动态随机演化，满足马尔可夫性质（论文中 Lemma 1 给出证明）。

### 2.3 Transformer 增强的 PPO 算法

- 将过去 L 个观测的历史状态序列 s̃(t) 输入 Transformer 编码器，借助**自注意力机制**捕获：
  - **时序依赖**：队列演化、负载波动、任务依赖模式随时间变化的长期规律；
  - **跨服务器交互**：不同 MEC 服务器间资源竞争和协作关系。
- Transformer 构成：线性投影（64 维）→ 可学习位置编码 → 单层编码器（4 头注意力、前馈维度 128、GELU 激活、pre-LN）→ 时序维平均池化 → LayerNorm 得到全局上下文向量。
- 该全局上下文向量同时输入 Actor（线性策略头，输出各候选服务器的 logits，构造分类分布选取动作）和 Critic（线性价值头，估计状态价值）。
- 训练采用 PPO 裁剪目标函数 + GAE，Adam 优化器（lr=10⁻⁴）、γ=0.99、λ=0.95、clip=0.2、价值损失系数 0.5、熵正则 0.005、梯度裁剪 0.5，每轮 3 个 PPO epoch，优势归一化并裁剪到 [−10, 10]。
- 对比基线：传统 PPO（用 MLP 替换 Transformer 编码器处理扁平化后的历史观测序列），以及无任务迁移方案（No migration）。

## 6. 论文的主要结论与发现

- Transformer-enhanced PPO 相比传统 PPO 收敛较慢（约 4000 轮后才逐渐缩小差距），但训练曲线更稳定、波动更小，最终收敛到显著更高的平均奖励。
- 在任务完成率方面，所提方法在所有用户数（10~50）下相较于传统 PPO和无迁移方案均有“一致且显著的差距”（例如 50 用户时服务器完成任务率约 0.35 vs 0.28 对无迁移）。
- Transformer 增强的 PPO 相比传统 PPO 将迁移任务完成率提升约 9%（实验条件 40 用户），总完成子任务数提升约 2%。
- 任务复杂度是性能瓶颈的主要因素：简单算子（如 layer norm 和 residual add）即使在 50 用户下完成率仍可达 0.95~0.97，而高计算量算子（feed_forward、self_attention）在高负载下完成率急剧下降至 0.26~0.49。
- 所提方法在各类算子下均保持了更高的完成率和更多的剩余截止时间扩展次数，表明其在高负载下具有更好的鲁棒性和资源利用效率。

## 7. 优点

- **问题建模严谨**：将 LLM 推理任务合理抽象为带依赖关系的 DAG 子任务模型，贴近真实 LLM 推理的算子级结构（注意力、前馈网络、归一化等），并考虑软截止时间与可受限扩展机制，实用性强。
- **方法设计合理**：用 Transformer 捕获时序依赖和跨服务器交互来解决传统 PPO 在动态 MEC 环境中的短视问题，是对 DRL 用于任务迁移决策的有效改进；加入位置编码与历史状态序列，能较好感知队列演化和工作负载波动。
- **奖励函数与目标对齐**：归一化奖励同时包含任务完成数和截止时间扩展惩罚，通过权重调节，训练目标与优化问题 P1 一致。
- **实验设计比较全面**：训练收敛性、不同负载、不同算子类型、不同方法的多视角对比，数据呈现完整（见图和表）。
- **引入迁移任务完成率与剩余调整率两个指标**，能从“任务调度的时效性”和“系统的容错余量”两个层面刻画系统性能，具有一定创新性。

## 8. 不足与局限

- **未报告训练成本**：未说明训练 Transformer-enhanced PPO 所需的 GPU 型号、数量和小时数，这对实际部署中评估算力开销非常重要。
- **缺少消融研究**：未分析历史序列长度 L、Transformer 层数/注意力头数、截止时间扩展上限、奖励权重 ω1/ω2 等超参数对性能的影响，方法设计的最优性缺乏验证。
- **仿真假设较强**：
  - 假设任务计算需求（FLOPs）是预先 profile 好的固定值，而实际 LLM 推理因缓存命中、动态批处理、输入差异等存在明显运行时变化；
  - 假设 MEC 间采用 RDMA 高速回传链路，未建模回传拥塞和网络延迟波动；
  - 用户到达采用泊松过程，真实业务往往呈现突发性（bursty）；
  - 假设队列采用 EDF 非抢占调度，简化了实际任务调度的复杂性。
- **可扩展性未探讨**：所提集中式 Transformer-enhanced PPO 代理需要收集所有服务器信息，在大型 MEC 系统（更多服务器、更多用户）下，状态空间扩大可能导致训练复杂度和通信开销急剧增加，本文未对其进行实验验证。
- **统计学可靠性不足**：单次训练结果未报告多次随机种子下的均值和方差，无法确认性能提升的统计显著性。
- **缺少真实系统与基线扩展验证**：实验结果全部来自仿真环境，且未与更多启发式方法（如最短队列优先迁移、最少负载迁移）进行对比，说服力有待加强。
