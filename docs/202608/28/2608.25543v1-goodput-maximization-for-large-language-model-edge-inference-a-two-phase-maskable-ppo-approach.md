## 摘要
本文提出了一种新颖的两阶段可掩蔽近端策略优化（TP-MPPO）算法，该算法在严格遵守服务水平目标（SLO）的前提下，最大化无线边缘网络中面向大语言模型（LLM）推理服务的系统有效吞吐量（即满足SLO的请求吞吐量）。在TP-MPPO的第一阶段，我们通过带有动作掩蔽机制的MPPO优化任务卸载决策，有效避免探索无效动作并缩小动作空间。在第二阶段，我们推导了上行链路带宽分配的闭式解；并为下行链路带宽分配设计了一种贪心算法，以为下一轮MPPO提供即时奖励。这两个阶段交替进行，直至收敛。仿真结果表明，与基准方法相比，TP-MPPO可将系统奖励提高33.3%–87.5%，并实现最高的有效吞吐量。

## Abstract
This paper presents a novel two-phase maskable proximal policy optimization (TP-MPPO) algorithm, which maximizes the system goodput counting request throughput with strict service level objective (SLO) compliance for large language model (LLM) inference services in wireless edge networks. In the first phase of TP-MPPO, we optimize the task offloading decisions by MPPO with action masking mechanism, effectively avoiding exploring invalid actions and reducing the action space. In the second phase, closed-form solutions are derived for uplink bandwidth allocation; a greedy algorithm is designed for downlink bandwidth allocation to provide immediate rewards for the MPPO in the next round. The two stages alternate till convergence. Simulation results demonstrate that TP-MPPO can improve the system reward by 33.3%--87.5% compared to its benchmarks and achieve the highest goodput.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想

提出**两阶段可掩蔽近端策略优化（TP-MPPO）**算法，将原始MINLP问题（P1）分解为两个交替优化的阶段：
- **第一阶段**：用带动作掩蔽机制的MPPO学习任务卸载决策。
- **第二阶段**：给定卸载决策后，上行带宽分配采用闭式解，下行带宽分配采用贪心算法，并为下一轮MPPO提供即时奖励。
- 两阶段交替迭代直到收敛。

### 关键技术细节

1. **系统建模**：
   - 场景：1个服务控制器（与AP共存）、J个GPU边缘节点、N个无GPU用户，用户将推理任务卸载至边缘节点。
   - 请求模型：每个请求 \(q_t^n = \langle s_{in}, s_{out}, \varsigma \rangle\)，包含输入长度、最大输出长度和E2E延迟界。
   - 通信模型：OFDM，边缘节点分频运行避免干扰；上下行带宽分数为 \(\beta_{up}, \beta_{down}\)；速率公式基于香农公式，信道包含路径损耗和瑞利衰落。
   - 延迟建模：E2E延迟 = 调度等待 + 上行传输 + 批处理等待 + 批推理（prefill + decoding）+ 下行传输。
   - 内存建模：内存足迹 = 模型权重 + KV缓存（ \(m_{kv} = 4hLb(s_{in} + o_{out})\) ），需满足节点显存上限。

2. **MPPO卸载决策**：
   - **状态空间**：请求信息、上下行信道增益、各节点空闲状态 \(I_j^t\)。
   - **动作空间**：对每个用户动态生成二进制掩蔽向量 \(v_t^n\)，节点不可用或请求不存在时对应logit设为 \(-\infty\)，Softmax后概率为0，从而**剪除无效动作，缩小搜索空间**。
   - **奖励函数**：\(r_t = \nu_{good} \frac{\sum g_t^n}{N_{req,t}} - \nu_{oom} \frac{N_{oom,t}}{N_{req,t}}\)，兼顾Goodput贡献与内存溢出惩罚。
   - **网络更新**：采用PPO的CLIP损失函数和GAE优势估计，行为网络和评论家网络交替训练。

3. **上行带宽闭式解**：
   - 目标：最小化同一批次中最大的上行传输延迟（min-max公平）。
   - 最优策略：令同批次所有用户的上行延迟相等，得到闭式解：\((\beta_{up}^{t,nj})^* = \frac{D_{in}^{t,n}/R_{up}^{t,nj}}{\sum_{i \in N_j^t}(D_{in}^{t,i}/R_{up}^{t,ij})}\)。

4. **下行带宽贪心算法（Algorithm 1）**：
   - 对每个用户计算满足SLO所需的最小下行带宽 \(\beta_{down,min}^{t,nj}\)。
   - 将用户按最小带宽需求升序排序，依次分配带宽直至耗尽，从而选择出满足 \(\sum \beta_{down,min} \le 1\) 的最大用户子集。
   - **最优性保证**：由于每个被选中用户对Goodput的贡献相等（均为1），按最小需求优先分配是最优策略，复杂度为 \(O(N \log N)\)。

## 7. 优点

1. **问题建模新颖且完整**：首次将E2E延迟全链路（调度等待、上行、批等待、推理、下行）与GPU内存约束统一建模，贴合真实LLM推理系统的实际运行方式。
2. **方法设计巧妙**：将NP-hard的MINLP问题分解为RL（卸载）+ 解析解（上行带宽）+ 贪心算法（下行带宽），其中下行带宽子问题利用“等值贡献”结构获得了最优贪心策略；闭式上化解避免了RL探索连续动作空间的高代价。
3. **动作掩蔽机制实用高效**：通过掩蔽无效动作大幅缩小动作空间，提升样本效率和收敛速度，可推广到其他受状态约束的决策问题。
4. **Goodput作为优化目标**：相比单纯吞吐量，Goodput同时计入了SLO合规率，更贴近真实服务质量需求。
5. **即时奖励设计合理**：第二阶段为MPPO提供即时奖励，解决了稀疏奖励下的训练困难问题。

## 8. 不足与局限

1. **仿真缺乏硬件实测验证**：所有实验均为仿真环境（基于简化的解析延迟模型和模拟信道），未在真实GPU集群（如A100/H100）或实际LLM推理系统（如vLLM、TGI）上验证，实际部署效果可能因硬件细节而异。
2. **通信模型假设理想化**：假定上行和下行传输均在一个时隙内完成、信道准静态，未考虑多时隙传输和信道时变性；实际无线网络中用户移动性和信道波动可能显著影响性能。
3. **实验统计不够充分**：未提供多次运行的标准差/置信区间，无法判断算法增益的统计显著性；缺乏对超参数（如 \(\nu_{oom}\)、\(\epsilon\)）的敏感性分析。

6. **扩展性未验证**：实验最多到30个用户、6个节点，更大规模（如百级节点、千级用户）下的性能和收敛性尚未研究。
