## 摘要
本文提出了一种针对Gemma-3-1B的分层位分配方法，将问题表述为在给定退化预算约束（允许的生成质量损失水平）下的性能最大化（延迟降低）。这种方法不同于文献中使用的耗时且耗资源的均匀层量化方法（如GPTQ或AWQ），也不同于没有证明性能加速效果的分层分配方法（如MixLLM或TorchAO）。我们先前工作SA-PTQ得到的层敏感性分布被应用于TensorRT-LLM内的激活直通模式。根据先前步骤中引入的分组（5+5、10+10、all26），每个层的精度按块单独确定，区分FFN、Attention和lm_head对总体加速的贡献。在RTX 5090上测量了13种W8A8变体的时钟速度。我们发现对于FFN和lm_head，量化/反量化的时间成本被整数算术的使用所补偿，而对于短上下文长度，Attention则相反：额外的量化步骤会减慢执行速度。我们提出了TensorRT-LLM的SmoothQuant手动实现，由于导出失败这是必要的，且不适用于lm_head。在联合考虑所有三个标准且退化最小的情况下找到的最佳解决方案是FFN 5+5与lm_head，提供了11.0%的延迟降低，质量损失可忽略（Top-1一致性98.90%，困惑度退化+0.85%）。对于FFN all26 + lm_head，在可接受的质量损失下，发现可实现高达19.1%的加速。我们建议进一步优化：INT8融合注意力内核、KV缓存量化、使用FP8代替INT8，以及类似于FFN的部分注意力量化。

## Abstract
This paper proposes a layer bit allocation method for Gemma-3-1B, formulating the problem as performance maximization (latency decrease) given a degradation budget constraint (allowable level of generation quality loss). This approach is different from time- and resource-consuming uniform layer quantization methods that are used in the literature (like GPTQ or AWQ) or allocation methods without proven performance-accelerating effect (like MixLLM or TorchAO). The layer sensitivity profile resulting from our prior work SA-PTQ is applied using the activation pass-through mode inside TensorRT-LLM. For each layer precision is determined individually in blocks, according to a grouping introduced in the prior step (5+5, 10+10, all26), differentiating the contribution of FFN, Attention, and lm_head to the overall speedup. The clock speed was measured for 13 W8A8 variants on an RTX 5090. We find that for FFN and lm_head the time cost of quantization/dequantization is compensated for by the use of integer arithmetic, while for short context lengths, the opposite holds true for Attention: an additional step of quantization slows execution down. We propose a manual implementation of SmoothQuant for TensorRT-LLM which was necessary due to export failures, unavailable for lm_head. The best solution found under joint consideration of all three criteria with minimal degradation was FFN 5+5 with lm_head, providing an 11.0% reduction in latency with negligible quality loss (98.90% Top-1 agreement, +0.85% perplexity degradation). With acceptable quality loss for FFN all26 + lm_head, a speedup up to 19.1% was found possible. We suggest further optimizations: fused attention kernels in INT8, KV-cache quantization, using FP8 instead of INT8 and partial Attention quantization analogous to FFN.

- 现有量化方法存在两类不足：
  - **均匀量化**（GPTQ、AWQ）：所有层使用相同位宽，未考虑不同层对量化的敏感性差异，且主要关注显存压缩，而非实际推理加速；
  - **已有的混合精度方法**（MixLLM、TorchAO）：虽然按层或按特征分配位宽，但**没有提供每层量化对延迟的实际影响证据**，也未处理混合精度导致的量化/反量化开销。
- 论文的核心问题可以概括为：**在给定生成质量退化预算下，如何为不同层分配位宽，以最大化推理速度（延迟降低）**，并通过真实硬件测量验证收益。

## 2. 方法论

- 基础：使用作者此前提出的 **SA-PTQ 敏感性指标**，通过 SQNR（信号量化噪声比）评估每层对量化的鲁棒性，从而选出“可安全量化”的层。
- 量化目标：对 FFN、Attention、lm_head 三个子系统进行**块级 W8A8（INT8 权重与激活）混合精度量化**，敏感层保持 FP16。
- 层分组方案：
  - `5+5`：量化第 0–4 层和 21–25 层（共 10 层）；
  - `10+10`：量化第 0–9 层和 16–25 层（共 20 层）；
  - `all26`：量化全部 26 层。
- 实现与关键细节：
  - 使用 **TensorRT-LLM** 的 activation pass-through（激活直通）模式，通过 QuantConfig 在编译期为不同子图设置不同数据类型；
  - 线性层采用**对称 per-channel 量化**：  
    `s_i = max_j |W_i,j| / (2^(b-1) - 1)`，`cW = round(W/s) * s`，其中 b=8；
  - **Attention 量化**：Q/K/V/O 投影均量化为 INT8，但 softmax、RoPE、KV-cache 仍保持 FP16；
  - **lm_head 量化**：由于 TensorRT-LLM 官方导出流程存在 bug（Gemma 的 tied embedding 会导致假量化），作者**手动实现了 SmoothQuant**，公式为：  
    `δ_j = max_t |X_t,j|^α / max_i |W_i,j|^(1-α)`，α=0.5；  
    权重静态 per-channel 量化，激活动态 per-token 量化，最终在 INT8 域执行 GEMM，并按尺度乘积反量化。由于插件单次最多 65536 个输出通道，lm_head（262144 维）被拆成 4 块分别处理。

## 6. 主要结论与发现

- **FFN 量化稳定加速**：`5+5` 为 1.031×，`10+10` 为 1.075×，`all26` 为 1.090×；且非量化中间层能部分补偿量化误差。
- **Attention 量化在短上下文下无速度收益**：`attn_ffn all26` 速度反而比 FFN-only `all26` 低（1.069× vs 1.090×，约 -7.7 tok/s）。原因：TensorRT-LLM 的 `masked_multihead_attention` 内核保持 FP16，只有 Q/K/V/O 投影使用 INT8 GEMM；且 Gemma-3-1B 采用 GQA（4 query heads，1 KV head），投影矩阵较小，INT8 收益不足以抵消 Q/DQ 开销。
- **lm_head 单独量化有效**：手动实现 SmoothQuant 后获得 1.071× 加速，Top-1 一致性 98.90%，困惑度仅退化 +0.85%。
- **最佳综合配置为 FFN `5+5` + lm_head**：加速 **11.0%**，生成质量基本保持；
- **在允许质量退化时，FFN `all26` + lm_head 可达 19.1% 加速**，但生成质量明显下降（出现重复 token）。
- 未来优化方向：融合 INT8 attention 内核、KV-cache 量化、FP8 替代 INT8、对 Attention 采用类似 FFN 的局部层量化。
