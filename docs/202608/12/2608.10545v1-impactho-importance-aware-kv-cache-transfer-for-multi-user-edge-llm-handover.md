## 摘要
边缘LLM必须在用户在边缘节点之间切换时保持推理连续性，这需要将键值(KV)缓存传输到目标节点。然而，同时切换会使回程网络饱和，从而在移动性约束的传输窗口内无法完成完整缓存交付。我们并非将带宽视为所有缓存条目同等价值来分配，而是按重要性对每个用户的KV缓存进行排序，仅传输其中信息量最大的部分，将令牌级稀疏性转化为通信节省。我们将传输问题构建为一个多用户回程分配问题，以最大化所有用户的平均准确率。每个用户的部分缓存准确率作为其效用：一个S形函数，在RULER基准上拟合测量结果，跨模型和上下文长度的$R^2>0.99$。由于重要性排序使得高价值条目优先传输，准确率曲线的凹区域几乎覆盖整个缓存。我们提出的分配器使服务用户保持在该区域内，从而使每个时隙的分配问题成为凸问题。最优解通过一种闭式加权注水解法推导得出，该解法推广了信息论注水法，并支持在线调度。所提出的分配器在500ms传输窗口内达到93.7%以上的平均准确率，与完整缓存上限的差距在0.5个百分点以内，并达到先验上限的98.2-99.5%。

## Abstract
Edge LLMs must preserve inference continuity when a user hands over between edge nodes, requiring key-value (KV) cache transfer to the target node. However, simultaneous handovers saturate the backhaul, preventing full cache delivery within the mobility-imposed transfer window. Rather than allocating bandwidth as if all cache entries were equally valuable, we order each user's KV cache by importance and transmit only its most informative fraction, turning token-level sparsity into communication savings. We cast the transfer as a multi-user backhaul allocation problem that maximizes average accuracy across users. Each user's partial-cache accuracy serves as its utility: a sigmoid that fits measurements on the RULER benchmark with $R^2>0.99$ across models and context lengths. Because importance ordering front-loads the high-value entries, the concave region of the accuracy curve spans nearly the entire cache. Our proposed allocator keeps served users within this region, making each per-slot allocation problem convex. The optimum is derived via a closed-form weighted water-filling solution that generalizes information-theoretic water-filling and enables online scheduling. The proposed allocator attains over 93.7% average accuracy in a 500ms transfer window, within 0.5pp of the full-cache ceiling, and reaches 98.2-99.5% of a clairvoyant upper bound.

### 1. 核心问题与研究动机

- **背景**：边缘LLM推理依赖多接入边缘计算（MEC）提供低延迟服务，但用户移动会导致服务节点切换（handover）。为了保持推理连续性，需要将用户的键值缓存（KV cache）从源节点传输到目标节点。
- **核心矛盾**：多用户并发切换会饱和回程链路（backhaul），导致无法在移动性约束的传输窗口内完成完整KV缓存传输。同时，KV缓存数据量远大于原始文本（如Qwen3-8B的8K上下文KV缓存约1.2 GB），使得全量传输不现实。
- **关键空白**：已有研究（如KV cache eviction）表明缓存条目重要性不均，但面向的是单模型内存预算而非共享回程的多用户带宽分配；已有边缘切换方案（如ctHO）需要预知切换时机、离线调度且不支持"随时推理"（anytime inference）。
- **核心问题**：如何以在线方式将有限回程带宽分配給多个同时切换的用户，最大化平均推理准确率？

### 2. 方法论

**核心思路**：按重要性对每个用户的KV缓存条目排序，只传输最富信息量的前缀部分，将token级稀疏性转化为通信节省。

**技术细节**：

- **重要性排序**：采用Fast KVzip的gating网络分数对每个KV条目（token在特定layer和head对应的key-value对）评分，按降序传输。与随机排序相比，重要性排序将准确率曲线的拐点（concavity anchor）拉低到约6.5%缓存分数处，使凹区域几乎覆盖整个缓存。
- **效用函数建模**：通过RULER基准测试，将部分缓存准确率拟合为代数Sigmoid函数（R²>0.99）：
  \[
  A_i(y)=\frac{M_i}{2}\left(1+\frac{k_i(y-\tau_i)}{\sqrt{1+k_i^2(y-\tau_i)^2}}\right)
  \]
  其中M_i、k_i、τ_i分别为准确率上渐近线、过渡尖锐度和凹性锚点。
- **优化问题**：将每个时隙的带宽分配建模为凸优化问题——在回程预算约束下最大化所有用户的聚合准确率提升。问题形式为：
  - 目标：最大化Σ[A_i(y_i)−A_i(x_i)]，其中x_i为当前已接收分数，y_i为时隙末接收分数。
  - 约束：回程带宽限制ΣL_i b_i ≤ B、每用户区间约束τ_i ≤ y_i ≤ 1。
- **闭式求解**：通过KKT条件推出加权注水（weighted water-filling）闭式解——每个用户的"水位"由其对偶价格λ和自身缓存大小L_i共同决定，边界情形（达到全缓存或停靠在锚点）统一处理。
- **可行性判断与准入控制**：若带宽不足以保证所有用户到达凹性锚点（B < B_min），则启用"均衡字节"（Equalized Bytes）回退策略，优先将带宽平均分配给未达锚点的用户，避免"亚τ饥饿"。
- **算法复杂度**：通过二分搜索对偶价格，每时隙运行时间为O(N log(λ̄/ε))，接近线性。

### 6. 主要结论与发现

- 重要性排序使部分缓存准确率呈Sigmoid形状（R²>0.99），拐点低至约6.5%缓存分数，使凹区域几乎覆盖整个缓存——这为凸优化分配奠定了经验基础。
- 提出的加权注水分配器在500ms传输窗口下达到93.7%平均准确率，距全缓存上限仅差0.5pp；达到clairvoyant上界的98.2%−99.5%。
- 在回程带宽有限和切换负载高的场景下，重要性感知分配比效用无关的EA和PF更优；比贪婪的WTA在大带宽场景下更优（避免过度服务饱和用户）。
- 重要性排序相对随机排序优势巨大：随机排序在ρ=8时准确率仅20.2%，而重要性排序保持在90%以上。
- 准入控制是重负载下的主导因素：无准入时亚τ饥饿率达20.8%，使用EB后降至0.65%。
- 相比计算基线，上下文越长优势越明显（平均延迟391ms vs re-prefill 847ms、hybrid 434ms），且支持anytime inference（收到部分缓存即可恢复解码）。

### 7. 亮点与优点

- **问题建模视角新颖**：将"缓存重要性排序塑造效用函数形状"与网络资源分配耦合，使非凸的Sigmoid效用问题退化为凸问题——这是方法论上的关键洞察。
- **闭式解优雅**：加权注水解带有清晰的物理解释（边际精度增益均衡），且退化为经典注水为特例，理论上兼容信息论框架。
- **经验驱动**：对四个Sigmoid函数族进行系统拟合，并报告拐点稳定性（τ∈[0.064,0.067]），为效用假设提供可靠经验支撑。
