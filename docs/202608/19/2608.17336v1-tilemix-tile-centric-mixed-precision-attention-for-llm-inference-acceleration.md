## 摘要
长上下文预填充（prefill）阶段在大型语言模型（LLM）中会产生大量的计算和内存流量，因为密集自注意力需要对查询-键点积进行二次方级别的计算。现有方法要么采用统一的低精度路径，要么选择性地处理令牌交互，而未能在融合的密集注意力中，跨硬件对齐的分数瓦片进行空间精度路由。我们提出了TileMix，一种以瓦片为中心的精度路由内核，将数值精度转变为融合密集注意力中分数瓦片组上的可执行空间决策。TileMix将注意力矩阵划分为硬件对齐的分数瓦片，将路由决策压缩为紧凑的位掩码，并将每个瓦片组通过FP16或INT8分数计算进行调度，同时两条路径共享在线softmax状态。可扩展的精度分组允许每个路由位管理多个相邻的键瓦片，从而在长上下文场景中保持硬件对齐的计算瓦片和紧凑的元数据。通过路由所有合法的瓦片组，TileMix保持了密集的令牌连通性，无需训练，并支持分组查询注意力、变长批次以及INT8键/值缓存。在LongEval、LV-Eval以及A100预填充基准测试中，针对LLaMA、Qwen和Vicuna模型，TileMix恢复了统一INT8下丢失的长上下文质量，并相对于FP16提升了预填充吞吐量，在不同模型家族中产生了可控的精度-效率权衡前沿。该实现可在https://github.com/HanzhiZhang-Ulrica/TileMix获取。

## Abstract
Long-context prefill in large language models (LLMs) incurs substantial computation and memory traffic because dense self-attention computes quadratic query-key scores. Existing methods either use a uniform low-precision path or select token interactions, leaving spatial precision routing over hardware-aligned score tiles outside fused dense attention. We introduce TileMix, a tile-centric precision-routing kernel that makes numerical precision an executable spatial decision over score-tile groups within fused dense attention. TileMix partitions the attention matrix into hardware-aligned score tiles, packs routing decisions into compact bitmasks, and dispatches each tile group through FP16 or INT8 score computation while both paths update a shared online-softmax state. Scalable precision grouping lets each routing bit govern multiple adjacent key tiles, preserving hardware-aligned compute tiles and compact metadata at long contexts. By routing all legal tile groups, TileMix preserves dense token connectivity, requires no training, and supports grouped-query attention, variable-length batches, and INT8 key/value caches. Across LongEval, LV-Eval, and A100 prefill benchmarks on LLaMA, Qwen, and Vicuna, TileMix recovers long-context quality lost under uniform INT8 and improves prefill throughput over FP16, yielding a controllable accuracy-efficiency frontier across model families. The implementation is available at https://github.com/HanzhiZhang-Ulrica/TileMix.

## 1. 核心问题与研究动机

- **背景**：Transformers 越来越依赖长上下文（如文档摘要、多页问答、检索增强生成）。在 LLM 的 prefill（预填充）阶段，密集自注意力需要计算所有 query-key 交互，产生 \(O(L^2)\) 次分数计算，成为长序列推理的主要瓶颈。
- **现有方法的不足**：
  - **低精度量化**（如 INT8）通常采用统一的算术路径或阶段级精度，缺乏对注意力矩阵中不同空间区域进行精细化精度分配的能力；
  - **稀疏化方法**通过移除部分 token 交互来减少计算，但会改变注意力连通性，可能导致信息丢失；
  - **IO 感知融合注意力**（如 FlashAttention）以硬件对齐的 tile 为基本执行单元，但精度仍是每个 kernel 调用或注意力阶段统一固定的。
- **核心问题**：能否在保持密集、完整注意力连接的前提下，将数值精度作为“空间决策”，在硬件对齐的 score tile 上灵活分配 FP16/INT8 路径，从而获得更好的精度-效率权衡？

## 2. 方法论：TileMix

### 2.1 核心思想

- 将注意力矩阵划分为硬件对齐的二维 score tile（大小为 `BLOCK_M × BLOCK_N`），每个“瓦片组”（可由多个相邻键瓦片组成）独立选择 FP16 或 INT8 计算路径。
- 所有合法瓦片组都参与计算，不引入稀疏性；FP16 与 INT8 路径共享同一个在线 softmax 状态，最终输出与密集注意力等价的归一化结果。
- 通过紧凑的 64 位位掩码编码路由决策，内核内部以常数时间完成路径选择。

### 2.2 关键技术细节

- **路由策略**：一个二进制图 \(R_{h_k,m,g_j}\) 决定查询瓦片行 \(m\) 的第 \(g_j\) 个键瓦片组走 INT8（1）还是 FP16（0）。支持多种静态布局模板：
  - `One`（全部 INT8）
  - `Zero`（全部 FP16）
  - `Band`（对角线附近保持 FP16）
  - `Global`（固定全局位置 FP16）
  - `RowRand`（每行随机选固定比例 FP16）
  - `AlignedSparse`（右对齐、随行扩展的 FP16 区域）
  - `BigBird`（局部 + 全局 + 随机的组合）
  - `SpTrans`（稀疏 Transformer 风格的局部跨步 + 尾部）
- **分组与位掩码**：
  - 定义分组因子 \(g\)，使每个路由位控制 \(g \cdot \text{BLOCK\_N}\) 个键 token；
  - 每个 (KV head, query tile row) 的路由决策打包成一个 64 位整数 \(b_{h_k,m}\)；
  - 内核内通过 `((b >> g_j) & 1)` 常数时间取出决策。
- **混合精度执行**：
  - FP16 路径：\(S_{nm} = Q_m K_n^\top / \sqrt{d}\)
  - INT8 路径：对 \(Q, K\) 分块量化得到 \(Q_8, K_8\) 和块缩放因子，利用 INT8 Tensor Core MMA 得到 INT32 累加结果，再乘以缩放因子并除以 \(\sqrt{d}\)，进入统一浮点域；
  - 两条路径均更新共享的在线 softmax 状态（running max、normalizer、output accumulator），状态保存在 FP16 中，但部分中间计算使用 FP32。
- **实用支持**：
  - GQA（分组查询注意力）：映射到同一 KV head 的 query head 共享路由掩码；
  - 变长批次：通过 `cu_seqlens` 前缀和元数据实现无 padding 路由；
  - INT8 KV 缓存接口：预存 K8/V8 及块缩放，decode 阶段直接使用。

## 6. 主要结论与发现

- TileMix 在保持密集 token 连接的前提下，通过瓦片级精度路由，**恢复了均匀 INT8 造成的长上下文质量损失**，并能在多种布局下**超过 FP16 的 prefill 吞吐**（如 LLaMA 3.2 3B 在 4k 时 SpTrans75 达 31.80 K tokens/s vs FlashAttention 14.33）。
- **精度-效率可控**：INT8 覆盖率越高，加速越明显，但质量下降程度与布局强相关；`row_rand`、`sptrans` 等布局在高覆盖率下保持更好的准确率。
- **数值行为**：输出偏差随 INT8 覆盖率增加而增大，但 0% 时与 FP16 参考接近；FP16 与 FP32 累加差异远小于路由本身带来的影响。
- **静态路由的保护作用**：SpTrans 布局下，高重要性 attention mass 被 INT8 覆盖的比例低于名义覆盖率，说明结构化先验可以有效保护关键交互。

## 7. 优点

- **方法新颖**：首次将“精度”作为可执行的空间路由决策，集成在 FlashAttention 风格内核内部；
- **无需训练**，直接适用于预训练模型；
- **硬件友好**：使用位掩码 + 常数时间查找，元数据开销极低（每个 query tile row 仅一个 64 位字），且保持硬件对齐的 Tensor Core 计算瓦片；
- **实用性强**：支持 GQA、变长批次、INT8 KV 缓存，可直接用于部署；
- **实验较全面**：多模型、多基准、多布局、多覆盖率的组合，验证了方法的普适性和可控性；
