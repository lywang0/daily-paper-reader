## 摘要
结构化剪枝通过移除权重列来减小大型语言模型（LLM）的规模与推理成本，但由此产生的输出误差可能损害精度。现有的免训练补偿方法在保留权重的输出侧使用加性偏置或单一正交旋转。这些校正保持其输入奇异框架不变，因此限制了保留权重在列移除后的适应能力。我们提出COEC（校准正交等价补偿），一种免训练的补偿框架，对保留权重交替施加左、右正交旋转。右旋转在约化Stiefel流形上优化，同时使用广义交叉验证重新缩放奇异值，以逐层选择正则化强度。COEC进一步对校准格拉姆矩阵进行温度调整，以减少高能量激活方向的主导作用，并引入对齐惩罚以保持相邻注意力投影之间的几何关系。所有组件均使用来自小型校准集的二阶统计量，既不需要通过LLM反向传播，也不需要重新训练模型参数。COEC独立于列剪枝准则，可应用于多种结构化剪枝方法。在Llama-3、Llama-3.1和Qwen2.5模型系列上、多种结构化稀疏度下的实验表明，与现有补偿方法相比，COEC在每个模型上均改善了困惑度，在大多数设置中提高了零样本准确率，且在更高稀疏度下收益更大。这些结果表明，剪枝后补偿可以部分恢复因列移除而损失的性能。

## Abstract
Structured pruning reduces the size and inference cost of large language models (LLMs) by removing weight columns, but the resulting output error can degrade accuracy. Existing training-free compensation methods use an additive bias or a single orthogonal rotation on the output side of the retained weight. These corrections leave its input singular frame unchanged and therefore limit how the retained weight can adapt after column removal. We propose COEC (Calibrated Orthogonal-Equivalence Compensation), a training-free compensation framework that applies alternating left and right orthogonal rotations to the retained weight. The right rotation is optimized on a reduced Stiefel manifold, while singular values are rescaled using generalized cross-validation to select the regularization strength for each layer. COEC further tempers the calibration Gram matrix to reduce the dominance of high-energy activation directions and introduces an alignment penalty that preserves the geometric relation between adjacent attention projections.All components use second-order statistics from a small calibration set and require neither backpropagation through the LLM nor retraining of the model parameters. COEC is independent of the column pruning criterion and can be applied to multiple structured pruning methods. Experiments on the Llama-3, Llama-3.1, and Qwen2.5 model families across multiple structured sparsity levels show that COEC improves perplexity on every model and zero-shot accuracy in most settings over existing compensation methods, with larger gains at higher sparsity. These results show that post-pruning compensation can recover part of the performance lost to column removal.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：大型语言模型（LLM）推理的算力和内存成本高昂，结构化剪枝通过删除整列权重（如 MLP 神经元、注意力 KV 组）来直接缩小稠密模型，在标准硬件上即可获得加速，无需稀疏内核支持。
- **核心挑战**：删除权重列必然引入输出误差，导致模型精度下降。由于 LLM 规模庞大、重训练成本过高，**免训练（training-free）的剪枝后补偿**成为关键需求。
- **现有方法的局限**：
  - 现有免训练补偿方法分为两类：加性偏置（如 FLAP）和单侧正交旋转（如 RCPU）。
  - **加性偏置**只能校正常数均值误差，无法弥补输入相关的方向性误差。
  - **单侧（左侧）旋转**只改变输出奇异框架，保留权重的输入奇异框架不变，限制了压缩后权重的适应能力。
  - 无约束最小二乘重拟合虽可降低校准误差，但易在小型校准集上过拟合，损害预训练权重。
- **论文的核心主张**：剪枝会显著旋转输入奇异子空间，仅靠左侧旋转无法恢复这种旋转。有效的补偿必须**同时在权重两侧施加正交旋转**，才能通过保留列恢复与已移除列相关的输出贡献。
- **整体含义**：COEC 提供了一种**与剪枝准则无关的通用即插即用补偿框架**，可附加在任何现有结构化剪枝方法之后，以零训练成本恢复部分因剪枝损失的性能。

## 2. 论文提出的方法论

### 2.1 核心思想

COEC 将补偿权重参数化为**保谱族的双侧旋转更新**：

$$\tilde{W} = Q_\ell W_K^{(S)} Q_r$$

- $Q_\ell \in O(d_{out})$：左旋转，调整输出奇异框架
- $Q_r \in O(k)$：右旋转，调整输入奇异框架
- $W_K^{(S)}$：对保留权重奇异模式施加正则化缩放

### 2.2 交替优化流程（Algorithm 1）

求解器交替执行以下步骤，最多 50 轮，早停条件为损失变化 < $10^{-4}$：

1. **左旋转（闭式解）**：$Q_\ell = \text{polar}(G_{yx}\tilde{W}^\top)$，即正交 Procrustes 解
2. **尺度更新**：$s^* = \langle G_{yx}, \tilde{W} \rangle / \langle \tilde{W}, \tilde{W}G_{xx} \rangle$
3. **右旋转（迭代求解）**：约化 Stiefel 流形上的加权正交 Procrustes 问题（无闭式解），从 $Q_r = I$ 初始化，采用投影梯度下降
4. **再次尺度更新**，并每轮重算 GCV 奇异值缩放

### 2.3 关键技术创新

| 组件 | 作用 | 技术实现 |
|---|---|---|
| **约化 Stiefel 求解器** | 消除不影响输出的冗余优化方向 | 利用切片 $W_g = U_g\Sigma_gV_g^\top$，直接优化 $R = V_g^\top Q_r \in \text{St}(b,k)$，计算量减少约 $b/k$ 倍 |
| **GCV 奇异值缩放** | 逐层自动选择正则化强度 | 正则化缩放 $s_{g,i}(\lambda) = (\rho_i + \lambda s^*\sigma_i)/(e_i + \lambda)$，通过广义交叉验证（GCV）在 120 点对数网格上逐层选 $\lambda$ |
| **Gram 谱温控** | 减少高能量激活方向的主导 | 对校准 Gram 矩阵 $G = E\,\text{diag}(\mu_i)E^\top$ 施加谱指数 $\alpha$（默认 0.9），压缩谱动态范围 |
| **锚定跨层对齐惩罚** | 保持相邻注意力投影间的几何关系 | 比较投影算子 $\Pi_{r_p}(R)$ 与锚定投影器 $\Pi_{\text{anchor}}$ 的差异，仅作用于注意力输出投影，$\lambda_a = 50$ |

### 2.4 损失函数

所有组件仅依赖校准集的二阶统计量（单次前向传播累积）：

$$\mathcal{L}(\tilde{W}, Q_r) = \frac{\|Y - \tilde{W}X_K\|_F^2}{\|Y\|_F^2} + \lambda_a \mathcal{A}(Q_r)$$

无需通过 LLM 反向传播，也无需重训练模型参数。

## 6. 论文的主要结论与发现

1. **COEC 在困惑度上全面胜出**：30% 稀疏度下，在 Wanda-sp、FLAP、RCPU 三种选择准则下，COEC 均在所有 6 个主模型上取得更低困惑度；最大收益为 Qwen2.5-32B（13.90→9.64）。
2. **零样本准确率多数提升**：在大多数设置和模型上优于现有补偿方法，高稀疏度下增益更大。
3. **高稀疏度下收益更明显**：对 RCPU 的平均困惑度差距从 10% 稀疏度的 0.06 扩大到 30% 的 0.25，说明剪枝越重，补偿越有价值。
4. **双侧重构优于单侧**：消融显示，"收敛的双侧旋转"将困惑度从 10.06 降至 9.45，是最大的单一贡献项；几何分析确认剪枝平均旋转输入方向约 22°，而现有方法未恢复这一旋转。
5. **补偿与剪枝准则正交**：COEC 可附加在任何列选择规则之后，无需逐准则调参。
6. **校准集规模稳健**：即使 N=32 也明显优于无补偿基线，且随 N 增大单调改善；更大的参数空间因 GCV 正则化而非过拟合。
7. **几何关系验证**：剪枝后补偿可将对齐惩罚中位数降低 7.2 倍，层内输入-输出框架的配对一致性保持在 1.1–1.2% 的差异内。

## 7. 优点

- **方法设计新颖且完备**：将补偿从单侧旋转推广到双侧旋转 + 逐模式缩放，首次将 GCV 引入剪枝补偿的逐层正则化选择；约化 Stiefel 求解器有效降低优化开销。
- **免训练、即插即用**：仅用二阶统计量、128 条校准序列，无需反向传播或重训练，可附加在任何结构化剪枝方法之后。
- **与剪枝准则解耦**：验证了三种独立选择准则下的有效性，证明补偿的通用性。
- **实验设计严谨**：统一协议、共享校准数据、隔离变量（选同一选择分数比较不同补偿），消融实验逐组件量化贡献。
- **可解释性分析**：通过几何测量（主角度、投影算子）从机制层面解释了"为什么双侧旋转有效"，增强了方法的可信度。
- **透明性**：附录详细说明数值防护（SVD 看门狗、步长封顶、阻尼带）、超参数选择、随机种子影响。

## 8. 不足与局限

- **计算开销**：补偿 7–8B 模型需 45–86 GPU 分钟（单卡 B300），随模型规模增长更甚（文中未报告 70B 级别的具体补偿时间）；虽然免训练，但相比无补偿的剪枝方法仍是显著额外成本。
- **FLAP 偏置在低稀疏度下仍具竞争力**：10–20% 稀疏度下，FLAP 偏置在部分模型上困惑度更优；COEC 的优势主要体现在足够高的剪枝率上。
- **零样本准确率的提升不够稳定**：个别模型（如 Qwen2.5-14B）上 RCPU 的准确率反超 COEC；部分附加模型（如 Llama-2-13B 30%、Llama-2-70B 20%）的准确率出现下降。
- **校准集仅使用 WikiText-2**：未测试其他校准数据分布（如域外数据）对补偿效果的影响；校准分布与评估分布不一致时的稳健性未知。
- **评估任务覆盖有限**：仅 7 个下游任务 + 困惑度，缺少对话质量、代码生成、多语言或开放域生成等更全面的能力评估。
- **补偿与选择准则的交互未完全建模**：论文表明补偿独立于列选择，但未深入分析补偿是否可以反过来影响最优选择策略（例如联合优化）。
