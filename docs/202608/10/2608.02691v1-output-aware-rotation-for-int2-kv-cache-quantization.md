## 摘要
键值缓存已成为长上下文大语言模型推理中的主要内存和带宽瓶颈，这使得超低位量化愈发重要。然而，现有的基于旋转的INT2方法在完整的注意力读出之前优化缓存统计或代理误差，尽管模型最终受到通过注意力和输出投影W_O传播的误差影响。为解决这一不匹配，我们提出OptR，一种输出感知的旋转方法，最小化经过W_O后的注意力输出误差。OptR将经过W_O后的注意力输出误差分解为键引发和值引发的项，并通过完整的INT2量化和注意力路径学习每头的正交校正。OptR进一步应用注意力等价的键重参数化，以在不改变softmax分布的情况下减少大的逐通道偏移。在三个模型和五个推理与编码基准上，OptR一致改进了QuaRot和OSCAR，并增强了长上下文检索，同时以可忽略的推理开销保持了分页KV缓存格式。

## Abstract
The key-value (KV) cache has become a major memory and bandwidth bottleneck in long-context large language model inference, making ultra-low-bit quantization increasingly important. However, existing rotation-based INT2 methods optimize cache statistics or proxy errors before the complete attention readout, even though the model is ultimately affected by the error propagated through attention and the output projection $W_O$. To address this mismatch, we propose \textit{OptR}, an output-aware rotation method that minimizes post-$W_O$ attention-output error. OptR decomposes the post-$W_O$ attention-output error into key- and value-induced terms and learns per-head orthogonal corrections through the full INT2 quantization and attention path. OptR further applies an attention-equivalent key reparameterization to reduce large channel-wise offsets without changing the softmax distribution. Across three models and five reasoning and coding benchmarks, OptR consistently improves both QuaRot and OSCAR and strengthens long-context retrieval, while preserving the paged KV-cache format with negligible inference overhead.

## 1. 核心问题与研究动机

- **背景**：随着大语言模型（LLM）规模和上下文长度不断增长，键值（KV）缓存已成为长上下文推理的主要内存和带宽瓶颈。在自回归解码中，每个 token 生成时都需要读取全部历史 KV 缓存，因此缓存大小直接限制了可支持的上下文长度和批处理规模。
- **INT2 量化的必要性**：INT2 仅需 BF16 缓存的 1/8 存储和 INT4 的一半，能在相同内存预算下支持更长上下文或更大批处理。但由于 INT2 仅有 4 个量化级别，异常值会显著扩大量化范围，导致多数值的舍入误差急剧增大。
- **现有方法的缺陷**：基于旋转的 INT2 量化方法（如 QuaRot、RotateKV、OSCAR）虽然通过正交变换使缓存更易量化，但它们选择旋转矩阵时要么采用固定变换，要么基于缓存统计或"完整注意力读出之前"的代理误差目标进行优化。这些代理目标**并未直接衡量传递给后续层的真实误差**——KV 量化改变注意力读出后，输出投影矩阵 W_O 会将此变化映射到模型隐藏空间，误差沿残差流传播并影响最终预测。因此，最能重建 KV 缓存原始值的旋转，并不一定是能最好保留 post-W_O 输出（即注意力输出经输出投影后进入残差流的值）的旋转，存在**目标错配**问题。
- **核心问题**：如何在 INT2 KV 缓存量化中，直接针对"注意力读出→W_O 投影"之后的真实输出误差来优化旋转矩阵？

## 2. 方法论：OptR（输出感知旋转）

### 2.1 核心思想

将 INT2 KV 量化视为**输出空间优化问题**，而非缓存重建问题。具体而言，OptR 将 post-W_O 注意力输出误差精确分解为两个部分：
- **键引发误差（key-induced）**：键量化改变注意力分布（softmax 权重），导致注意力加权求和结果偏离 BF16；
- **值引发误差（value-induced）**：值量化在注意力加权聚合后直接引入误差。

两个误差项均经 W_O 投影到模型隐藏空间，构成最终输出误差。OptR 的优化目标即最小化该 post-W_O 总误差。

### 2.2 关键技术细节

**（1）注意力等价的键重参数化**

- 对键执行逐通道的均值减除：先计算校准数据中每个通道的 key 均值 μ，量化前对键执行 `(k − μ)` 的平移。
- 关键性质：对所有 cached token 减去同一 μ，相当于给所有 logits 加上一个仅依赖 query 的常数，由于 softmax 的平移不变性，**注意力分布完全不变**（为注意力等价变换）。
- 该操作显著缩小了 INT2 分组的动态范围，从而减少量化误差。值不做此操作，因为平移值会直接改变注意力输出。

**（2）每头正交旋转校正（Orthogonal Rotation Refinement）**

- 对任意基础旋转初始化 $R^0_K, R^0_V \in O(d)$（如 QuaRot 的 Hadamard 旋转或 OSCAR 的协方差旋转），OptR 学习**每 KV 头独立的**正交校正。
- 参数化方式：学习无约束矩阵 A，构造反对称生成器 $S = A - A^\top$，校正旋转定义为 $R = R^0 \exp(S)$；由于反对称矩阵的矩阵指数必为正交矩阵，校正旋转始终保持在正交流形上。
- 通过完整的前向传播路径（旋转 → 裁剪 → 分组 → INT2 舍入 → 反量化 → 逆旋转 → 注意力 → W_O 投影）进行端到端优化。
- **优化顺序**：先优化键旋转（因为键决定注意力分布），再在选定键旋转的注意力分布下优化值旋转。

**（3）损失函数**

- 键校准损失：
  $$
  L_K = \mathbb{E}_{(t,j)} \left[ D_{KL}(p_t \| p^K_t) + \lambda_K \frac{\|e^K(t,j)\|^2_2}{d_{model}} \right]
  $$
  包含 KL 散度项（保持注意力分布与 BF16 一致）和 post-W_O 键引发输出误差项。

- 值校准损失：
  $$
  L_V = \mathbb{E}_{(t,j)} \left[ \frac{\|e^V(t,j)\|^2_2}{d_{model}} \right]
  $$
  直接衡量值量化经注意力加权和 W_O 投影后的输出误差。

**（4）可微性处理**

INT2 舍入不可微，采用直通估计器（STE）：$\partial Q_2(Z)/\partial Z \approx \mathbb{1}\{|Z| \le \tau_c\}$，梯度仅回传到裁剪阈值内的元素。

**（5）部署等价实现**

- 键路径：实际存储旋转后的量化键 $k_{R,s}$，将旋转矩阵 R_K 应用到 post-RoPE query 上（而非对每个反量化键显式乘以 $R_K^\top$），两者数学等价。
- 键均值减除重写为 $(k-\mu)R = kR - \mu R$，μR 可离线预计算，推理时只需一次减法。
- 值路径：$\tilde{W}_V = R_V^\top W_V$，$\tilde{W}_{O,j} = W_{O,j} R_V$，将值旋转和逆旋转分别融合进值投影和 W_O 的权重矩阵中，**无需单独的旋转内核**。
- 全程保持分页 KV 缓存和融合解码内核的兼容性。

## 6. 主要结论与发现

1. **精度大幅提升**：以 Qwen3-8B 为例，AIME25 上 QuaRot-INT2 从 17.33% 提升至 QuaRot+OptR 的 66.67%；OSCAR 从 54.67% 提升至 OSCAR+OptR 的 66.00%，逼近 BF16 的 68.00%。Qwen3-4B 上 QuaRot 从 0% 跃升到 60%+。
2. **长上下文优势更显著**：上下文越长，OptR 的增益越大（如 Qwen3-4B 在 64K 时 OSCAR+OptR 为 69.58% vs OSCAR 为 55.72%），说明其对累积量化误差的抑制持续有效。
3. **误差确实降低**：OptR 同时减少 post-WO 输出误差和传播的残差流误差，且收益分布广泛（多数层和 KV 头均受益，而非少数异常头）。
4. **目标选择至关重要**：post-WO 输出误差目标（70.67%）优于 pre-WO 注意力读出目标（62.67%），远优于原始缓存重建目标（65.33%），验证了"输出空间优化"思路的正确性。
5. **开销可忽略**：OptR 在解码延迟、端到端吞吐量和预填充时间上与基础管线差距不超过 2%，内存增加仅约 18 MiB。

## 7. 优点与亮点

- **方法论层面**：
  - 首次将"post-WO 注意力输出误差"这一真实端到端影响作为量化旋转的优化目标，直接解决现有方法的目标错配问题；
  - 严格的理论分解（键引发/值引发误差）使优化路径清晰，且键、值分步优化的顺序设计符合注意力机制因果依赖；
  - 注意力等价的键重参数化是一个巧妙且几乎零成本的改进——理论保证不改变 softmax 却显著缩小量化动态范围；
  - 基于反对称矩阵指数参数化保证旋转的正交性，且可适用于任何基础旋转初始化，普适性强。
- **工程层面**：
  - 将旋转和键均值放入 Triton 缓存写入内核，避免额外内核启动；
  - 将值旋转融合进投影权重矩阵（$W_V$ 和 $W_O$），数学上完全等价但省去单独的值旋转操作；
  - 保持分页 KV 缓存、前缀缓存等现有系统兼容性，无需变更缓存布局；
  - 通过旋转 query 而非反旋转键的方式匹配 GQA 的每头键旋转，实现高效推理。

## 8. 不足与局限

- **校准数据来源问题**：校准数据来自 GPQA-Diamond 评估集的提示（提示本身来自评估池，文中表示使用不与验证重叠的 chunk），尽管不使用答案标签且训练/验证分离，仍存在评估集提示泄漏的潜在风险，可能使 GPQA 结果略微乐观。
- **超参敏感性**：λK 的最佳值依赖基础旋转（OSCAR 为 1，QuaRot 为 10），论文为统一性取 1.0，但用户若使用不同旋转初始化可能需要重新调参，缺乏自适应机制。
- **模型覆盖有限**：仅 3 个模型（两个同族、一个跨族），且规模上限为 14B，缺乏更大规模（如 70B+）模型或 MoE 架构的验证；也未覆盖商用 API 模型。
- **TurboQuant 比较不完整**：TurboQuant 因实现开销仅报告单次运行，且其 BPE（3.25）高于旋转方法（2.32），比较时带宽/精度权衡口径不完全一致。
- **量化精度仍有差距**：即便 OptR 大幅提升，在部分基准上仍未完全达到 BF16（如 Phi4-14B 的 AIME25 为 58.00% vs BF16 60.67%；长上下文 128K 时仍有明显衰减），INT2 固有极限尚未完全克服。
- **Sink/Recent 窗口依赖**：方法依赖 64+256 个 BF16 保留 token，对极端长上下文中这些窗口内的键偏移处理依赖精度，且未对不同窗口大小做系统消融。
- **可选性讨论较少**：论文未深入讨论 OptR 在非长上下文（短上下文、小 batch）场景下的收益与开销权衡，也未对比其他非旋转型量化方法（如 KVQuant、KIVI）在同口径下的表现。
