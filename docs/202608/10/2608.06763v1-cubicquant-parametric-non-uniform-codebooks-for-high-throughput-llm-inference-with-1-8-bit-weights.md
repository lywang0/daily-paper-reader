## 摘要
权重量化用于大语言模型推理时，必须平衡自适应重构级别与足够规则的表示，以实现高效的GPU执行。均匀整数将每个组约束为线性网格。低位浮点格式使用固定的指数-尾数结构，而学习型码本以不规则解码和额外元数据为代价获得灵活性。我们提出CubicQuant，一种参数化非均匀标量格式，在保持密集整数码流的同时，在每个权重组内自适应重构级别。一条由两个形状参数和一个尺度指定的单调三次曲线，将均匀间隔的幅度码映射到非均匀级别。该系列涵盖1-8位权重负载，包含对称均匀整数量化作为精确特例，对于负载宽度B和组大小G，有效宽度为B + 64/G位每权重。我们推导了在均匀、高斯和拉普拉斯分布下的群体失真，制定了连续和动态A8载波感知拟合目标，并描述了直接的打包权重GPU执行。对于G=128的有限组，每组15,360个样本，相对于最优裁剪的四位均匀整数量化，W4 CubicQuant在均匀样本上降低了3.90%的重构RMSE，在高斯样本上降低了13.49%，在拉普拉斯样本上降低了28.14%。相对于最优枚举的四位有限浮点格式，降低幅度分别为3.90%、9.44%和6.27%。初步H200内核测量显示一个依赖工作负载的交叉点：对于窄GEMV，模型dtype执行更快，而随着行数增长，动态A8变得有利。结果确立了该格式的表示能力和直接可执行性；下游模型质量和跨设备端到端性能仍是待评估的问题。

## Abstract
Weight quantization for large-language-model inference must balance adaptive reconstruction levels with representations regular enough for efficient GPU execution. Uniform integers constrain each group to a linear grid. Low-bit floating-point formats use a fixed exponent-mantissa structure, while learned codebooks gain flexibility at the cost of irregular decoding and additional metadata.   We introduce CubicQuant, a parametric non-uniform scalar format that preserves a dense integer code stream while adapting reconstruction levels within each weight group. A monotonic cubic curve, specified by two shape parameters and one scale, maps uniformly spaced magnitude codes to non-uniform levels. The family spans 1-8-bit weight payloads, contains symmetric uniform integer quantization as an exact special case, and has effective width B + 64/G bits per weight for payload width B and group size G. We derive population distortion under Uniform, Gaussian, and Laplace distributions, formulate continuous and Dynamic-A8-carrier-aware fitting objectives, and describe direct packed-weight GPU execution.   For finite groups of G=128 with 15,360 samples per distribution, W4 CubicQuant reduced reconstruction RMSE relative to optimally clipped four-bit uniform integer quantization by 3.90% on Uniform, 13.49% on Gaussian, and 28.14% on Laplace samples. Relative to the best enumerated four-bit finite floating-point format, the reductions were 3.90%, 9.44%, and 6.27%. Preliminary H200 kernel measurements show a workload-dependent crossover: model-dtype execution is faster for narrow GEMV, while Dynamic A8 becomes favorable as row count grows. The results establish the format's representational promise and direct executability; downstream model quality and cross-device end-to-end performance remain open evaluation questions.

## 1. 核心问题与整体含义（研究动机与背景）

大语言模型（LLM）推理需要反复将权重矩阵从 GPU 内存流式加载，降低权重存储宽度可直接缓解显存容量和带宽压力，尤其在权重复用有限的解码（decode）场景。然而，现有量化格式在**自适应重构能力**与**规则化 GPU 执行**之间难以两全：

| 格式类型 | 优点 | 局限 |
|---------|------|------|
| 均匀整数（Uniform Integer） | 打包紧凑、算术规则、硬件友好 | 每个权重组被限制在仿射线性网格，无法适应强变化的局部权重统计 |
| 低位浮点格式（如 FP8） | 通过固定指数-尾数结构分配动态范围 | 灵活性受限于预设结构，无法完全匹配数据分布 |
| 学习型码本（Learned Codebooks） | 可自由调整所有重构级别 | 解码不规则、元数据开销大、与常规 GPU 点积路径不自然对齐 |
| 向量/加法码本 | 表达空间更大 | 将解码问题从标量重构变为结构化查找，复杂度高 |

**CubicQuant 的定位**：在固定网格与自由码本之间取折中——保留标量整数码流和规则打包格式，但让重构级别具有参数化的自适应性。其核心思想是：用**单调三次曲线**将均匀间隔的幅度码映射为非均匀重构级别，每个权重组拥有自己的曲线（由两个形状参数和一个尺度定义），兼顾表达力与执行效率。

## 2. 方法论：核心思想、关键技术细节

### 2.1 代码空间设计

- **B ∈ {1,…,8}** 为负载位宽。对 B > 1，定义 M = 2^(B−1) − 1，码值 k ∈ {−M, …, 0, …, M}，共 2^B − 1 个有效值。
- 保留二进制补码中最负模式（−2^(B−1)），解码时确定性地映射为**精确零**。
- W1 为独立二值情形，码值仅 {−1, +1}。
- 打包码流按行主序连续存储；W3/W5/W6/W7 等宽度不整除 8 时，支持跨字节解码。

### 2.2 参数化级别函数（核心创新）

重构公式为：

```
ŵ(k) = sign(k) · s · q(t_k)
其中 t_k = |k|/M, q(t) = t[a + t(b + ct)], c = 1 − a − b
```

- **s**：正组尺度（FP32），决定端点幅度（±s 精确重构）。
- **a、b**：两个形状系数（FP16 存储），控制内部重构级别的分布。a = q′(0) 为初始斜率，b = q″(0)/2 为初始曲率的一半。
- **c**：派生系数（不存储），保证 q(1) = 1。
- **单调性约束**：q′(t) = a + 2bt + 3(1−a−b)t² > 0（t∈[0,1]），防止级别反转；可通过二次函数最小值解析判定。

**关键性质**：对称均匀整数量化是 CubicQuant 族的**精确特例**（a=1, b=0 时 q(t)=t），因此搜索时总能保证不劣于均匀整数（在元数据舍入前）。

### 2.3 元数据与有效宽度

- 组形状为 [1, G]：每个输出行独立划分为 G 个输入通道为一组。
- 每组存储：GB 位负载 + 一个 FP32 尺度 s + 两个 FP16 形状系数 a、b = 8 字节元数据。
- **有效存储宽度**：B_eff = B + 64/G (bits/weight)。

对比：
- 对称分组 INT：B + 16/G
- 2D 块缩放 FP8：8 + 32/G²

### 2.4 失真理论分析

- 推导了**精确的解析失真表达式** D(s, a, b)，基于 Voronoi 边界与单元矩（cell moments）。
- 证明了集合嵌套关系：**均匀整数 ⊂ Cubic ⊂ 自由码本（Lloyd-Max）**，从而三者失真满足：D_LM ≤ D_C ≤ D_INT。
- 均匀分布下，均匀整数即人口最优（三者相等）；高斯和拉普拉斯下，Cubic 可恢复 84.8%–96.9% 的 INT-LM 差距（W4–W8）。
- W3 时 Cubic 恰好有 3 个自由度匹配 3 个正电平，因此**达到 Lloyd-Max 下界**。
- 解析失真经 200 万样本 Monte Carlo 验证，最大偏差仅 2.10 个标准误。

### 2.5 拟合目标

- **连续参考目标**（模型 dtype 路径）：最小化原始域 MSE，遍历单调 (a, b) 候选，联合优化尺度与裁剪。
- **Dynamic-A8 载波感知目标**：将归一化 Cubic 电平映射到 INT8 载波（r(k) = round(127·sign(k)·q(|k|/M))），联合优化目标为 L_joint = ½L_C + ½L_A8，即对连续重构和 A8 重构误差**等权平均**。该目标使同一份 checkpoint 可同时服务两种执行路径。

### 2.6 GPU 执行实现

- **融合解码-计算原则**：输出 tile 仅加载打包负载和组元数据，在 kernel 内部生成模型 dtype 或 INT8 操作数并立即用于点积，避免物化完整精度张量。
- **模型 dtype 路径**：接受 FP16/BF16 激活，重构连续 Cubic 值，FP32 元数据算术 + tl.dot。
- **Dynamic-A8 路径**：激活按行动态量化到 INT8（round-away-from-zero），权重通过 INT8 载波参与 DP4A 风格整数点积，INT32 部分和累加，最终按组用 (d_x·s_g)/127 缩放到 FP32。
- **内核选择**：根据 (B, G, M, N, K)、激活 dtype、路由拓扑、GPU 架构等，在窄行 GEMV 与二维稠密内核间确定性选择。

## 6. 主要结论与发现

1. **表示优势**：W4 下，CubicQuant 相比最优裁剪均匀整数，NRMSE 降低：均匀 3.90%、高斯 13.49%、拉普拉斯 28.14%；相比最优有限浮点：均匀 3.90%、高斯 9.44%、拉普拉斯 6.27%。
2. **理论定位**：Cubic 族是均匀整数与自由 Lloyd-Max 码本之间的“中间层”，恢复了两者差距的 84.8%–96.9%（高斯、拉普拉斯、W4–W8）。
3. **W3 达到 Lloyd-Max**：参数数量恰好匹配自由度，理论等价。
4. **两种执行路径**：model-dtype（A16）和 Dynamic-A8 均从同一打包表示直接执行，拟合目标可同时优化两者。
5. **内核交叉点**：M=1 时 A16 更快；M≥16 后 A8 普遍更快（2.2×–4.5× 于 A16 在某些配置下），交叉点依赖位宽和形状。
6. **负面发现**：持久化 INT8 激活载体反而变慢（0.78×–0.94×），因此 Dynamic-A8 定位为算子局部计算模式，而非全整数图。
7. **端到端结论保持克制**：论文不做任何端到端加速比/功耗声明，仅断言格式的表示能力和可执行性。

## 7. 优点

1. **理论-实验闭环**：从解析失真推导 → 人口最优求解 → 有限组模拟 → 实际 GPU kernel，逻辑链条完整。
2. **格式设计优雅**：单调三次曲线以极简元数据（每组合计 8 字节）实现了组级自适应；均匀整数是精确特例，向下兼容性强。

- **硬件验证单一**：仅 H200（Hopper），Ampere/Ada/Blackwell 仅有编译覆盖而无性能数据。

### 8.2 偏差风险

- **参考分布理想化**：均匀/高斯/拉普拉斯不一定是真实 LLM 权重的分布，有限组收益可能不具普适性。
- **MSE 非模型感知**：权重 MSE 最小不代表输出误差最小；未使用 Hessian 或激活统计信息。
- **无消融**：未对比“连续目标拟合 vs 联合目标拟合”在 A8 路径上的实际差异；未量化 FP16 形状系数舍入的影响幅度。

### 8.3 系统级限制

- **不是原生 Tensor Core 类型**：打包码必须被重构为模型 dtype 或 INT8 载波才能参与矩阵乘法；带宽收益依赖融合解码，否则可能被抵消。
- **无端到端系统验证**：未在完整 vLLM 服务场景下测量吞吐、延迟、功耗。
- **激活路径非持久化**：Dynamic-A8 动态量化激活有运行时开销，且已证明持久载体方案不可行（在当前实现下）。

### 8.4 应用限制

- **动态量化的边界**：CubicQuant 仅覆盖权重侧；激活量化误差传播未被建模。
- **元数据-局部性权衡**：小 G 提升适应性但增加元数据；大 G 摊销元数据但降低粒度；论文未给出最优 G 的结论。
- **长上下文、KV 量化**：完全在论文范围之外。

## 总体评价

CubicQuant 在**权重表示设计**上具有理论优雅性和实际创新性——用极简参数集弥合了“固定网格”与“自由码本”之间的鸿沟，并且其理论分析（人口失真 + 有限组适应）与初步系统证据（H200 kernel 交叉点）相互支撑。然而，作为一篇技术报告，其证据体系**不足以**断言实际部署优势：缺乏下游任务质量、跨架构性能、系统级端到端吞吐三大关键证据。该工作更适合视为**有前景的格式提案 + 配套理论分析**，而非已充分验证的工程方案。
