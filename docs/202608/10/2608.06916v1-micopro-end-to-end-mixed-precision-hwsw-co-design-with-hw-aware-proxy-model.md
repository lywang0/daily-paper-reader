## 摘要
量化神经网络（QNN）采用低位宽数据在边缘设备上实现高效存储和计算方面已展现出巨大潜力。为在最大化加速的同时减轻精度下降，逐层混合精度量化（MPQ）成为一种流行方案。然而，现有探索MPQ方案的算法在灵活性和效率上存在局限。理解不同MPQ方案对训练后量化和量化感知训练结果的复杂影响，对传统方法来说是一大挑战。此外，现有工作中缺乏用于MPQ模型优化与部署的端到端框架。为应对这些挑战，我们提出了MiCo框架，这是一个面向边缘AI应用的整体MPQ探索与部署框架。该框架采用一种新颖的优化算法，在严格的延迟约束下搜索精度最优的量化配置。我们进一步将框架扩展为MiCoPro，引入稳健的硬件感知代理（HAP）模型以提升预测准确性和硬件通用性。通过利用目标特定的延迟建模，MiCoPro实现了从PyTorch模型到裸机C代码的快速探索与直接部署。我们在BitFusion加速器和支持SIMD扩展的RISC-V处理器上展示了该框架的通用性，实现了高达40%的延迟降低，同时精度下降不到3%。

## Abstract
Quantized Neural Networks~(QNN) with low-bitwidth data have proven promising in efficient storage and computation on edge devices. To mitigate accuracy degradation while maximizing speedup, layer-wise mixed-precision quantization~(MPQ) becomes a popular solution. However, existing algorithms for exploring MPQ schemes are limited in flexibility and efficiency. Comprehending the complex impacts of different MPQ schemes on post-training quantization and quantization-aware training results is a challenge for conventional methods. Furthermore, an end-to-end framework for the optimization and deployment of MPQ models is missing in existing work.   To address these challenges, we propose the MiCo framework, a holistic MPQ exploration and deployment framework for edge AI applications. The framework adopts a novel optimization algorithm to search for accuracy-optimal quantization configurations under strict latency constraints. We further extended the framework to MiCoPro, which introduces a robust Hardware-Aware Proxy (HAP) model to enhance prediction accuracy and hardware versatility. By leveraging target-specific latency modeling, MiCoPro enables rapid exploration and direct deployment from PyTorch models to bare-metal C code. We demonstrate the versatility of our framework on both the BitFusion accelerator and SIMD-extended RISC-V processors, achieving up to 40\% of latency reduction with less than 3\% of accuracy drop.

## 2. 论文提出的方法论

### 2.1 MiCo：MPQ 搜索框架

- **问题建模**：将 MPQ 探索形式化为约束优化问题——在硬件成本（延迟/BOPs/模型大小）约束下最大化模型精度，采用黑盒优化的思路。
- **精度预测器**：采用**随机森林（Random Forest）集成模型**作为精度代理，输入为逐层位宽特征（`bw_i`, `ba_i`）及层 MAC 数，输出为预测精度。相比高斯过程（扩展性差）和强化学习（样本效率低），RF 在有限样本下能建模复杂的非线性位宽交互。
- **逐层正交初始采样**（算法 2）：
  - 强制纳入全最高位宽（如 W8A8）和全最低位宽（如 W1A1）两个极端方案；
  - 其余初始样本随机选取若干**互不重叠的层**进行量化，保证每层在初始样本中至少被量化一次，高效捕获逐层敏感性信息。
- **近约束采样 NCS**（算法 3）：
  - 核心洞察：精度通常随硬件预算增加而提升，最优解大概率落在约束边界附近；因此将搜索集中在约束附近的 ROI（初始 `[0.8×C, C]`，后期放宽至 `[0.5×C, C]`）；
  - 使用遗传算法（交叉+变异）在 ROI 内生成候选方案，按到 ROI 的距离筛选；
  - 保留"首尾层高位宽"启发式以增强实用性。
- **评估策略（PTQ/QAT 分流）**：
  - 实验发现低位宽（<4bit）下 PTQ 与 QAT 精度差距显著（图 1），因此 ≥4bit 方案用 PTQ 快速评估；<4bit 方案采用短 QAT（约预训练时间的 1/20）评估，最终选出的最优方案再延长重训练（约预训练时间的 1/10）。

### 2.2 MiCoPro：硬件感知代理（HAP）模型

- **动机**：BOPs 与实际硬件延迟相关性差（图 2，R² 仅 0.35-0.55），无法指导硬件感知搜索。
- **核心理念**：将硬件成本度量从"一个数"分解为反映底层硬件机制的多维特征。
- **CBOPs（Composite Bit Operations）特征集**：
  - `BMACs = max(bw, ba) × MACs`：反映 MAC 单元的计算宽度瓶颈（窄操作数通常被扩展到宽数据路径）；
  - `ALoads = ba × MACs`：独立刻画激活访存流量；
  - `WLoads = bw × MACs`：独立刻画权重访存流量；
  - 相比 BOPs（`bw × ba × MACs`），CBOPs 区分了计算与访存的非对称影响。
- **完整核特征（Full Features）**：在 nn-Meter 特征基础上增加 `bw_i`、`ba_i`、`⌊32/bw⌋`（子字打包效率）、`⌊32/ba⌋` 及非对称精度指示符，配合非线性回归器（RF/XGB）实现最高精度预测。
- **网络级 Min-Max 校准**：对全最低精度和全最高精度网络分别获取实际硬件延迟与代理预测值，通过线性变换（α、β）消除非计算开销（如 im2col、量化/反量化）的系统性偏差。
- **跨硬件迁移学习**：对架构相似的新硬件（如不同配置的 RISC-V 变体），在已有代理模型基础上只拟合残差 `δt(x)`，仅需 5% 数据即可获得高精度预测，将 profiling 时间从 27 小时降至约 2 小时。

### 2.3 端到端部署流程

- 从 PyTorch 模型提取 FX 图，根据目标硬件分流：
  - **BitFusion**：FX 图转换为 DnnWeaver 算子图，在 BitFusion 模拟器上部署；
  - **RISC-V CPU / 主机**：通过 C 代码生成器将 FX 图映射到扩展的裸机核函数库（支持 8/4/2/1-bit 的 MatMul、Conv2D、SIMD 加速及打包/解包函数），编译为可在目标上运行的 bare-metal C 程序。

## 6. 论文的主要结论与发现

1. **PTQ/QAT 分界点**：位宽 ≥4bit 时 PTQ 与 QAT 精度差距小；<4bit 时差距显著，"先 PTQ 快速筛选、后 QAT 精修"的分流策略可行性得到验证。
2. **RF+NCS 搜索高效性**：在相同样本预算下，MiCo 在绝大多数模型和约束下优于 w-based、HAQ、BOMP 和 HAWQ-V3；SqueezeNet 搜索轨迹显示 MiCo 在第 2 次迭代即超过 NLP 方法的最终精度，HAQ 需要额外 59 个样本才能达到同等精度（耗时是 MiCo 的 1.84 倍）。
3. **BOPs 的局限被证实**：BOPs 与真实延迟相关性弱（R² < 0.55），仅用 BOPs 约束搜索会导致实际延迟远超约束；例如 BitFusion 上设定 0.6× 约束时，BOPs 引导的搜索实际只达到 0.72×，而 HAP 引导达到 0.58–0.60×。
4. **CBOPs 与完整特征显著优于 BOPs**：CBOPs + 线性回归将 MAPE 从 18.02% 降至 6.50%、R² 从 0.38 提升至 0.84；完整特征 + 非线性模型进一步将 MAPE 降至 3-4%；BOPs 在所有 VexiiMiCo 变体上产生负的 R² 值，完全无法作为延迟代理。
5. **迁移学习有效**：仅用 5% 新数据即可将 R² 从负值提升至 0.65–0.93，大幅降低新硬件的 profiling 成本。
6. **端到端加速效果**：在 BitFusion 上实现最高 40% 延迟降低（ResNet-18：0.58×），VexiiMiCo 各配置下达到 0.78–0.85×，精度损失大多在 1% 以内。

## 7. 优点

1. **端到端完整性**：罕见的"搜索 → 建模 → 部署"全覆盖框架，从 PyTorch 模型自动生成裸机 C 代码，具备实际应用价值。
2. **硬件感知的成本建模**：提出的 CBOPs 特征分解（BMACs/ALoads/WLoads）简单有效，揭示了计算宽度 vs 访存流量的非对称影响；min-max 校准方法轻量且实用。
3. **搜索策略设计精巧**：
   - 正交初始采样捕捉逐层敏感性的效率远高于纯随机采样；
   - 近约束采样利用了精度-预算关系中的单调性先验，大幅缩小搜索空间；
   - PTQ/QAT 分流评估在保证精度的同时控制了搜索成本。
4. **迁移学习设计合理**：利用相似架构间延迟分布的一致性，将新硬件 profiling 开销降低一个数量级，提升了框架的可扩展性。
5. **实验对比公平**：与学习类方法设置相同样本预算、多随机种子取平均；消融实验逐步验证了各组件的贡献。

3. **低位宽的精度风险**：1-bit/2-bit 方案严重依赖 QAT，而短 QAT 只是对完整 QAT 的近似，可能低估或高估最终精度，导致搜索选出次优方案；且极低位宽下激活和权重的量化噪声很大，对语音、语言等敏感任务可能造成不可接受的精度损失。论文也未讨论混合精度中符号位、缩放因子等额外参数对实际存储和计算开销的影响。
4. **硬件成本模型的简化**：CBOPs 和完整核特征虽然比 BOPs 更贴近硬件，但主要刻画了计算与访存开销，未包含能耗、编译调度开销、缓存命中率、多核通信等实际芯片上的关键因素。Min-max 校准仅处理了系统性偏差，无法覆盖不同层形状导致的非线性交互。
5. **迁移学习的适用边界**：跨硬件迁移仅在 VexiiMiCo 同一微架构族内验证，未测试跨指令集（如 ARM vs RISC-V）、跨数据流架构（如 SIMD vs 脉动阵列）的迁移效果。若异构程度高，残差拟合可能失效，仍需完整的 profiling。
6. **搜索过程的可复现性**：遗传算法和随机采样存在随机性，论文虽报告多种子平均结果，但未给出方差、置信区间或失败案例；RF 预测器的模型方差也未报告，可能掩盖极端情况下的性能波动。
7. **规模扩展性问题**：逐层位宽特征在高层次数（如 100+ 层）下输入维度增大，RF 的训练和推理开销随之上升；近约束采样在高维空间中可能变得稀疏，遗传算法的收敛速度可能显著下降，论文未对超过 ResNet-34 规模的模型进行验证。

## 9. 总体评价与展望

论文提出了 MiCo/MiCoPro 这一完整的混合精度量化框架，将 **MPQ 搜索 → 硬件延迟建模 → 端到端部署** 三者打通，是少见的系统级解决方案。核心创新在于：

- 用**正交初始采样 + 近约束采样**高效引导搜索，用 **PTQ/QAT 分流**平衡效率与精度；
- 将硬件成本从 BOPs 这种单值指标升级为 **CBOPs / 多维核特征**，并借助**迁移学习**大幅降低新硬件的 profiling 成本；
- 实验覆盖视觉、音频、语言等多种任务和多种硬件模拟器，展示了较强的泛化能力。

但作为学术成果，其验证局限于模拟器，资源披露不足，对低位宽场景的鲁棒性和大规模模型的扩展性还有待加强。未来工作可以在真实芯片上验证能耗与延迟、引入更细粒度的量化方案（如通道级、混合精度激活重计算），以及探索适用于大语言模型的高效搜索算法，以进一步推动边缘 AI 的软硬件协同设计落地。
