## 摘要
在智能体时代，大语言模型（LLM）越来越多地读取长输入，从整份文档和代码库到多轮对话。它们的推理内存主要被键值（KV）缓存占据，即模型已读取和生成的每个令牌的注意力键和值。由于缓存随上下文长度增长，并且在生成每个令牌时都会被完整重读，因此更长的上下文意味着更多的GPU内存。为了降低这一成本，大多数现有方法通过将每个存储值降低到相同的低精度来压缩KV缓存，这种技术称为量化。它们可以将此推到每个值接近2比特，但很难进一步，因为在此2比特悬崖处质量急剧下降：四个级别对于缓存中异常值密集的值来说太少，其中少数较大的条目消耗了这些级别，并将其余条目压成噪声。一个自然的补救措施是将更多比特分配给重要的通道（特征维度），而将较少比特分配给其余通道，但原始缓存没有提供线索：其通道高度相关，因此没有一个通道显得更重要。我们的分析表明，一旦将缓存旋转到由其自身统计信息计算出的坐标系中，消除这些相关性，这个线索就会出现。在那里，一小部分通道承载了几乎全部信息，将预算花在少数几个通道上远比平均分配更准确。在此分析的指导下，我们开发了SPECTRA，这是一种免训练、即插即用的编解码器，它将缓存重新编码到该坐标系中，并将比特预算集中在承载信号的通道上。在Llama-3.1-8B和Qwen2.5-7B上，在长上下文基准测试中，SPECTRA在4倍压缩时接近无损，在8倍压缩时（均匀量化已崩溃）具有竞争力，并可达12倍压缩，将可用压缩推向2比特悬崖之外，使同一GPU可容纳更长的上下文和更大的批次。

## Abstract
Large language models (LLMs) increasingly read long inputs in the agentic era, from whole documents and codebases to conversations across many turns. Their inference memory is then dominated by the key-value (KV) cache, the stored attention keys and values of every token the model has read and generated. Because the cache grows with context length and is re-read in full at every generated token, a longer context means more GPU memory.   To reduce this cost, most existing methods compress the KV cache by lowering every stored value to the same low precision, a technique known as quantization. They can push this to nearly two bits per value, but rarely further, because quality drops sharply at this 2-bit cliff: four levels are too few for the cache's outlier-heavy values, where a few large entries consume the levels and collapse the rest into noise. A natural remedy is to spend more bits on the channels (feature dimensions) that matter and fewer on the rest, but the raw cache offers no handle: its channels are strongly correlated, so none stands out as more important.   Our analysis shows that this handle appears once the cache is rotated into a coordinate system computed from its own statistics, removing these correlations. There, a small fraction of channels carries almost all the information, and spending the budget on those few is far more accurate than spreading it evenly.   Guided by this analysis, we develop SPECTRA, a training-free, drop-in codec that re-encodes the cache into this coordinate system and concentrates the bit budget on the channels that carry the signal. On Llama-3.1-8B and Qwen2.5-7B over long-context benchmarks, SPECTRA is near-lossless at 4x compression, competitive at 8x where uniform quantization has collapsed, and reaches up to 12x, pushing usable compression past the 2-bit cliff so the same GPU holds longer contexts and larger batches.

## 1. 论文的核心问题与整体含义

大语言模型（LLM）在智能体场景下需要处理越来越长的上下文，导致推理内存被 **KV 缓存**（key-value cache）主导。KV 缓存随序列长度线性增长，每个生成步骤都要整体重读，因此长上下文直接转化为 GPU 显存瓶颈。现有压缩手段中，**量化**是最常见的做法，但存在一个明显的“**2-bit 悬崖**”：当每个值压到约 2 比特时，只有 4 个量化级别，而缓存中少量大的离群值会消耗掉大部分量化区间，使大量小值塌缩为噪声，导致质量急剧下降。更根本的问题是，原始缓存通道（特征维度）之间存在强相关性，无法直接判断哪些通道更重要，因此均匀分配比特预算既浪费又低效。

论文的核心洞察是：**如果先将缓存旋转到由自身统计量计算出的坐标系（谱变换 / KLT），通道间的相关性被消除，能量会集中到少数几个通道上；此时按通道重要性差异化分配比特预算，就能突破 2-bit 极限，并统一低秩投影和量化两种压缩策略**。基于这一思路提出的 SPECTRA 是一种免训练、即插即用的编解码器，在 4 倍压缩下接近无损、8 倍仍可用、最高可达 12 倍。

## 2. 方法论

### 2.1 核心思想

把 KV 缓存压缩看作**率失真编码问题**，而不是简单的“剪枝”或“降低位宽”。关键步骤是：

1. 用一个**激活加权的线性变换**（基于输入激活的 Gram 矩阵）将缓存旋转到谱坐标系，使通道去相关且按能量排序；
2. 在这个坐标系上，用**反向注水（reverse water-filling）算法**给每个通道分配不同比特数，能量高的给更多比特，能量极低的给 0 比特（即直接丢弃，等价于低秩截断）；
3. 该变换矩阵可以**折叠回原模型权重**，部署时无需额外运行时结构。

### 2.2 关键技术细节

- **激活加权低秩分解（G-weighted SVD）**：  
  设某层输入激活 \(h\)，其未中心化二阶矩矩阵 \(G = \mathbb{E}_h[h^\top h]\)。要最小化激活空间中的重建误差：
  \[
  \min_{\mathrm{rank\ } r} \mathbb{E}_h \| h(W_K - W_{down}W_{up}) \|^2
  = \min_{\mathrm{rank\ } r} \| G^{1/2}(W_K - W_{down}W_{up}) \|_F^2
  \]
  对白化权重 \(M = G^{1/2}W_K\) 做 SVD 截断，得到：
  \[
  W_{down} = G^{-1/2}U_r\Sigma_r^{1/2},\quad W_{up} = \Sigma_r^{1/2}V_r^\top
  \]
  这种“平方根分配”使缓存潜变量满足 \(\mathbb{E}[c^\top c] = \Sigma_r\)（对角且降序），即潜变量在第二矩意义下正交且能量有序。

- **率失真比特分配（反向注水）**：  
  将潜变量各坐标近似为独立高斯标量源，方差为 \(v_j\)。最小化总失真 \(\sum_j v_j 2^{-2b_j}\)（固定平均比特 \(\bar{b}\)）的闭合解为：
  \[
  b_j = \bar{b} + \frac12 \log_2\left(\frac{v_j}{\mathrm{GM}(v)}\right)
  \]
  其中 \(\mathrm{GM}(v)\) 是方差的几何均值，结果截断到 \([0, b_{\max}]\)。低方差通道比特数为 0 时被丢弃，从而自然过渡为低秩压缩。

- **工程实现**：  
  为支持流式缓存，相邻能量有序的通道被分为一组（组大小 \(g=64\)），共享一个位宽，每 token 存储 fp16 的 scale 和 zero-point（计入有效压缩率）。此外，低秩分解 value 路径会产生注意力输出残差，用闭合形式的 reduced-rank regression 修正输出投影 \(W_O\)，不增加推理成本。

- **两种运行模式**：  
  - Mode A（重构后注意力）：逐 token 下投影、量化、追加，重建 K/V 后做标准注意力，RoPE 精确、免训练；  
  - Mode B（潜在空间注意力）：将上投影并入 query，注意力直接在 r 维潜空间计算，可将显存节省转化为计算节省，但本文仅做微基准验证，未做端到端内核集成。

## 6. 主要结论与发现

1. **在变换后的谱坐标系中，KV 缓存的信息高度集中**：原始通道强相关（平均非对角相关约 0.2），旋转后接近 0，且前 25% 的通道承载了 96% 的 key 能量。
2. **按重要性分配比特明显优于均匀量化**，尤其在低于 2 bits 的区域，错误中位数可降低 1.6×、最高 5.5×；比特数上升后差距缩小。
3. **通道重要性应由激活数据决定，而非权重本身**：激活加权变换在相同压缩率下重建错误比权重 SVD 低约 13×，注意力输出错误低约 1.9×。
4. **SPECTRA 在 4 倍压缩下近无损**（甚至略高于 dense），**在 8 倍压缩时仍保持竞争力**，而均匀量化基线的分数已大幅滑坡；最高可用压缩达 12 倍（Llama 上 LongBench 平均 48.8，dense 为 53.24）。
5. **显存容量显著提升**：24 GB 下 dense fp16 最多 65k tokens，SPECTRA 在 12× 时可容纳 793k tokens；容量分析精度在 H200 上实测与理论误差小于 1%。
6. SPECTRA 将低秩压缩和量化统一为“给每个通道分配多少比特”的单一控制，避免被迫站在 2-bit 悬崖上。

## 7. 优点

- **免训练、即插即用**：变换矩阵折叠进模型权重，部署成本低，无需微调或蒸馏。
- **理论扎实**：有完整的率失真框架、闭合形式最优解（G-weighted SVD、反向注水、Eckart-Young 定理），不是纯启发式。
- **统一了低秩与量化**：0 比特通道即丢弃，两个方向自然融合，形成了单一参数控制。
- **公平性较好**：有效压缩率口径统一，所有方法在同一评测框架下比较，基线来自官方实现。
- **实验设计有说服力**：多个模型、任务、压缩档位、动机分析实验齐全，并给出显存容量验证。
- **Motivation 清晰**：用三个简洁的观察逐步导出方法，逻辑链条完整。

## 8. 不足与局限

- **未做端到端内核加速**：Mode B（潜在空间注意力）能节省计算，但只做了微基准验证，没有投入实际 kernel，因此论文只报告显存容量而非吞吐/时延收益。
- **模型规模有限**：仅验证 7–8B 级别模型，未覆盖更大规模 LLM（如 70B+）或不同架构（非 GQA）。
