## 摘要
在边缘设备上部署大规模语言模型（LLM）进行推理具有挑战性，因为存在严重的内存和带宽限制。尽管推测解码和混合专家模型（MoE）已被提出以提高推理效率，但将它们简单组合通常会导致过多的验证开销和较差的专家重用，从而限制了它们在内存受限的边缘环境中的有效性。在这项工作中，我们提出了S2-MoE，一种用于边缘设备上MoE推理的高效自推测解码框架。S2-MoE通过路由感知的自适应推测扩展减少了冗余验证，通过重用感知的专家门控提高了验证效率，并通过共享上下文使草稿模型和目标模型的执行对齐。在llama.cpp中实现，S2-MoE在多种MoE模型和数据集上，相较于标准自回归解码，在边缘设备上实现了高达5.3倍的加速（平均约2.0倍）。代码可在https://github.com/angerybob/S2-MoE获取。

## Abstract
Deploying large language models (LLMs) for inference on edge devices is challenging due to severe memory and bandwidth constraints. While speculative decoding and Mixture-of-Experts (MoE) have been proposed to improve inference efficiency, naively combining them often incurs excessive verification overhead and poor expert reuse, limiting their effectiveness in memory-bound edge settings. In this work, we propose S2-MoE, an efficient self-speculative decoding framework for MoE inference on edge devices. S2-MoE reduces redundant verification through routing-aware adaptive speculative expansion, improves verification efficiency with reuse-aware expert gating, and aligns draft and target execution via shared context. Implemented in llama$.$cpp, S2-MoE achieves up to $5.3\times$ speedup (about $2.0\times$ on average) over standard autoregressive decoding across diverse MoE models and datasets on edge devices. Code is available at https://github.com/angerybob/S2-MoE.

- **两种互补路线的冲突**：推测解码（Speculative Decoding, SD）通过轻量级草稿模型生成候选 token，再由目标模型并行验证，以提升"输出密度"；MoE（Mixture-of-Experts）通过稀疏激活减少每步访问的参数量，以降低"参数密度"。理论上两者互补，但**简单组合在边缘场景下效果不佳**。
- **核心矛盾**：MoE 模型中，草稿 token 可能激活不同的专家，导致验证阶段参数重用率低、验证成本高；被拒绝的草稿 token 仍会触发额外的专家激活，产生大量**冗余验证开销**。现有置信度剪枝策略无法反映专家级别的验证成本，导致推测解码的收益被抵消甚至逆转。

提出 S²-MoE——一种面向边缘设备 MoE 推理的高效**自推测解码**（Self-Speculative Decoding）框架，通过三个互补的组件同时提升草稿保真度、降低冗余验证、增强专家参数重用，实现端到端加速。

## 2. 论文提出的方法论

S²-MoE 由三个核心组件构成，整体架构如图 3 所示：

### （1）路由感知的自适应推测扩展（Routing-aware Adaptive Speculative Expansion）

**核心思想**：在 MoE 模型中，草稿 token 的验证成本取决于其激活的专家集合，而非仅取决于置信度。因此，推测树的扩展应同时考虑"接受概率"和"边际验证成本"。

**关键技术细节**：

- **预期收益**：对于深度为 𝑘 的草稿 token 𝑖，其接受概率为前缀置信度 𝑝ᵢ = Πⱼ₌₁ᵏ 𝑝ᵢ,ⱼ，预期收益定义为 𝐵ᵢ = 𝑝ᵢ·𝑇_AR（𝑇_AR 为目标模型单步解码平均延迟）。
- **路由感知成本估计**：边际验证成本定义为新增专家的数量乘以单位专家延迟 𝑇_exp：Δ𝐶_ver(𝑖|𝑆) = |Eᵢ\⋃ⱼ∈𝑆 Eⱼ|·𝑇_exp，其中 Eᵢ 为 token 𝑖 的预测专家集合，𝑆 为已选入扩展的草稿 token 集合。总成本为 𝐶ᵢ = Δ𝐶_ver + 𝐶_draft。
- **自适应扩展**：效用定义为 𝑈ᵢ = 𝐵ᵢ/𝐶ᵢ，贪心地扩展所有满足 𝑈ᵢ ≥ 1 的候选节点。

**优势**：相较于固定宽度或仅基于置信度的剪枝，该策略能够识别"接受-验证成本"更优的候选，在不利接受结果下仍能限制冗余开销（如图 4 的 Bad Case 所示）。

### （2）重用感知的专家门控（Reuse-aware Expert Gating）

**核心思想**：MoE 模型中相邻 token 往往路由到不同的专家，导致并行验证时参数重用率低。该方法通过软性偏置将低置信度 token 的专家选择向高置信度 token 已激活的专家对齐，从而提高专家参数局部性。

**关键技术细节**：

- **跨 token 专家重要性聚合**：对每个 MoE 层，用 token 置信度加权聚合门控 logits：𝑔ₑ = Σ𝑏∈B 𝑤ᵦ·ℓᵦ,ₑ，使高置信度 token 的专家偏好获得更大权重。
- **全局偏好专家选择**：选取 TopCap 个聚合重要性最高的专家作为"重用奖励专家"集合 E★，其中 cap ≥ 𝑘（top-k 路由数），保证原优先专家仍可被选择。
- **软路由偏置**：对每个 token 的门控 logits 注入加性偏置 ℓ′ᵦ,ₑ = ℓᵦ,ₑ + 𝜆ᵦ·1[𝑒∈E★]，其中 𝜆ᵦ 正比于 token 的 top-1 与第 (𝑘+1) 个专家的分数差，使得偏置主要影响边界专家而不干扰主导路由。
- **融合实现**：以轻量级 fused CUDA kernel 实现，开销可忽略。

### （3）上下文对齐的自推测解码（Context-aligned Self-speculative）

**核心思想**：自推测草稿与目标模型如果维护独立的 KV cache，草稿的近似误差会随解码步数累积，导致接受率下降。通过共享统一的 KV cache，将误差限制在当前推测步内。

**关键技术细节**：

- 目标模型先处理提示词并建立 KV cache。
- 草稿模型直接读取共享上下文，不维护独立历史。
- 草稿产生的 KV 更新视为临时的，验证前回滚，仅接受的 token 提交到共享缓存。

## 9. 总结与个人评价

### 核心贡献再定位

S²-MoE 的贡献可以概括为"在 MoE 推测解码的验证侧做减法、在草稿侧做加法"：通过路由感知的自适应扩展控制冗余验证成本，通过重用门控把被拒绝 token 的专家激活"转化"为可复用的参数访问，通过共享 KV cache 压缩草稿误差的传播。三者协同，使得自推测解码在 MoE 上首次展现出对边缘设备 LLM 推理的显著加速价值。

### 方法设计的巧妙之处

- **将验证成本纳入推测树的效用函数**是全文最具洞察力的设计。传统推测解码只关心接受率，而 S²-MoE 明确指出在 MoE 中**验证成本的边际增量**取决于新激活的专家集合大小，这一视角在同类工作中极少被明确提出。
- **重用门控的"软偏置"设计**保持了原路由的语义：通过 top-1 与 top-(k+1) 的分数差控制偏置强度，使偏置只影响"本来就在边缘徘徊"的专家选择，而非强行改写高置信度 token 的路由，这是质量可保持的深层原因。

### 局限性的客观权衡

从学术贡献角度，论文的实证性强、系统完成度高，但理论深度有限，且评估场景单一（仅边缘单 batch）。从实用角度，其对 116.8B 模型在 16 GB 内存设备上的部署能力验证具有现实意义，但未给出 profiling 成本和内存峰值的完整账目，距离"即插即用"仍有距离。

## 10. 适用场景与未来工作方向

### 适用场景

- **边缘 / 端侧 MoE 推理**：内存带宽受限、单 batch 交互为主、需要低延迟响应的场景（如机器人控制、车载助手、本地隐私敏感问答）。
- **大模型本地部署的性价比优化**：在 Jetson 类设备上运行 30B–120B 级 MoE 模型时，S²-MoE 可作为 llama.cpp 推理栈的直接上层优化，无需重训练或额外草稿模型。
- **冷启动 / 动态加载环境**：训练无关特性使其适合模型频繁切换、缓存资源紧张的多租户边缘服务。

### 未来工作方向

1. **扩展到批量推理**：研究 batch 内多序列间的专家重用协同，将单序列的路由感知扩展推广到跨序列维度。
2. **与大语言模型协同设计**：在 MoE 预训练阶段加入路由局部性正则化（如鼓励相邻 token 共享专家），从模型侧增强推测解码的可加速性。
3. **推测策略的在线自适应**：将成本模型与运行时接受的 token 统计结合，实现在线动态调整推测树宽度、深度与偏置强度，减少人工校准。
4. **多模态 MoE 的适配**：探索视觉-语言 MoE 模型中模态间专家路由差异对推测解码的影响，扩展 S²-MoE 的适用范围。

**总体评价**：S²-MoE 是一篇工程完成度和实验扎实度俱佳的系统型论文。它精准识别了 MoE 推测解码中"成本-收益错位"这一核心矛盾，用三个轻量、正交、可解释的组件给出了端到端的解决方案，并在多种硬件与模型规模上验证了 1.3×–5.3× 的加速效果。尽管在理论深度、场景广度和资源透明度上存在可挑剔之处，其方法设计的思想（以验证成本为效用核心、以软偏置保语义、以共享缓存压误差）对后续嵌入式计算与大模型推理的交叉研究具有明确的借鉴价值，是边缘 MoE 推理领域一项值得关注的代表性工作。
