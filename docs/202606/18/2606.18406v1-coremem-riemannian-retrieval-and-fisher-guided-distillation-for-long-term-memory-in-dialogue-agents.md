## 摘要
个性化对话代理需要持续的长期记忆，以在多轮会话中保持连贯交互。然而，在消费级硬件（如8 GB显存的边缘设备）上部署这些能力会带来严重的内存与计算瓶颈。现有系统通常依赖各向同性的余弦相似度进行检索，并使用启发式规则进行上下文压缩。这些方法缺乏统一的理论基础，常常在高维检索中遭受中心化问题（hubness problem），而在压缩过程中则出现句法碎片化。为克服这些局限，我们提出CoreMem，一种资源高效的边缘-云记忆架构，其统一基础为信息几何。首先，黎曼检索以局部自适应的费舍尔-拉奥度量替代余弦匹配，通过马氏距离结合O(Ndr)伍德伯里加速进行实时搜索，有效惩罚中心存储记忆。其次，费舍尔引导离散令牌蒸馏（FDTD）引入分层句子到令牌的压缩机制。它从费舍尔信息迹中导出灵敏度分数，提供一种原则性的压缩-KL权衡，并辅以显式结构句法保护。在LOCOMO和LongMemEval-S基准测试上，CoreMem实现了显著的精度提升，在开放领域（+4.51个百分点）和时间推理（+4.17个百分点）上取得实质性进展。广泛的性能分析证实，CoreMem可在严格的8 GB显存预算内无缝运行，成功弥合了资源受限边缘设备与对理论基础牢固的终身记忆代理需求之间的鸿沟。

## Abstract
Personalized dialogue agents require continuous long-term memory to maintain coherent interactions across multiple sessions. However, deploying these capabilities on consumer-grade hardware (e.g., 8 GB VRAM edge devices) introduces severe memory and compute bottlenecks. Existing systems typically rely on isotropic cosine similarity for retrieval and heuristic rules for context compression. These approaches lack a unified theoretical foundation, frequently suffering from the hubness problem in high-dimensional retrieval and syntactic fragmentation during compression. To overcome these limitations, we propose CoreMem, a resource-efficient edge-cloud memory architecture fundamentally unified by information geometry. First, Riemannian retrieval replaces cosine matching with a locally adaptive Fisher-Rao metric, effectively penalizing hub memories via Mahalanobis distance with O(Ndr) Woodbury acceleration for real-time search. Second, Fisher-guided discrete token distillation (FDTD) introduces a hierarchical sentence-to-token compression mechanism. It derives sensitivity scores from Fisher information traces, providing a principled compression-KL tradeoff augmented with explicit structural syntax protection. Evaluated on the LOCOMO and LongMemEval-S benchmarks, CoreMem achieves strong accuracy improvements, yielding substantial gains in Open-domain (+4.51 pp) and Temporal (+4.17 pp) reasoning. Extensive profiling confirms that CoreMem operates seamlessly within a strict 8 GB VRAM budget, successfully bridging the gap between resource-constrained edge devices and the demand for theoretically grounded, lifelong memory agents.

  - **架构**：检索与压缩被**独立优化**，导致级联失败。
- **整体含义**：CoreMem旨在以**信息几何**为统一理论框架，在资源受限（8GB VRAM）边缘设备上实现理论严谨、资源高效且经济（减少API调用token量）的长期记忆代理，弥合学术理论与实际部署的鸿沟。

## 2. 论文提出的方法论

### 2.1 核心思想
将检索和压缩统一在**统计流形**几何下：检索视为在嵌入流形上使用**Fisher-Rao度量**的距离测量，压缩视为通过**Fisher信息矩阵对角线**评估损失曲率以衡量token重要性。

### 2.2 关键技术细节
- **黎曼检索（Riemannian Retrieval）**：
  - 将每个记忆嵌入视为高斯分布的均值，用**马氏距离**（Mahalanobis distance）代替余弦相似度。
  - 构建局部协方差矩阵 Σ ≈ U_r M_r U_r^T + D，其中 D = diag(σ²+λ)（λ = 10·mean(σ²) 防止病态），U_r 来自SVD（选取解释95%方差的低秩r）。
  - 利用**伍德伯里恒等式**（Woodbury identity）将逆协方差计算从 O(d³) 降至 O(Ndr)，实现实时搜索。
  - 引入**残差度量融合**：score = α·norm(cos) + (1-α)·norm(rie)，α=0.5平衡余弦和黎曼的优势。
- **Fisher引导离散令牌蒸馏（FDTD）**：
  - 目标：在严格token预算B下最小化生成KL散度 D_KL(p_θ(Y|X)||p_θ(Y|˜X))。
  - 采用**一阶泰勒展开**，使用**对角Fisher信息矩阵**迹作为每个token的敏感性：S(x_i)=∥∇_{h_i} L ⊙ h_i∥₂，通过单次后向传播获得（冻结模型参数）。
  - **层次化压缩**：先按句子分块，长句子（>8tokens）保留首尾3个token保护主谓宾骨架，中间只丢弃低分冗余token；句子按平均分数贪心选择直至预算。
  - **结构保护掩码**：叠加多种启发式先验：
    - 推理关键词（but, because等）×1.2
    - 句法标点（:, .等）×1.3-1.5
    - 内容词（数字、大写专有名词）×1.3-1.4
    - 对话轮次衰减（1.0→0.6）
    - 局部间隙填充（连续丢弃间隔≤3时自动恢复）
  - **理论性质**：定理1给出压缩误差KL散度上界 O(L²·∑丢弃token的S)，当按S升序丢弃时最小化上界。

### 2.3 算法流程（文字描述）
1. 边缘设备使用高效编码器（如gte-Qwen2-1.5B）嵌入查询和记忆。
2. 黎曼检索：用预计算的伍德伯里逆协方差计算马氏距离，融合余弦得分，选择top-k记忆。
3. 本地小语言模型（SLM，如Qwen3-0.6B）执行FDTD：前向计算loss，反向计算每个token嵌入的梯度得到敏感性，应用结构保护掩码，按分层策略压缩至预算B。
4. 仅将压缩后的上下文 ˜X 传输至云端LLM（如GPT-4o-mini）生成最终回答。

## 6. 主要结论与发现

1. **端到端性能**：CoreMem-Fusion在所有指标上最优，在**开放域推理**提升4.51百分点（p.p.），**时序推理**提升4.17百分点（MiniLM-L6下）。
2. **黎曼检索的优势**：主要体现于开放域和时序场景，能有效找回余弦检索忽略的“尾部记忆”；与余弦互补，混合融合（α=0.5）达到最佳平衡。
3. **小嵌入模型价值凸显**：在384维MiniLM上CoreMem增益最大（+3.70 p.p. Judge），因为小模型中心化问题更严重；高质量1536维嵌入提升较小。
4. **压缩策略**：FDTD在预算1000时保持高精度（条件准确率0.9756），压缩比67.4%；但极低预算（250）时所有学习型压缩器均不如简单截断，说明小模型容量上限。
5. **结构保护至关重要**：移除关键词（因果连接词）保护时Judge准确率骤降4.5 p.p.，而ROUGE-L几乎不变，证明词汇与语义度量的重要差异。
6. **LLM Judge vs ROUGE-L**：两者相关系数 r≈0.56，表明纯词汇重叠无法捕捉因果关系，需语义评判。

## 7. 优点

- **理论统一性**：将检索和压缩均建立在信息几何上（Fisher-Rao度量、Fisher信息矩阵），提供KL散度上界，避免启发式盲区。
- **边缘可行性**：显存占用<6GB，满足8GB VRAM严格的消费级硬件条件；同时压缩context减少20-30%的token，直接节省API成本。
- **计算高效**：伍德伯里加速使黎曼搜索复杂度O(Ndr)，远低于直接求逆；FDTD仅需一次后向传播。
- **设计互补性强**：混合权重机制巧妙融合了两种度量的优势；结构保护掩码弥补了纯Fisher近似在自然语言上的盲点。
- **实验覆盖广泛**：跨两个基准、多种推理类型、多个压缩预算、消融和案例研究，结论可信度高。
- **公开代码**：提供源码和实验数据，促进可复现性。

## 8. 不足与局限

- **实验限制**：
  - 仅限于**英语**基准，对形态丰富语言的结构保护掩码未验证。
  - 未进行全因子端到端消融（检索×压缩交互），量化两者协同作用不足。
