## 摘要
动态稀疏注意力通过仅关注每个查询最相关的Top-K KV块来加速长上下文LLM解码，但这一机制引入了串行的选择-注意力依赖关系，成为新的延迟瓶颈。我们提出PRR，一种推测-重用-修复运行时，利用DSA选择中的时间局部性来预测可能的块，在选择进行过程中推测性地对它们进行注意力计算，并在得知真实选择集后增量式地修复遗漏的块。PRR采用轻量级的基于EMA的预测器、基于性能分析的推测预算（确保推测工作不在关键路径上），以及基于FlashAttention的修复核，利用在线softmax统计将遗漏块折叠到部分注意力状态中。在长上下文基准测试和代表性DSA方法上，PRR将每个token的解码延迟降低高达40%，同时保持下游任务精度。GitHub: https://github.com/Tianyu9748/Incremental_FlashAttention

## Abstract
Dynamic sparse attention (DSA) accelerates long-context LLM decoding by attending to only the top-K KV blocks relevant to each query, but it introduces a serialized selection-to-attention dependency that emerges as a new latency bottleneck. We present PRR, a speculate-reuse-repair runtime that exploits temporal locality in DSA selections to predict likely blocks, speculate the attention over them while selection is in flight, and incrementally repair missed blocks once the true selected set is known. PRR uses a lightweight EMA-based predictor, a profiling-guided speculation budget that keeps speculative work off the critical path, and a FlashAttention-based repair kernel that folds missed blocks into the partial attention state using online-softmax statistics. Across long-context benchmarks and representative DSA methods, PRR reduces per-token decoding latency by up to 40% while preserving downstream task accuracy. Github: https://github.com/Tianyu9748/Incremental_FlashAttention

## 1. 论文的核心问题与整体含义（研究动机和背景）

动态稀疏注意力（DSA）通过仅为每个查询选择最相关的 Top-K KV 块来显著减少注意力计算，是长上下文 LLM 解码的高效方案。然而，DSA 引入了一个新的关键路径瓶颈：**选择（Selection）→ 注意力（Attention）的串行依赖**——必须先执行压缩注意力并选出 Top-K 块，才能对该块集进行稀疏注意力计算。随着上下文长度增长，选择阶段耗时占比可达 41%，严重拖慢每 token 生成延迟。

论文的核心洞察：DSA 的块选择在连续解码步骤中表现出强**时间局部性**（约 68% 的块被重复选中），且 GPU 资源在 DSA 解码中存在大量空闲（SM、L2/DRAM 带宽利用率均低于 40%）。这允许在块选择执行的同时，**预测并预先计算**注意力，最后通过增量修复处理误预测的块，从而打破串行依赖，加速解码。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想：预测（Predict）、推测执行（Reuse）、增量修复（Repair）

- **预测**：利用历史重要性分数预测当前步骤的 Top-K 块集 P。
- **推测执行**：在块选择进行的同时，对预测集 P 执行 KV 收集和稀疏注意力计算（与选择并行）。
- **增量修复**：等真实 Top-K 块集 A 确定后，仅对遗漏块 M = A \ P 进行增量注意力修复，将它们的贡献合并到已有部分注意力状态中。

### 2.2 关键技术细节

**（1）轻量 EMA 预测器**

- 为每个块 i 维护平滑水平 ℓᵢ 和趋势估计 vᵢ。
- 预测量：êISᵢᵗ = ℓᵢᵗ⁻¹ + γ·vᵢᵗ⁻¹（γ 控制趋势外推强度）。
- 更新：
  - vᵢᵗ = β(ISᵢᵗ - ℓᵢᵗ⁻¹) + (1-β)vᵢᵗ⁻¹
  - ℓᵢᵗ = α·ISᵢᵗ + (1-α)ℓᵢᵗ⁻¹
- 超参数 (α, β, γ) 在预填充阶段通过网格搜索（80 个候选）在预填充重要性分数轨迹上校准，几乎不增加模型执行开销。

**（2）推测预算的动态控制**

- 通过离线 profiling 测量不同上下文长度和预算比率 δ 下的选择延迟和推测注意力延迟。
- 运行时在线选择最大的安全 δ，使得推测注意力时延不超过当前选择窗口，避免推测扩展关键路径。

**（3）基于在线 Softmax 的增量修复内核**

- 修改 FlashAttention 前向过程，不仅输出注意力结果 O，还输出分母 ℓ 和运行最大值 m（每头两个标量）。
- 修复内核利用 FlashAttention 的在线 softmax 递推式：

  - ℓ⁽ᵗ⁺¹⁾ = e^(m⁽ᵗ⁾-m⁽ᵗ⁺¹⁾)·ℓ⁽ᵗ⁾ + e^(m̃-m⁽ᵗ⁺¹⁾)·ℓ̃
