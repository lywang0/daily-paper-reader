## 摘要
大型语言模型（LLM）已成为现代应用不可或缺的组成部分，但其部署仍面临挑战。除了执行模型本身，实际部署还必须兼顾成本效率、低延迟和最优资源利用率。传统方法通常假设整个模型可以托管在单个设备上，但这在许多实际场景中并不成立，尤其是在设备资源受限的边缘和雾环境中。本文介绍了E2LLM，一个旨在在此类资源有限环境中实现高效LLM部署的框架。E2LLM并非简单地将单个模型拆分到所有可用设备上，而是将完整模型复制到多组设备（副本）上，并在每个副本内应用模型并行。每个副本根据其处理输入和输出令牌的效率被分配专门的角色：PREFILL或DECODER。这种分离利用了LLM推理这两个阶段之间的固有差异。为了有效组织设备，我们采用遗传算法形成集群，以最大化系统性能。在每个集群内，我们应用动态规划确定最优分区策略，以最小化模型并行执行中的瓶颈。实验结果表明，我们的方法能够稳健地适应不同的工作负载，包括输入和输出令牌长度变化显著的场景。与Splitwise基线相比，E2LLM在高需求条件下平均等待时间减少了50%以上。

## Abstract
Large Language Models (LLMs) have become integral to modern applications, yet their deployment remains challenging. Beyond executing the models themselves, practical deployment must address cost efficiency, low latency, and optimal resource utilization. Conventional approaches typically assume that an entire model can be hosted on a single device, which does not hold in many real-world scenarios, particularly in Edge and Fog environments where device resources are constrained. In this paper, we introduce E2LLM, a framework designed to enable efficient LLM deployment in such resource limited settings. Rather than simply partitioning a single model across all available devices, E2LLM replicates the full model across multiple groups of devices (replicas) and applies model parallelism within each replica. Each replica is assigned a specialized role PREFILL or DECODER based on its efficiency in handling input and output tokens. This separation leverages the inherent differences between these two phases of LLM inference. To effectively organize devices, we utilize a Genetic Algorithm to form clusters that maximize system performance. Within each cluster, we apply Dynamic Programming to determine an optimal partitioning strategy that minimizes bottlenecks in model-parallel execution. Experimental results demonstrate that our approach adapts robustly to varying workloads, including scenarios with significant variation in input and output token lengths. Compared to the Splitwise baseline, E2LLM reduces average waiting time by over 50% under high-demand conditions

### 2. 论文提出的方法论
- **核心思想**：将完整LLM**复制到多个设备组（replica）**，每个replica内采用**模型并行（管道并行）**；依据计算特性为每个replica分配**PREFILL或DECODER**角色，利用两者内存/计算差异优化整体效率。
- **关键技术细节**：
  - **延迟剖析**：假设相同类型Transformer块延迟相似，使用llama.cpp加载简化版模型（减少Transformer块数）测量每层在每台设备上的计算时间，以及设备间网络带宽。
  - **动态规划（DP）模型划分**：用于在单个replica内分配模型各层到设备。算法1（DP-based Pipeline Allocation）找出使**最慢阶段延迟最小化**的划分方案。核心公式：  
    ```
    DP(i,k,m) = min( min(DP(j-1,k-1,mp), L(j,i,k,m), T(k-1,k)) )  ∀j≤i
    DP(i,1,m) = L(0,i,1,m)
    ```
    其中，`DP(i,k,m)`表示前`i`层分配到前`k`个设备时的最慢阶段延迟，`m`表示当前设备是否为master（负责语言模型头），`L`为层执行延迟（含网络传输），`T`为设备间通信延迟。复杂度O(M²N²)。
  - **角色分配**：根据Prefill和Decoder阶段计算特性差异（Prefill计算密集、Decoder内存密集），通过分析输入/输出令牌比例（公式3）计算瓶颈阶段，并利用公式4 `bottleneck = bottleneck_phase - arrival_period` 估算累积等待时间。通过**穷举**搜索确定最优的Prefill和Decoder replica数量及角色分配，使瓶颈最小。
  - **遗传算法（GA）集群形成**：采用双染色体表示（设备排序+副本划分），通过交叉、变异（多种策略，突变概率30%）和精英保持策略，搜索使系统吞吐量最大化的设备聚类方案。GA内部调用DP评估每个replica的Prefill和Decoder性能，并利用缓存加速。
  - **负载均衡**：使用**Join Shortest Queue (JSQ)**策略将请求分发到延迟最短的replica。

- **效率**：结合复制和模型并行在异构边缘环境中可实现高效的LLM服务，且角色分离策略优于统一执行。

### 7. 优点
- **方法创新**：首次在边缘/雾异构环境中系统性地结合**复制（replication）** 与**模型并行（pipeline parallelism）**，并引入**Prefill/Decoder角色分离**，专门优化瓶颈阶段。
- **算法设计**：遗传算法（双染色体、精英策略）与动态规划（以最小化瓶颈为目标）互补，兼顾全局搜索与局部最优；DP复杂度O(M²N²)优于EdgeShard的指数级。

- **实际意义**：面向中小企业和隐私敏感场景，提供低成本、低延迟的本地LLM推理方案。
