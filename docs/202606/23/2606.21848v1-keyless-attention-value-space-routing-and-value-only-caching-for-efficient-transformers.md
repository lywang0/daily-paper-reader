## 摘要
我们提出无键注意力（Keyless Attention），一种完全消除键投影的注意力机制，仅对查询和值进行操作。这产生了仅值缓存（Value-Only Cache），相比标准注意力将KV缓存内存和访问开销精确降低50%，同时匹配或超越标准注意力的解码吞吐量。在效率之外，我们引入深度-m注意力因子分解：标准注意力计算注意力双线性形式的深度-2因子分解，而无键注意力实现了该系列的深度-m实例。在m=3时，无键注意力通过一个值空间路由矩阵匹配标准注意力的投影矩阵数量，该矩阵替代了键投影并引入了路由与检索之间的耦合。在五个模型和四种架构（GPT-2 280M、GPT-2 557M、Pythia 410M、Qwen2 1.5B和Llama 3.2 1B）上的实验表明，无键注意力在5个模型中的4个中在困惑度上匹配或优于标准QKV注意力。在下游零样本评估（GPT-2 557M）中，无键注意力在5个常识推理基准中的4个上表现更优，同时在整个过程中实现了50%的KV缓存减少。

## Abstract
We propose Keyless Attention, an attention mechanism that eliminates the key projection entirely, operating over queries and values only. This yields a Value-Only Cache that reduces KV cache memory and access overhead by exactly 50% over standard attention, while matching or exceeding standard attention's decode throughput. Beyond efficiency, we introduce Depth-$m$ Attention Factorization: standard attention computes a depth-2 factorization of the attention bilinear form, while Keyless Attention realizes a depth-$m$ instance of this family. At m=3, Keyless Attention matches the projection matrix count of standard attention via a value-space routing matrix that replaces the key projection and introduces a coupling between routing and retrieval. Experiments across five models and four architectures (GPT-2 280M, GPT-2 557M, Pythia 410M, Qwen2 1.5B, and Llama 3.2 1B) show that Keyless Attention matches or outperforms standard QKV attention on perplexity in 4 out of 5 models. On downstream zero-shot evaluation (GPT-2 557M), Keyless Attention outperforms on 4 out of 5 commonsense reasoning benchmarks, while achieving 50% KV cache reduction throughout.

# 论文《Keyless Attention: 面向高效Transformer的值空间路由与仅值缓存》详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：标准Transformer模型中，用于自回归推理的**Key-Value (KV) 缓存**占用了大量显存并引入了显著的访问开销。随着模型规模、层数和序列长度的增加，KV缓存甚至可能超过模型参数本身，成为长上下文推理的主要瓶颈。
- **现有方法的局限性**：
    - 现有的优化工作多集中于KV缓存的“事后”优化，如量化、剪枝、稀疏化或系统级管理（如PagedAttention）。
    - 这些方法并未从根本上质疑KV缓存存在的必要性，即**键（Key）投影**是否必不可少。
- **研究动机**：本文从一个根本性问题出发：**能否重新设计注意力机制，从源头上减少KV缓存的需求？** 作者受认知类比启发，认为人类在生成语言时，用一个单一的查询去检索单一的过去表征“存储器”，而非维护独立的路由（Key）和检索（Value）副本。

## 2. 方法论：核心思想、关键技术细节与公式

- **核心思想**：提出**无键注意力（Keyless Attention）**，完全移除标准的键（K）投影，注意力分数直接在查询（Q）和值（V）之间计算。这使得在推理时只需缓存值（V），即**仅值缓存（Value-Only Cache）**，将KV缓存内存和访问开销精确减少50%。

- **核心公式**：
    - **标准注意力**：
        `Attn(X) = softmax(Q * K^T / sqrt(dk)) * V`
        其中 `Q = XW_Q`, `K = XW_K`, `V = XW_V`。
    - **无键注意力**：
        `Attention(Q, V) = softmax(Q * V^T / sqrt(dk)) * V`
        其中查询 `Q = XW_Q`，值 `V = XW_V`。通过调整 `W_Q` 的维度，使其与 `W_V` 的输出空间相匹配，从而无需显式的键投影。

- **关键技术：深度-m注意力因子分解与QVV(3)**
    - 作者从数学上证明，在满足一定条件（如 `W_V` 满秩）时，无键注意力的表达力可以等价于标准注意力。
    - 提出一个统一的理论框架：**深度-m注意力因子分解**。标准注意力是深度-2 (m=2) 因子分解，无键注意力是该家族中的深度-m实例。
    - **QVV(3) 方法**：这是本文重点研究的深度-3实例，它使用**三个投影矩阵**（`W_Q1`, `W_Q2`, `W_V`），与标准注意力的矩阵数量一致。
        - `W_Q1`：第一个查询投影。
        - `W_Q2`：**值空间路由矩阵**，其作用是将查询表示适配到值空间，建立路由与检索的耦合。
        - `W_V`：值投影。
        - 推理时，`W_Q1` 和 `W_Q2` 可预先融合成一个矩阵 `~W_Q`，因此推理计算量不超过标准注意力。

- **值空间路由**：
    - 在无键注意力中，路由分数直接基于查询和**值本身**计算。这引入了一个有益的**归纳偏置**：模型学习关注其内容对当前查询直接相关的token，而非在一个辅助的键空间中匹配的token。
    - **梯度纠缠**：`W_Q2` 和 `W_V` 的梯度在训练中相互耦合。作者认为这种耦合充当了一种隐式正则化，限制了路由机制对语料库特定共现模式的过度泛化，从而减少了过拟合。

- **扩展性**：无键注意力可以自然地扩展到**交叉注意力**和**多模态注意力**，并兼容**MQA (Multi-Query Attention)**、**GQA (Grouped-Query Attention)** 等现有高效注意力变体，以及**MLA (Multi-Head Latent Attention)** 中的低秩压缩策略，以进一步减少缓存。
