## 摘要
大型语言模型（LLMs）在生成推理和长上下文任务上优于早期架构，但其庞大的规模在内存使用、能耗和设备端部署方面带来了显著挑战。由于扩展预训练语言模型能提升下游能力，键值（KV）缓存成为了主要的推理瓶颈。最近的KV缓存压缩方法通过仅保留注意力相关令牌的子集来降低这一成本。然而，尽管这些方法在良性工作负载上保持了准确性，其压缩策略要么无法防御越狱攻击，要么在激进驱逐下削弱了安全对齐。我们提出AnchorKV，这是一种对KV缓存压缩的即插即用修改，它使令牌保留分数偏向于远离与有害提示相关的关键空间方向。AnchorKV通过将差异均值表示工程方法适配到KV缓存中使用的层特定关键投影空间，构建了一个离线安全锚。基于此锚，一个软惩罚令牌选择规则以少量效用换取显著提升的安全对齐，当惩罚为零时则退化为原始压缩器。

## Abstract
Large language models (LLMs) outperform earlier architectures on generative inference and long-context tasks, but their large size introduces significant challenges in memory usage, energy cost, and on-device deployment. Since scaling pre-trained language models improves downstream capability \cite{zhao2023survey}, the key-value (KV) cache becomes a dominant inference bottleneck. Recent KV cache compression methods \cite{jo2025fastkv,li2024snapkv,zhou2024dynamickv} reduce this cost by retaining only a subset of attention-relevant tokens. However, while these approaches preserve accuracy on benign workloads, their compression policies either fail to defend against jailbreak attacks \cite{jiang2024robustkv} or degrade safety alignment under aggressive eviction.   We propose AnchorKV, a drop-in modification to KV cache compression that biases token retention scores away from directions in key space associated with harmful prompts. AnchorKV constructs an offline safety anchor by adapting a difference-of-means representation engineering approach \cite{arditi2024refusal,zou2023representation} to the layer-specific key projection space used in KV caching. Based on this anchor, a soft penalty token selection rule trades a small amount of utility for substantially improved safety alignment, while reducing to the original compressor when the penalty is zero.

- **研究动机**：大型语言模型的KV缓存随序列长度线性增长，成为长上下文推理的主要内存和延迟瓶颈。现有KV压缩方法（如SnapKV、FastKV）在压缩率较高时能保持任务准确率，但严重忽视了模型的安全对齐。论文发现，单纯使用注意力贪婪的令牌驱逐策略（如FastKV的25%保留率）会显著增加越狱攻击成功率（ASR），例如AdvPrompter攻击下ASR从0.44升至0.506（白盒），跨模型转移攻击下从0.299升至0.632（提升超过100%）。
- **整体含义**：现有KV压缩方法在压缩效率与安全对齐之间存在根本性冲突——恶意提示的对抗性框架可能积累高注意力分数，导致恶意查询令牌被优先驱逐（“拒绝证据稀释”）；反之，安全类模板令牌被保留，模型退化为通用拒绝模板（“模板模式回归”）。作者提出AnchorKV，旨在不牺牲太多效用的前提下，在激进压缩时保持模型的安全对齐。

## 2. 方法论

### 核心思想
- 利用表示工程（Representation Engineering）技术，在层特定的键投影空间中构建一个“拒绝方向”（harm anchor），作为软惩罚信号融入令牌保留评分。该方向通过有害/无害提示对在特定层（ℓ*）的键投影的类均值差获得，计算每个令牌的投影分数，从而在保留决策中偏向安全方向。

### 关键技术细节
- **离线锚构建**：
  1. 使用AdvBench训练集的有害提示和DeepSeek-V3生成的长度匹配无害提示。
  2. 对每个提示在选定层ℓ*计算键投影K^(ℓ*)(p) ∈ R^(H×Lp×d)（H：注意力头数，Lp：提示长度，d：每头维度）。
  3. 通过所有令牌均值池化得到提示级表示φ(p) = (1/Lp)∑_t K^(ℓ*)_t(p) ∈ R^(H×d)。
  4. 定义有害锚：v_h = mean_{p∈D_h^tr} φ(p) - mean_{p∈D_s^tr} φ(p)。
  5. 选择最优层ℓ*（基于验证集AUROC最大化），并计算阈值θ = (median(D_val^h) + median(D_val^s))/2，以校正键空间中的共享负偏置。
- **在线软惩罚选择**：
  1. 每个令牌的原始有害分数h_t = (1/H)∑_h ⟨K_t^(ℓ*,h), v_h^(h)/∥v_h^(h)∥₂⟩。
  2. 应用截断和两个结构保护：注意力汇保护（前S个令牌免除惩罚，默认S=4）和重要性免疫（保留α比例的最高注意力令牌，默认α=0.3），得到最终惩罚信号fh⁺_t。
  3. 重要性分数改写：score_t = a_t - λ·ā·fh⁺_t，其中a_t是FastKV原始重要性分数，ā是令牌平均重要性，λ是惩罚强度（安全率）。
  4. λ=0时退化为FastKV（比特级一致）。
- **算法流程**：离线算法1（锚构建）和在线算法2（令牌选择）。

### 公式说明（文字版）
- 锚：v_h = 有害类均值 - 无害类均值（在ℓ*层键投影空间）。
- 令牌有害投影：h_t = 各头投影均值。
- 惩罚信号：fh⁺_t = max(0, h_t - θ)，再经位置豁免保留。
- 最终得分：score_t = a_t - λ·(ā)·fh⁺_t。
- 保留集：TopK(score_t, N-w) ∪ 窗口令牌。

## 6. 主要结论与发现

1. **安全提升显著**：在λ∈[1,30]宽范围内，ASR从FastKV的0.68降至0.13~0.17，最佳λ=10时达0.13（相对降低81%）。
2. **效用损失极小**：在安全有效范围内（λ≤3），LongBench平均分较FastKV下降<0.5点；λ=10时下降约1点，远低于压缩本身带来的1.59点损失。
3. **连续性保证**：λ=0比特级恢复为FastKV，保证可消融性；安全与效用之间存在连续平滑的权衡。
4. **非单调反转现象**：λ≥100时安全反而下降（ASR=0.78 at λ=300），源于过度惩罚破坏了提示内容骨架（模板模式回归）。
5. **锚有效性**：在ℓ*=15键投影空间构建的锚可实现AUROC 0.996，证明拒绝方向在键空间同样存在且可恢复。

## 7. 优点

- **即插即用设计**：直接修改FastKV的TSP评分规则，无需重训练，离线锚构建一次后在线无额外模型前向传播。
- **信号正交**：安全信号基于键空间几何而非注意力排名，避免了基于注意力的防御可能被自适应攻击者操纵的弱点。
- **可消融性**：软惩罚强度λ连续且λ=0完全退化为基线，便于科学对照和与现有压缩器集成。
- **机制探究**：识别出“拒绝证据稀释”和“模板模式回归”两种具体失效模式，并揭示了安全压力非单调反转现象，为未来安全感知压缩研究提供重要谨慎教训。
