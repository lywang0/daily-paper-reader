## 摘要
量化感知训练（QAT）对于极低比特大语言模型（LLMs）至关重要。当前的QAT方法主要基于标量量化（SQ），虽然能实现高效优化，但在2比特精度下性能严重下降。另一方面，向量量化（VQ）提供了更高的表示能力，但其离散码本查找阻碍了端到端训练。我们提出LC-QAT，一个2比特仅权重的VQ-QAT框架，通过离散向量上的学习仿射映射表示量化权重，产生高质量的PTQ初始化，并在训练前向过程中无需显式码本查找即可实现完全可微的端到端优化。这种强大的训练后初始化使LC-QAT具有极高的数据效率。在多种LLM上的实验表明，LC-QAT在使用仅0.1%至10%训练数据的情况下，始终优于最先进的QAT方法。我们的结果将LC-QAT确立为极端低比特模型部署的实用且可扩展的解决方案。

## Abstract
Quantization-aware training (QAT) is essential for extremely low-bit large language models (LLMs). Current QAT methods are mainly based on scalar quantization (SQ), which enables efficient optimization but suffers from severe performance degradation at 2-bit precision. On the other hand, vector quantization (VQ) provides substantially higher representational capacity, but its discrete codebook lookup prevents end-to-end training. We propose LC-QAT, a 2-bit weight-only VQ-QAT framework that represents quantized weights via a learned affine mapping over discrete vectors, which yields a high-quality PTQ initialization and enables fully differentiable end-to-end optimization without explicit codebook lookup in the training forward pass. This strong post-training initialization makes LC-QAT highly data-efficient. Experiments across diverse LLMs demonstrate that LC-QAT consistently outperforms state-of-the-art QAT methods while using only 0.1%--10% of the training data. Our results establish LC-QAT as a practical and scalable solution for extreme low-bit model deployment.

## 1. 核心问题与整体含义（研究动机与背景）
- **问题**：在 2 比特（超低比特）量化大语言模型时，现有量化感知训练（QAT）主要基于标量量化（SQ），但 SQ 在 2-bit 下表示能力严重不足，导致性能急剧下降。向量量化（VQ）具有更强的表示能力，但其离散码本查找操作导致无法进行端到端梯度反向传播。
- **整体目标**：提出一种既能保留 VQ 高表示能力、又能支持全可微端到端训练的 QAT 框架，实现低比特下模型精度的大幅提升，同时大幅降低对训练数据量的依赖。

## 2. 方法论：核心思想与关键技术细节
- **核心思想**：将传统 VQ 中的非结构化码本替换为**线性约束码本**（Linear-Constrained Codebook）。每个码字由离散四进制向量 `z ∈ {0,1,2,3}^d` 经过共享的线性仿射映射 `c = A z + B` 生成，其中 `A∈R^{d×d}, B∈R^d` 为可学习参数。
- **关键技术细节**：
  - **前向传播**：不再执行耗时的最近邻搜索与码本查找，而是通过简单的取整（round）和裁剪（clip）获得整数索引 `W_z`，然后通过线性投影直接解码得到量化权重 `Ŵ`。前向计算可重新组织为 `Ŵ` 的矩阵乘形式，复用标量量化中的 Int2×FP16 高效内核。
  - **可微梯度估计**：取整操作的导数几乎处处为零，因此采用可微梯度估计器（DGE，式 (9)-(10)）代替常用的直通估计器（STE），避免训练初期损失尖峰，保证稳定收敛。
  - **初始化策略**：使用 LDLQ 算法结合 Hadamard 变换获得高质量的 PTQ 初始点，并通过对整数权重进行仿射变换（Xavier 风格）初始化代理权重 `W_p`，以保证训练稳定性。
  - **整体流程**：维护浮点代理权重 `W_p` → 离散化为整数权重 `W_z` → 通过线性约束码本解码得到量化权重 `Ŵ` → 计算损失 → 通过 DGE 反向传播更新 `W_p`（及 `A, B`）。

## 6. 主要结论与发现
- LC-QAT 在 **2-bit VQ-QAT** 上显著优于现有 VQ-QAT 方法（PV-Tuning），并且在使用 **仅 0.1%–10%** 训练数据的情况下超越了当前最先进的 SQ-QAT 方法（ParetoQ）。

- LC-QAT 在更大模型（14B）和更大数据量（10B tokens）上仍能持续提升，展现良好可扩展性。

## 7. 优点
- **创新性**：首次将 VQ 的离散码本查找转变为线性仿射映射，实现真正的端到端可微 VQ-QAT，避免复杂的坐标下降/束搜索。
- **数据效率**：极低数据量（4B tokens）即取得优于 30B tokens 训练的 ParetoQ 的结果，大幅降低训练成本。

- **稳定性**：DGE 和预处理有效避免了训练早期损失振荡，确保收敛。
