## 摘要
随着大语言模型（LLM）服务输入长度的持续增长，KV缓存已成为AI基础设施中的主要瓶颈。它限制了GPU内存容量、服务并发性、缓存重用和分布式可扩展性。几个重要问题，包括位置无关的KV缓存、前缀KV缓存压缩、热/冷KV缓存分离以及分布式KV缓存管理，都依赖于KV缓存的表示和管理方式。然而，现有的服务系统大多依赖单一的KV缓存抽象，将KV缓存视为同质的令牌级内存块序列，并在注意力头和服务场景中使用类似策略进行管理。我们观察到KV缓存的效用在不同KV头之间高度结构化：不同的头表现出不同的功能角色、注意力距离和运行时重要性。因此，对于每个头、令牌范围或服务场景，完整的KV缓存并非总是必要的。我们提出了RedKnot，一种用于LLM服务的头部感知型KV缓存管理系统。RedKnot通过沿KV头分解KV缓存，打破了传统的单一KV缓存抽象，这些KV头的重要性和有效注意力范围在不同服务场景中变化显著。这种头部级分解将KV缓存从单一的张量抽象转变为结构化的内存对象，使RedKnot能够统一支持位置无关的KV重用、前缀KV压缩、热/冷KV分离和分布式KV放置，同时保持输出保真度并提高资源效率，且无需模型重新训练或微调。RedKnot通过将KV缓存从单一的被动运行时工件转变为动态的、模型感知的运行时基础，为AI基础设施建立了新的基础，以实现可扩展的LLM服务。

## Abstract
As the input length of large language model (LLM) serving continues to grow, the KV cache has become a dominant bottleneck in AI infrastructure. It limits GPU memory capacity, serving concurrency, cache reuse, and distributed scalability. Several important problems, including position-independent KV cache, prefix KV cache compression, hot/cold KV cache separation, and distributed KV cache management, all depend on how the KV cache is represented and managed. However, existing serving systems largely rely on a monolithic KV cache abstraction, where the KV cache is treated as a homogeneous sequence of token-level memory blocks and managed with similar policies across attention heads and serving scenarios. We observe that KV cache utility is highly structured across KV heads: different heads exhibit different functional roles, attention distances, and runtime importance. Therefore, a full KV cache is not always necessary for every head, token range, or serving scenario.   We present RedKnot, a head-aware KV cache management system for LLM serving. RedKnot breaks the conventional monolithic KV cache abstraction by decomposing the KV cache along KV heads, whose importance and effective attention ranges vary significantly across serving scenarios. This head-level decomposition turns the KV cache from a monolithic tensor abstraction into a structured memory object, enabling RedKnot to uniformly support position-independent KV reuse, prefix KV compression, hot/cold KV separation, and distributed KV placement while preserving output fidelity and improving resource efficiency, without requiring model retraining or fine-tuning. RedKnot establishes a new foundation for AI infrastructure by transforming the KV cache from a monolithic, passive runtime artifact into a dynamic, model-aware runtime substrate for scalable LLM serving.

# RedKnot 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）服务中，输入长度不断增长，KV 缓存成为 GPU 内存、服务并发性、缓存重用和分布式扩展的主要瓶颈。现有系统将 KV 缓存视为同质的令牌级内存块序列，在注意力头和服务场景中使用单一策略管理，忽视了 KV 头之间的结构化差异（功能角色、注意力距离、运行时重要性不同）。
- **整体含义**：RedKnot 提出头部感知的 KV 缓存管理，将 KV 缓存沿头部维度分解，转变为结构化的内存对象，从而统一支持位置无关的 KV 重用、前缀压缩、热/冷分离和分布式放置，无需模型重训练或微调，旨在实现可扩展的 LLM 服务基础架构。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将 KV 缓存从 “单一张量抽象” 转变为 “按头部分解的结构化内存对象”，利用不同头部（global vs local）的稀疏模式，分别管理注意力和前馈网络（FFN）计算。

### 关键技术细节
1. **头部级稀疏化（Head-Class Sparsification）**：
   - 离线分类：通过离线 profiling 将每个 (layer, head) 标记为 **global（全局头）** 或 **local（局部头）**。global 头（约 12–15%）需要全上下文访问；local 头（约 85–88%）只需滑动窗口（如 256 令牌）和 sink 令牌。
   - 运行时恢复：当缓存块被重用（位置无关缓存，PIC）时，仅对 global 头重新计算，local 头直接重用缓存 + 局部窗口修复。

2. **分段分页注意力（SegPagedAttention）**：
   - 按每个 (layer, head) 独立分配分页 KV 存储，而非所有头共享同一张量。
   - 使用融合的变长注意力内核，每个头只保留其实际需要的令牌页（global 头全范围，local 头窗口+ sink），避免构造 `attn_mask`，从而保持 FlashAttention 快速路径，消除 4.9–7.6× 的 mask 惩罚。

3. **稀疏 FFN（Sparse FFN）**：
   - 在注意力恢复后，根据注意力信号估计令牌重要性，只对 top-k 重要令牌执行完整 FFN，其他令牌走残差恒等路径。此优化与上下文长度无关，尤其适合短上下文场景（agent 工作负载，FFN 占主导）。

4. **层感知的弹性恢复（Layer-wise Elastic Recovery）**：
   - 浅层：使用局部注意力恢复 + 全 FFN（保守策略）。
   - 深层：启用 global 头重新计算 + 局部头窗口修复 + 稀疏 FFN。

### 算法流程（文字说明）
- 离线：对每个 (layer, head) 计算头部类别映射表。
- 在线：
  1. 将可重用块的缓存键通过 RoPE 旋转对齐到新位置。
  2. 逐层处理：
     - 对于浅层（`l < L_dense`）：执行局部注意力 + 全 FFN。
     - 对于深层：重新计算 global 头；对 local 头仅在其可视窗口 `W(i) = S_sink ∪ [max(0,i-w), i]` 内修复；合并头部产出；根据注意力信号选择重要令牌执行稀疏 FFN，其余令牌跳过 FFN。

- 构造方式：标准 RAG 布局，问题与 N_seg 个检索段落（包含黄金段落和干扰文档）拼接，黄金段落随机放置。

## 6. 主要结论与发现

1. **RedKnot 在所有配置下均优于令牌级 PIC 基线**：在 6 个 QA 数据集上，TTFT 加速最高达 3.54×，并发会话容量提升 4.7–7.8×，预填充 FLOPs 减少 67–79.5%，同时保持或超越密集基线的精度（EM、F1、token 匹配）。
2. **头部级恢复解决了令牌级方法的“并集膨胀”问题**：令牌级方法因不同头关注不同 token 子集，必须取并集，导致大量重计算；RedKnot 仅重计算 global 头，local 头直接复用。
3. **SegPagedAttention 消除了 mask 惩罚**：将稀疏模式物理化（每个头独立分页），使 FlashAttention 快速路径可用，解码延迟加速 2.5–21.0×，预填充加速 6.3–23.3×（随上下文长度增大而增大）。
4. **稀疏 FFN 是短上下文场景的关键杠杆**：对于 2–8K 令牌，FFN 占预填充时间 57–62%，注意力优化无效；RedKnot 的稀疏 FFN 可独立于注意力减少计算。
5. **三个优化轴（头、存储、通道）基本正交，效果可乘**：头部级稀疏 + 稀疏 FFN + SegPagedAttention 共同带来显著性能提升。

## 7. 优点

1. **新颖的头部级分解思想**：打破传统单一 KV 缓存抽象，将头部视为独立管理单元，通用性高（可支持 PIC、前缀压缩、热/冷分离、分布式放置）。
2. **无模型修改**：不需要重新训练或微调，仅需离线 profiling，易于部署。
3. **端到端系统级优化**：不仅关注算法，还设计了 SegPagedAttention 存储和内核，将算法节省转化为实际硬件加速。
