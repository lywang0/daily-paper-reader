## 摘要
4位量化显著降低了大型语言模型（LLM）的内存占用并加速了推理。然而，其有限的位宽表示难以同时忠实捕获密集的常见值（内点）和罕见的大幅值（外点），导致严重的精度下降。现有的混合精度方法通过将外点保留在高精度来缓解这一问题，但代价是破坏了低比特执行的统一性，引入了精度转换和额外的数据移动，削弱了实际加速效果。我们提出MosaicQuant，一种基于内点-外点分解新原理的统一4位LLM量化范式。MosaicQuant并不提升外点精度，而是将整个权重矩阵量化成一个密集的4位基分量，其中内点被忠实捕获，而外点则不可避免地量化。随后引入一个稀疏的4位残差分量来补偿这些量化误差，选择性地针对误差最关键的权重块，这些块的输出失真已被证明是集中的。然而，仅统一表示是不够的，因为将稀疏残差作为独立核执行仍会破坏统一的低比特推理流水线。为解决这一问题，我们引入ZipperEngine，通过重叠流水线将稀疏块计算融合到密集4位GEMM核中，不仅统一了表示，还将执行统一为一个连贯的低比特推理流水线。在LLaMA3和Qwen3上的大量实验表明，MosaicQuant在保持接近FP16精度的同时，相较于W16A16基线实现了高达1.24倍的加速。

## Abstract
4-bit quantization significantly reduces the memory footprint and accelerates the inference of large language models (LLMs). However, its limited bit-width representation struggles to faithfully capture both dense common values (\emph{inliers}) and rare large-magnitude values (\emph{outliers}), causing substantial accuracy degradation. Existing mixed-precision methods mitigate this by retaining outliers in high precision, but at the cost of breaking the uniformity of low-bit execution, introducing precision conversion and extra data movement that undermine practical speedup. We propose \textbf{MosaicQuant}, a unified 4-bit LLM quantization paradigm built on a novel principle of \emph{inlier--outlier disaggregation}. Rather than elevating outlier precision, MosaicQuant quantizes the full weight matrix into a dense 4-bit base component, where inliers are captured faithfully while outlier are inevitably quantized. A sparse 4-bit residual component is then introduced to compensate for these quantization errors, selectively targeting the most error-critical weight blocks where output distortion is shown to be concentrated. However, a unified representation alone is insufficient, as naïvely executing the sparse residual as a separate kernel still breaks the unified low-bit inference pipeline. To bridge this gap, we introduce \textbf{ZipperEngine}, which fuses sparse block computation into the dense 4-bit GEMM kernel via an overlapped pipeline, unifying not only the representation but also the execution into a single coherent low-bit inference pipeline. Extensive experiments on LLaMA3 and Qwen3 demonstrate that MosaicQuant preserves near-FP16 accuracy while achieving up to $1.24\times$ speedup over the W16A16 baseline.

### 论文总结：MosaicQuant

#### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）的规模持续增长，导致其推理过程面临巨大的内存和计算开销。
- **现存挑战**：4-bit量化是一种有效的模型压缩和加速技术，但其有限的表示能力无法同时准确表示密集的常规值（内点，Inliers）和罕见的大幅值（外点，Outliers），导致严重的精度损失。
- **现有方案局限**：为应对精度损失，常见的混合精度方法（如Atom、ResQ）将外点通道保留在高精度（如8-bit），但这破坏了低比特执行的统一性，引入了额外的精度转换和数据搬运开销，削弱了实际速度提升。
- **论文目标**：提出一种**统一的4-bit量化范式**，在不依赖高精度回退（high-precision fallback）的前提下，既能恢复由外点引起的精度损失，又能保持硬件友好的低比特推理效率。

#### 2. 方法论：核心思想、关键技术细节

- **核心思想：内点-外点分解（Inlier-Outlier Disaggregation）**：将LLM的权重矩阵分解为两部分：
    1.  **密集4-bit基分量 (Dense 4-bit Base Component)**：对整个权重矩阵进行4-bit量化，忠实表达大部分内点，但不可避免地会损坏外点。
    2.  **稀疏4-bit残差分量 (Sparse 4-bit Residual Component)**：仅对量化误差最大、对输出影响最关键的权重块引入另一个4-bit残差来进行补偿。
    - **关键优势**：所有运算均在4-bit空间内完成，保持了统一的低比特执行。

- **关键技术1：基于Hessian的块选择（Δ-Hessian Score）**
    - **动机**：量化误差在权重矩阵中呈**块级（block-level）**集中，而非通道级。通道级的补偿会包含许多低影响的值，而块级补偿更精细高效。另外，权重大小无法反映对输出的实际影响，需要**输出感知（output-aware）**的选择。
    - **方法**：借鉴GPTQ思想，提出 **Δ-Hessian分数（SB）**，它是一个可独立计算的代理指标，用于估计补偿某个特定残差块能带来的输出误差减少量。
        - `SB = [ Σ hj * R^2 - Σ hj * (R - Q(R))^2 ]+`
        - `hj` 是输入激活的对角Hessian估计，用于衡量输入通道的敏感性。
        - `R` 是残差（`W - Q(W)`），`Q(R)` 是量化后的残差。
    - **流程**：只需进行一次校准数据的前向传播，计算所有块的Δ-Hessian分数，然后**选择Top-K个分数最高的块**进行残差补偿。理论证明，在对角Hessian目标下，这种选择是最优的。

- **关键技术2：ZipperEngine（融合执行引擎）**
    - **问题**：即使残差分量也是4-bit的，但要将其作为独立稀疏核执行，会引入额外的内核启动和内存访问开销，抵消加速效果。
    - **方法**：ZipperEngine通过以下方式将稀疏残差计算无缝“缝合”到密集4-bit GEMM内核中：
        1.  **内核融合（Kernel Fusion）**：将量化、布局打包、密集计算、稀疏残差计算和累加归约融合成一个单一的内核，避免了冗余的HBM访问。
        2.  **重叠流水线（Overlapped Pipeline）**：将计算tile进一步细分为子块，通过软件流水线技术，让Tensor Core（执行密集计算）、CUDA Core（执行量化/打包）和HBM（预取稀疏数据）并行工作，隐藏辅助工作的延迟。
