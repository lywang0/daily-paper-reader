## 摘要
大语言模型（LLM）已成为现代 AI 应用的骨干，但给高效推理带来了重大挑战。其自回归生成将执行划分为两个阶段：以大型 GEMM 为主的预填充，以及以小规模 GEMV 为主的解码。现代服务系统还通过连续批处理和预填充-解码解耦引入了复杂性，导致动态工作负载和阶段分离。然而，现有加速器与这些系统级行为仍然匹配不佳，造成 LLM 服务效率低下。在这项工作中，我们提出 DynaCore，一种通过系统-架构协同设计实现高效 LLM 服务的统一架构。我们观察到，脉动阵列所执行的计算瓦片，即其最小高效单元（MEU），横跨 GEMM 的全部三个维度。DynaCore 沿这三个维度重塑 MEU：在空间上，它以非对称方式在阵列宽度和高度之间进行权衡，在保持输入路径不变的同时提高权重传输；在时间上，Split-K 将归约映射到阵列上，通过阵列已有的互连来折叠部分和。为了利用阶段分离，我们进一步提出解耦量化，对预填充应用双边量化，对解码应用仅权重量化，并采用内积混合精度数据通路，使输出位宽与精度无关。随后，运行时调度框架为每个批次选择一个 MEU。使用真实服务轨迹的评估表明，DynaCore 相比量化加速器和可重构加速器显著降低了服务级延迟，分别将 TTFT 提升 3.50 倍和 2.97 倍，将 TPOT 提升 36.55 倍和 8.02 倍。

## Abstract
Large language models (LLMs) have become the backbone of modern AI applications, but pose significant challenges for efficient inference. Their autoregressive generation divides execution into two phases: prefill, dominated by large GEMMs, and decoding, dominated by small GEMVs. Modern serving systems further introduce complexity through continuous batching and prefill-decoding disaggregation, leading to dynamic workloads and phase separation. However, existing accelerators remain poorly aligned with these system-level behaviors, resulting in inefficiencies in LLM serving.   In this work, we present DynaCore, a unified architecture for efficient LLM serving via system-architecture co-design. We observe that the compute tile a systolic array executes, its Minimum Efficient Unit (MEU), spans all three GEMM dimensions. DynaCore reshapes the MEU along all three: spatially it trades array width against height asymmetrically, raising weight delivery while leaving the input path untouched, and temporally Split-K maps the reduction onto the array, folding partial sums through the interconnect the array already has. To exploit phase separation, we further propose disaggregated quantization, applying dual-side quantization to prefill and weight-only quantization to decoding, with an inner-product mixed-precision datapath that keeps output width invariant to precision. A runtime scheduling framework then selects an MEU per batch. Evaluation with real-world serving traces shows that DynaCore substantially reduces service-level latency over quantization and reconfigurable accelerators, improving TTFT by 3.50x and 2.97x and TPOT by 36.55x and 8.02x, respectively.

# DynaCore 论文总结：面向高效 LLM 服务的形状自适应架构与解耦量化

## 1. 核心问题与整体含义

- **研究背景**：LLM 自回归生成分为两个本质不同的阶段——**预填充（prefill）**以大型 GEMM 为主、计算密集、硬件利用率高；**解码（decoding）**以逐 token 的小型 GEMV 为主、内存受限、算力利用率极低（在 S×S 阵列上空间利用率塌缩至 1/S）。
- **系统层复杂性**：现代服务系统引入**连续批处理（CB）**与**预填充-解码解耦（PDD）**，使 GEMM 形状随活跃 token 数动态波动，阶段比例持续变化，静态硬件难以匹配。
- **现有方案的三重错配**：
  - 脉动阵列面向大型 GEMM 优化，无法处理解码的"扁平 GEMM"（M=1）。
  - 量化通常对两阶段采用统一配置（W8A8 或 W4A16），但两阶段分别位于 roofline 的脊点两侧，统一配置必然次优。
  - 现有可重构阵列（Planaria、SARA）仅沿 **m=n 的对角线**做对称分裂，无法达到扁平 GEMM 所需的 m 下降、n 上升的非对称工作点。
- **整体含义**：论文主张 LLM 服务的低效源于**算法-系统-硬件缺乏跨层协同设计**，提出统一架构 **DynaCore**，通过重塑 MEU 三个维度 + 阶段专属量化 + 运行时调度来对齐动态负载。

## 2. 方法论

### 核心思想：MEU 三维重塑
- 引入**最小高效单元（MEU）= m×n×k**：m、n 为空间维度（由阵列组织决定），k 为时间维度（归约深度，取决于操作数传递方式）。
- 利用率公式：`U = [min(M,m)·min(N,n)/(m·n)] · [K/(K+k)]`，全利用需 M≥m、N≥n、K≫k。

### 关键技术一：非对称空间重塑（Splittable Systolic Array）
- 每个 DynaPE 内置 **selector**，选择权重的来源（来自上方 PE 或权重缓冲），仅需改写 S 个控制位即可改变阵列拓扑划分。
- 若断言 g 行，则 **m = S/g，n = gS，m·n = S²**，可在同一 PE 数量下实现 S×S 到 1×S² 的连续配置（32×32 核有 6 种可达形状）。
- **非对称性**：重塑只增加权重流数量（g 组需 g 条权重流），输入路径仍为单条广播流，匹配解码"激活数据少、权重带宽压力大"的特性。

### 关键技术二：时间维 Split-K 映射
- 将阵列沿 K 划分为 t 组，每组产生同一输出瓦片的部分和，**m·n·t = S²，k = t·max(m,n)**。
- **Tick-Tock 归约**：不引入专用加法树，而是复用阵列已有垂直链路——末组作为目标累加器，其余组每周期下移一行（tick），到达对应位置时累加（tock）。归约与排空合为同一阶段，阵列仍在 S 周期内清空。

### 关键技术三：解耦量化（Disaggregated Quantization）
- **预填充用 W8A8**（双面量化，INT8 吞吐翻倍），**解码用 W4A16**（仅权重量化，权重流量降 4×）。
- **内积混合精度数据通路**（对比外积方案）：FP16 乘法用 9 个 4-bit 子乘法器实现 12-bit 乘法器；INT8 模式复用其中 8 个，将 K 相邻的两个操作数打包进 16-bit 输入字。**输出瓦片保持 1×1，PE 仍只有一个累加器、输出 32-bit 结果**，低精度吞吐被导向 K 而非新增输出，与外积方案（输出扩张为 2×2、面积超 2×）形成对比。

### 关键技术四：系统-架构协同调度（三层）
- **系统层（主机 CPU）**：长期调度 PDD 的预填充/解码设备比例；短期调度 CB 决定每轮 batch token 数。
- **编译层**：**金字塔打包**（如 M=11 在 4×4 核上分解为 4×4、4×4、2×8、1×16），逐层取最大可容纳配置，最小化扁平配置占比；在满足 m·n·t=S² 的候选中按**延迟-能耗联合目标** `c = τ·(T_lat + λ·T_eng)` 打分（见 Alg. 1），搜索空间小，运行时退化为表查找。
- **加速器层**：16 个独立可重塑的 32×32 核。

## 7. 优点

- **跨层协同的系统性**：将量化策略、阵列组织、执行调度、系统调度统一到一个框架，而非单点优化。
- **MEU 抽象清晰有力**：用 m×n×k 三维统一解释空间与时间维度的利用率损失，为后续设计提供可分析的语言。
- **非对称重塑的洞见**：识别出"扁平 GEMM 需要 m、n 反向移动"这一关键点，并指出这正是 Planaria/SARA 共形分裂无法达到解码工作点的根本原因。
- **低开销的工程巧思**：selector 仅改写控制位、Split-K 复用已有垂直链路与排空阶段、内积混合精度保持输出位宽不变，三者都避免了新增专用硬件。
- **实验设计有层次**：单设备 → 批大小扫描 → 多设备在线服务 → 消融，且消融采用累加式设计，能暴露组件间的依赖与瓶颈转移。
- **精度与效率的双赢**：解耦量化在精度上接近 W8A8，在效率上获得 W4A16 的带宽优势。
