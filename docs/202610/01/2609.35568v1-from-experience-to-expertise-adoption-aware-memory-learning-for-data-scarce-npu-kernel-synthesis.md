## 摘要
高性能内核是高效加速器执行的基础，但需要专家调优和漫长的人工优化周期。LLM 编码智能体有望实现自动化，然而其 CUDA 知识很难迁移到 NPU 等数据稀缺的领域专用架构（DSA），因为后者的执行模型和内存层次结构与 GPU 存在显著差异。为弥合这一迁移差距，后训练方法可使 LLM 适应 NPU 编程，但依赖稀缺的专家数据和大量训练算力。记忆学习智能体则通过外部记忆进行适应，但其统一的信用分配会将被采纳和未被使用的经验赋予相同的奖励目标，从而可能使后续检索排序产生偏差。此外，当学习到的价值仅用于指导检索时，能够跨算子泛化的高价值经验必须被反复检索，而不是保留在上下文中，从而增加检索开销并削弱跨任务指导。因此，我们提出 SAGE，一种面向 NPU 内核合成的持久自改进智能体。采纳追踪效用估计（ATU）将显式的采纳记录与内核评估结果相结合，以实现采纳感知的信用分配。效用门控巩固（UGC）利用正效用和跨算子的重复采纳，选择可复用规则并将其抽象到有界常驻上下文中。在 NPUKernelBench 上，SAGE 实现了 95.5% 的执行率，而最强的受控基线为 84.1%，且 86.9% 的已求解算子在性能上优于 torch_npu。在 GLM-5.3 上，SAGE 在稀疏 flash attention 上相较 torch_npu 参考实现实现了 43.99 倍加速。这些结果表明，采纳感知的信用分配和选择性巩固使智能体能够跨任务积累并复用硬件特定知识。

## Abstract
High-performance kernels underpin efficient accelerator execution but require expert tuning and lengthy manual optimization cycles. LLM coding agents promise automation, yet their CUDA knowledge transfers poorly to data-scarce domain-specific architectures (DSAs) such as NPUs, whose execution models and memory hierarchies differ substantially from those of GPUs. To address this transfer gap, post-training methods adapt LLMs to NPU programming but depend on scarce expert data and substantial training compute. Memory-learning agents instead adapt through external memory, but their uniform credit assignment gives adopted and unused experiences the same reward target, potentially biasing subsequent retrieval rankings. Moreover, when learned values guide only retrieval, high-value experiences that generalize across operators must be retrieved repeatedly rather than retained in context, thereby increasing retrieval overhead and weakening cross-task guidance. We therefore present SAGE, a persistent self-improving agent for NPU kernel synthesis. Adoption-Traced Utility estimation (ATU) combines explicit adoption records with kernel evaluation outcomes for adoption-aware credit assignment. Utility-Gated Consolidation (UGC) uses positive utility and repeated adoption across operators to select and abstract reusable rules into a bounded resident context. On NPUKernelBench, SAGE achieves a 95.5% execution rate versus 84.1% for the strongest controlled baseline, with 86.9% of solved operators outperforming torch_npu. With GLM-5.3, SAGE achieves a 43.99x speedup over the torch_npu reference on sparse flash attention. These results show that adoption-aware credit assignment and selective consolidation enable agents to accumulate and reuse hardware-specific knowledge across tasks.

  - **记忆学习智能体**：冻结主干、通过外部记忆适应，但存在两个关键缺陷：
    1. **统一信用分配**：被采纳与未被使用的经验获得相同奖励目标，导致未使用经验获得偏高价值估计，可能挤占后续检索中更优经验的位置。

- **整体含义**：提出 SAGE，让冻结 LLM 通过外部记忆演化，从"经验"累积为"专长"，实现数据稀缺 NPU 内核合成的持续自我改进。

## 2. 方法论

### 2.1 问题形式化

- 在有序任务流上建模为非参数持续学习：生成器参数 θ₀ 固定，仅外部记忆 M 随任务演化。
- 任务 τ = (x, g)，x 为算子规格，g ∈ {corr, opt} 分别对应正确性 episode 与优化 episode。
- 第 t 轮：上下文 cₜ = Γ(M, τ, kₜ₋₁, fₜ₋₁)，生成候选内核 kₜ = Gθ₀(...)，评测反馈 fₜ = E(τ, kₜ)。
- episode 结束后记忆更新：M ← Φ(M, ε)。

### 2.2 冷—热分层记忆

- M = (C, H)，Tok(H) ≤ B（固定 token 预算）。
- **冷记忆 C**：保存源经验及其条目级证据与生命周期统计，用于检索。
- **热记忆 H**：保存已巩固的规则，直接进入生成器上下文，**无需检索**。

### 2.3 采纳追踪效用估计（ATU）

- **轨迹锚定的经验收集**：每轮检索集 Rₜ 中，每个条目 m 记录采纳状态 aₘ,ₜ ∈ {1, 0, ⊥}（已采纳 / 未采纳 / 未解决）及理由。通过**轨迹完整性钩子**阻止评测，直到所有条目采纳状态被显式解决。
- **延迟信用分配**：收益可能在最终内核才显现，故在 episode 终止时分配信用。
- **终端分数**：
  - 正确性 episode 且通过 → z = 1；
  - 优化 episode 且 Tbest < Tfirst → z = 1 − Tbest/Tfirst；
  - 其他 → z = −δ（0 < δ < 1 的失败惩罚）。
- **条目级证据**：
  - 已采纳条目：ξₘ = z / |A|（被采纳集合共享固定信用预算，防止信用膨胀）；
  - 检索但未采纳：ξₘ = −β（0 < β < 1）。
- **在线效用更新（bandit 式）**：uₘ ← (1 − ηₘ)uₘ + ηₘξₘ，步长 ηₘ = max(1/(1+n_ret), η_min)，随证据累积稳定，η_min 防止历史证据永久主导。
- **效用感知检索**：先用混合稀疏—稠密检索器获取候选池，仅在后期重排序引入效用：s(m) = s_rel(m)(1 + γuₘ)，γ 控制调制强度；热记忆中的常驻知识绕过检索。

### 2.4 效用门控巩固（UGC）

- **证据门控准入**：冷记忆条目满足 uₘ > 0、n_ado ≥ K_ado、|Oₘ| ≥ K_op（跨算子采纳数）方可从 normal → validated，并抽象为简洁可迁移规则（可含最小代码/API 示例），保留源标识符；源经验保留溯源但退出主动检索。
- **预算化热记忆选择**：按单位常驻 token 的期望效用排序 U(m) = uₘ·p̂ₘ / Lₘ，其中 p̂ₘ 为经验访问频率估计，Lₘ 为常驻 token 成本；在 Tok(H) ≤ B 下贪心选择（跳过放不下的大项，允许更小的低排名项入选）。
- **使用衰减与降级**：常驻条目访问频率按 EMA 更新 p̂ₘ ← (1 − μ)p̂ₘ + μ·1{被使用}；持续未使用则 U(m) 下降，可能被降级回 validated，源经验重新获得检索资格。实现**冷—热双向演化**，而非单调上下文增长。

### 2.5 理论性质（附录 E）

- **有界归一化采纳信用**：ξₘ ∈ [−q, 1]（q = max{δ, β}），且 Σ_{m∈A} ξₘ = z，总信用等于终端分数，与采纳数量无关。
- **稳定但持续自适应的效用**：uₘ 始终保持在 [−q, 1] 凸区间内；旧证据按 (1 − η_min)^h 几何遗忘，η_min = 0.05 时半衰期约 13.5 次更新。
- **受控效用重排序**：调制因子 1 + γuₘ ∈ [1 − γq, 1 + γ] 严格为正；当 s_rel(m₁)/s_rel(m₂) > (1+γ)/(1−γq) ≈ 1.38 时，相关性排序不被效用反转——效用只能重排语义相近的候选，负证据被保守对待。
- **常驻优先级随持续未使用衰减**：未使用 h 次后 p̂ 与 U 按 (1 − μ)^h 衰减；μ = 0.1 时半衰期约 6.6 次更新；持续有用的候选最终必然超过任何长期未使用的常驻条目（有限时间超越）。

- **公平性**：所有记忆方法共享相同初始记忆状态、主干、框架、提示、诊断工具、交互预算与评测器，仅记忆机制不同；评测按顺序学习流进行，每个任务结果在记忆更新前记录，避免信息泄漏。
- **客观性**：使用中位数 Sself 与 Fast 1.0 而非算术平均加速，规避长尾分布误导；报告 CR/ER 双指标。
- **潜在不足**：所有实验由作者自行构建的受控基线完成，论文明确指出因基准差异与实现/知识库获取限制，**未与已有 SOTA 系统做直接系统级对比**，外部可比性受限。

## 6. 主要结论与发现

- **主结果（GLM-5.2）**：SAGE 在 88 算子中解出 84 个，ER 达 95.5%（最强受控基线 Value Memory 为 84.1%），CR 98.9%；Fast 1.0 从 75.7% 提升至 86.9

%-1.2 个百分点）；Sself 从 1.44 提升至 1.75，即在已解算子上，迭代精化带来的最佳/首次性能比中位数提高了约 21.5%。CR 98.9% 说明 SAGE 几乎不产生无法编译的内核，ER 95.5% 意味着绝大多数算子能获得功能正确的实现。

- **跨主干一致性**：在 Qwen3-Coder-Next 80B 与 DeepSeek-V4-Flash 284B 上，SAGE 相对各自最强基线的 ER 与 Fast 1.0 均有一致提升，表明增益来源于记忆机制而非特定模型的规模或先验知识。这一结论对"冻结主干 + 外部记忆"路线的通用性具有支撑作用。

- **xCCL 迁移**：在 16 个更复杂的 xCCL 算子（融合注意力、归一化、缓存管理、GMM 类）上，SAGE 在 GLM-5.2 与 GLM-5.3 上均保持优势，说明已巩固的热记忆规则与新积累的采纳证据能够泛化到原始训练分布之外的新算子库，而非仅记忆特定算子的解法。

- **任务顺序消融**：在 L3 Only / L2+L3 Mixed / L2→L3 三种调度下，SAGE 在 L2→L3 的渐进式课程中表现最佳，暗示"先积累较易任务的可迁移经验、再应对高难目标"更利于冷—热记忆的巩固与复用；而 L3 Only 因缺乏可复用中间经验，收敛更慢。

- **机制消融**：完整 SAGE > w/o UGC ≈ Random UGC > Uniform Credit。其中 Uniform Credit 的下降幅度最大，直接印证了论文核心论点——**统一信用分配会让未被采纳的经验获得过高价值估计，污染检索排序**；w/o UGC 与 Random UGC 的次优表现则说明效用门控的**准入条件与预算化选择**共同起作用，随机巩固会挤占热记忆预算并稀释常驻知识质量。

- **固定记忆库控制**：在冻结同一最终记忆库、仅切换 relevance-only / uniform credit / ATU 三种排序信号的条件下，ATU 排序仍显著优于前两者。这一结果把信用分配质量从"记忆累积量"的混淆中剥离出来，是全文最有力的因果性证据之一。

- **跨主干记忆迁移**：以 GLM-5.2 为记忆供体，DeepSeek 与 Qwen 在 GLM Transfer 条件下优于 Initial 与 Native 条件，说明巩固后的规则具有**模型无关的可迁移性**，可作为轻量"专长包"在不同主干间共享，降低每个新主干重新积累经验的成本。

- **专家审计**：随机抽样的 50 条"已采纳"记录中，88% 被 Ascend C 专家评为 full（真实指导了诊断或代码修改）、12% 为 partial、0% 为 unrelated。这为"采纳状态"作为代码修改代理的有效性提供了人工验证，排除了智能体自报采纳的严重虚高。

- **理论结论与实验一致**：有界归一化信用保证总信用守恒，避免采纳条目越多、单条信用被稀释或膨胀；受控效用重排序保证效用只在语义相近的候选间调整次序，防止低相关但高历史效用的条目抢占检索位；常驻优先级衰减保证热记忆不会因"历史功劳"而永久占据预算，实现冷—热双向演化。

## 7. 局限性

- **缺乏与外部 SOTA 的系统级对比**：受基准差异、实现可用性与知识库获取限制，论文仅与自建受控基线（Refinement、Static RAG、Value Memory）比较，未与 EvoKernel 等已发表的记忆学习系统或其他 NPU 代码生成方案做端到端对标，外部可比性受限。
- **算力成本未量化**：未报告训练/评测总时长、NPU 卡时、单次实验挂钟时间与记忆演化消耗的推理 token 总量，难以评估方法相对后训练路线的实际成本优势。
- **主实验为覆盖导向子集**：88 个算子虽覆盖 16 个类别，但并非 NPUKernelBench 全集，对极端长尾或超大规模算子的表现尚不明确。
- **采纳标注依赖智能体自报 + 事后审计**：虽有专家审计背书，但审计仅抽样 50 条，且采纳判定仍由智能体在轨迹完整性钩子下显式声明，可能存在系统性偏差（如将间接影响误标为未采纳）。
- **超参数敏感性与稳定性**：η_min、δ、β、γ、K_ado、K_op、μ、B 等多个超参数共同决定效用动态，论文提供了超参数表但未系统报告敏感性分析，跨域迁移时是否需要重新调参尚不清楚。
- **理论性质为保守界**：有界性、几何遗忘、受控重排序等结论提供的是安全性与稳定性保证，未刻画收敛速率或最优性，对"记忆何时达到足够专长"缺少定量刻画。

## 8. 更广泛的意义与启示

- **范式层面**：论文把"从经验到专长"这一认知隐喻落为可操作的工程机制——**采纳是经验升华为专长的判据，跨算子重复采纳是可迁移性的证据**。这为数据稀缺领域的持续学习提供了不同于后训练的第三条路径：冻结主干 + 外部记忆演化。
- **方法论层面**：ATU 与 UGC 的组合可视为"带使用证据的 bandit 式知识管理"，其思路（延迟信用、条目级证据、预算化常驻、使用衰减）并不绑定 NPU，理论上可迁移到编译器优化、EDA、数据库调优、机器人技能库等同样"公开数据稀缺、反馈延迟、跨任务可复用"的场景。
- **工程层面**：冷—热分层与预算化热记忆给出了在固定上下文窗口下管理长期知识的实用方案，避免"上下文无限增长"或"每次都要检索"的两难；常驻规则的降级机制则回应了持续学习中的灾难性遗忘与陈旧知识污染问题。
- **评测层面**：论文对"防作弊约束"、中位数 Sself、固定记忆库控制、专家审计等设计的强调，为智能体式代码生成的可信评测提供了可借鉴的规范，尤其是"先记录结果再更新记忆"的顺序学习流设置。
- **待验证问题**：采纳证据能否在更强主干上仍然带来边际收益？记忆能否跨架构（如 GPU→NPU、NPU→其他 DSA）迁移？巩固出的规则是否可读、可审计、可被人类专家直接复用？这些是论文结论自然引出的后续方向。
