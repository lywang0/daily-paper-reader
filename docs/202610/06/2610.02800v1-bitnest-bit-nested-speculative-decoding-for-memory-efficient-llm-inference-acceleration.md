## 摘要
投机解码通过使用轻量级草稿提出多个 token 以进行并行验证，从而加速自回归生成。然而，现有方法通常需要额外的草稿模型或权重表示，在资源受限设备上引入不可忽略的内存开销。自投机方法降低了这种开销，但仍面临草稿质量、目标质量和存储效率之间的权衡。我们提出 BitNest，一种比特嵌套投机解码框架，将低精度草稿直接嵌入到高精度目标表示中。BitNest 并非从预定义目标中导出草稿，而是先构建一个强低精度基座，再通过残差细化恢复高精度目标，使两个模型共享单一物理权重表示。BitNest 进一步将这种渐进式精度设计扩展到 KV 缓存，以支持长上下文推理。在多个 7B--8B 边缘友好的 LLM 和多样化工作负载上，BitNest 实现了 95.2% 的平均投机接受率，同时很好地保持高精度模型的质量，并相较于 FP16 自回归解码实现了 1.48--1.61 倍的端到端加速。在所有代表性自投机基线均支持的 LLaMA 模型上，BitNest 也持续实现具有竞争力或更高的解码加速比。

## Abstract
Speculative decoding accelerates autoregressive generation by using a lightweight draft to propose multiple tokens for parallel verification. However, existing methods often require an additional draft model or weight representation, introducing non-negligible memory overhead on resource-constrained devices. Self-speculative approaches reduce this overhead, yet still face trade-offs between draft quality, target quality, and storage efficiency. We propose BitNest, a bit-nested speculative decoding framework that embeds a low-precision draft directly into the higher-precision target representation. Instead of deriving a draft from a predefined target, BitNest first constructs a strong low-precision base and then recovers the higher-precision target through residual refinement, enabling both models to share a single physical weight representation. BitNest further extends this progressive-precision design to the KV cache for long-context inference. Across multiple 7B--8B edge-friendly LLMs and diverse workloads, BitNest achieves an average speculative acceptance rate of 95.2% while closely preserving higher-precision model quality, and delivers 1.48--1.61x end-to-end speedup over FP16 autoregressive decoding. On the LLaMA models supported by all representative self-speculative baselines, BitNest also achieves consistently competitive or higher decoding speedup.

## 2. 方法论

### 2.1 核心思想

- **比特嵌套投机解码**：低精度草稿不是独立模型，而是高精度目标权重表示的一个子集。
- 先构造强低精度基座，再通过残差精修恢复高精度目标；草稿只读基座，目标读基座+精修。
- 默认实例化：**W4 基座用于草稿，W8 目标用于验证**；KV 缓存同样扩展为 KV4/KV8 嵌套。

### 2.2 权重构建流程

- 先做函数保持的旋转变换：`W' = Fuse(W; R1, R2)`，用于抑制异常值，便于低比特量化。
- 用 GPTQ、group size 128 构造 W4 基座：`(q4, s4) = Quantize4,g=128(W')`，草稿权重为 `Wdraft = q4 s4`。
- 固定 W4 基座，计算残差：`ΔW = W' - Wdraft`。
- 精修尺度：`sref = s4 / 16`。
- 4-bit 残差码：对 `ΔW / sref` 取整并裁剪；当 `q4 = -8` 时做非对称约束，防止组合整数越过 signed 8-bit 下界。
- 目标权重重建：`Wtarget = q4 s4 + qr sref = (16q4 + qr) sref`。
- 关键点：**不修改已优化的 W4 草稿**，使 W4 草稿成为 W8 目标的精确子集。

### 2.3 双平面权重存储

- 现代内存按字节寻址，单个 4-bit nibble 不能独立寻址。若 base 与 refinement 交错存放，草稿仍会读取精修位，失去低精度访存优势。
- BitNest 将 base 和 refinement 分别打包为两个独立 bit plane。
- 对 N 个权重，base plane 和 refinement plane 各占 `N/2` 字节。
- 草稿只访问 base plane，即 4 bits/weight 权重码流量；验证访问两个 plane，恢复 W8 目标。
- 精修不需要额外 scale 元数据，因为 `sref = s4 / 16` 可由 base scale 推导。

### 2.4 KV 缓存嵌套

- 将渐进精度思想扩展到 KV 缓存：草稿读 KV4 base，验证读 KV4+refinement 恢复 KV8。
- 在线 per-token、per-KV-head 对称 RTN 量化：
  - `s = max_i |x_i| / 7`
  - `q4 = clip(round(x / s), -8, 7)`
  - 草稿表示：`x_draft = q4 s`
  - 残差：`qr = clip(round((x - q4 s) / (s/16)), -8, 7)`
  - 目标表示：`x_target = (16q4 + qr) s / 16`
- 草稿阶段仅读 KV4 历史缓存；验证阶段读两平面恢复 KV8。
- 候选 token 的 KV 临时生成，验证时重算；接受项保留，拒绝后缀丢弃。
- 短上下文用 KV8 草稿+KV8 验证；长上下文用 KV4 草稿+KV8 验证。还支持 Recent-N 策略，最近 N 个 KV 保持高精度草稿视图。

### 2.5 实现

- 使用自定义 Triton kernel 实现 dual-plane GEMM 和 flash decoding。
- 激活使用 per-token INT8 量化。
- 权重采用 SpinQuant 旋转 + GPTQ W4 基座 + 闭式 signed 4-bit 残差精修。
