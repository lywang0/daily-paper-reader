## Abstract 

Analog in-memory computing is a promising platform for on-device execution of large language models because it performs matrix–vector multiplications (MVMs) in memory and in parallel, reducing data movement. However, limited digital-to-analog converter precision, input noise, and finite conductance states can degrade model accuracy, while full-model retraining to address these effects can be costly. We develop an optimizer-agnostic, parameter-efficient adaptation method based on Low-Rank Adaptation (LoRA), keeping the pretrained weights stored on analog arrays fixed while training the LoRA weights to adapt to downstream tasks and hardware non-idealities. Reliable adaptation requires handling errors in both for-ward and backward MVMs and physical weight updates. We use input reshaping to reduce input-induced MVM errors and update accumulation to retain small updates before programming them to finite-state analog devices. Across Llama-3.2-1B-Instruct and Llama-3-8B with both Muon and AdamW, input reshaping improves analog LoRA fine-tuning under noisy MVM computation. Update accumulation separately preserves sub-threshold updates and substantially improves adaptation under finite-resolution programming, including configurations with as few as 20 conductance states. Additional experiments show consistent held-out negative log-likelihood improvements across noisy analog settings. 

## 1 Introduction 

Large language models (LLMs) rely heavily on matrix–vector multiplications (MVMs) in their linear layers [1, 2]. Analog in-memory computing (AIMC) [3, 4] is an attractive hardware platform for these operations because weights can be stored directly in memory and MVMs can be performed in place and in parallel [5–7]. This reduces data movement and can improve energy efficiency and latency [8, 7, 9], making AIMC a promising candidate for on-device intelligence. However, deploying pretrained LLMs on analog hardware can degrade model accuracy because limited digital-to-analog converter (DAC) precision, input noise, and finite conductance states intro-duce errors into the model’s computation. Hardware-aware retraining can mitigate this degradation by accounting for analog non-idealities during training [9–11]. However, retraining the full model requires gradients and optimizer states for all trainable weights, as well as computation to update those weights. Repeating this process for downstream tasks can therefore incur substantial training-memory and computation costs. These costs motivate parameter-efficient fine-tuning (PEFT) for on-device analog adaptation [12]. We consider Low-Rank Adaptation (LoRA) [13, 14] to adapt the model to downstream tasks and compensate for hardware-induced degradation while keeping the pretrained weights fixed. In our setting, the deployed pretrained weights and the corresponding LoRA weights are executed on analog arrays, with digital support for input reshaping and update accumulation. Our input reshaping treats the fixed pretrained weights and trainable LoRA weights differently. For the pretrained weights, function-preserving base-path rescaling jointly rescales the weights and their inputs to reduce the input range without changing the ideal computation [16]. For the LoRA weights, we route persistent input-outlier channels through a protected perfect-I/O analog path, so that their large values no longer set the quantization scale for the remaining analog inputs. Figure 1 summarizes the method. Our contributions are threefold. First, we develop a lightweight adaptation method for LLMs on analog hardware, motivated by the needs of on-device intelligence. The method keeps pretrained weights fixed and trains only a small set of LoRA weights to address hardware-induced degradation. Second, we address noisy MVM computation through input reshaping and limited weight-update resolution through mixed-precision update stabilization using digital mini-batch aggregation and update accumulation. Third, we evaluate the optimizer-agnostic design in simulation on Llama-3.2-1B-Instruct and Llama-3-8B using Muon [17, 18] and AdamW [19]. Input reshaping remains effective with both optimizers under noisy MVM computation, while its gains largely disappear when MVM input perturbations are removed. Update accumulation separately improves adaptation under finite-resolution weight programming. Additional model and task results show consistent held-out negative log-likelihood improvements under noisy analog settings. 

## 2 Related Work 

Parameter-efficient fine-tuning. Parameter-efficient fine-tuning methods include Adapter Tuning [20], Prefix Tuning [21], Prompt Tuning [22], LoRA [13], QLoRA [23], AdaLoRA [24], and DoRA [25]. Recent work further revisits LoRA architectures, optimization, and deployment considerations from a signal-processing perspective [26]. For analog hardware adaptation, prior work keeps the pretrained weights fixed on AIMC tiles while performing the LoRA computation on separate digital processors [14]. Its deployment therefore requires a dedicated digital LoRA execution path whose latency must be balanced with the AIMC tiles. We instead place the main LoRA computation and weight updates on analog arrays. This removes the need to rely on a fully digital LoRA computation path, but makes the trainable LoRA weights themselves subject to noisy MVMs and non-ideal programming, which motivates the robustness techniques studied in this work. 

Analog training and low-precision computation. Analog in-memory training is affected by noisy MVMs, finite conductance states [27], peripheral quantization, and non-ideal programming 2responses [28–30]. Hardware-aware training and simulation frameworks model these effects during training [9–11], while mixed-precision computational-memory training uses high-precision digital accumulation to improve weight updates on low-precision analog devices [7]. Recent work further co-designs weight mapping and optimization to improve the scalability of analog training under hardware non-idealities [31]. Complementary work on low-precision transformers addresses large activation ranges and persistent outliers through activation–weight rescaling [16], outlier suppression [32], and activation-aware quantization [33]. Noise-optimized rescaling (NoRA) further applies activation–weight rescaling to analog inference to reduce input-side non-idealities [34]. 

## 3 Analog LoRA Fine-Tuning under Hardware Non-Idealities 

This section presents our analog LoRA fine-tuning method under non-ideal MVM computation and physical weight programming. We first define the analog LoRA computation and the hardware-noise model used during training. We then introduce input reshaping to reduce DAC-side MVM perturbations, followed by digital mini-batch aggregation and update accumulation to stabilize finite-state programming of the trainable LoRA weights. 

3.1 Analog LoRA and non-ideal MVMs 

We start from a pretrained transformer and map part of the pretrained weights and the corresponding trainable LoRA weights to analog arrays. For a layer with input dimension n and output dimension m,the pretrained base weights Wbase ∈ Rm×n are programmed once and kept fixed, while the LoRA matrices A ∈ Rr×n and B ∈ Rm×r are updated during fine-tuning. Both the pretrained and LoRA weights are used in non-ideal analog forward and backward MVMs. Because the LoRA weights are trainable, they are additionally subject to finite-state and non-ideal physical programming when updates are written to the arrays. For input x ∈ Rn, the ideal output y ∈ Rm is 

y = Wbase x + αr BAx , (1) where r is the LoRA rank and α is the LoRA scaling factor. Our input reshaping is motivated by the persistent activation outliers observed in pretrained trans-formers [16, 33]. We use absolute-maximum input scaling, which normalizes each MVM input by its maximum absolute value ∥x∥∞ so that the largest input magnitude determines the DAC range. As a result, a few persistent outlier channels can repeatedly enlarge the quantization step for all remaining channels. We therefore reshape the MVM inputs to reduce this dynamic range while preserving the intended computation. 3.3 Update-path stabilization for analog LoRA 

The trainable LoRA weights are also affected by non-ideal physical programming. Finite conductance resolution limits how small an update can be programmed to the analog LoRA weights. We use digital mini-batch aggregation and update accumulation [7]. Gradients are aggregated digitally before the optimizer computes the weight update, and the same update accumulation procedure is then applied to the resulting update regardless of the optimizer choice. Updates smaller than the conductance step are retained until they can be programmed. Let t denote an optimizer step and Θt ∈ { At, Bt} denote either trainable LoRA weight matrix. The QA experiments address two complementary questions. The first two result columns in Table 1 evaluate input reshaping. Under noisy MVM computation, reshaping improves F1 and EM for both models and both optimizers, while its effect is small under perfect I/O, where the targeted input-side perturbations are removed. The Llama-3.2-1B-Instruct results further show that the benefit persists when analog mapping is extended to all 16 decoder blocks. The last two result columns in Table 1 isolate update accumulation while keeping reshaping enabled. Discarding the programming residual substantially degrades F1 and EM for both models and op-timizers, demonstrating the importance of retaining sub-threshold updates under finite-resolution programming. Validation NLL in Table 4 shows the same qualitative trends for both input reshaping and update accumulation. The N = 20 stress test in Table 5 further shows that both benefits persist under coarser programming resolution.

Together with the Llama QA results, these results show that input reshaping remains effective across different models, tasks, optimizers, and analog settings.

## 5 Conclusion and Limitations 

We present a parameter-efficient approach for adapting pretrained LLMs to analog hardware without full-model hardware-aware retraining. Input reshaping mitigates input-side MVM errors, while update accumulation preserves sub-threshold updates under finite-resolution programming. Across the primary QA and additional evaluations, these techniques improve analog LoRA fine-tuning under the simulated non-idealities considered. Our study is limited to AIHWKit simulation and selected models and device settings; it does not measure physical-device behavior or end-to-end latency, energy, programming cost, or communication overhead. Some supplementary stress-test and component-ablation results are point estimates. Physical validation, broader device coverage, and system-level evaluation remain future work. 6References

## A Experimental Details 

We use IBM AIHWKit [40, 10] to simulate analog LoRA fine-tuning. Pretrained weights remain frozen, while the LoRA weights in the mapped layers are trainable. DAC precision and input noise are applied to both forward and backward analog MVMs. Digital mini-batch aggregation is performed before the Muon or AdamW optimizer step, followed by the update-accumulation procedure described in Sec. 3.3. Throughout the paper, No reshaping + UA disables input reshaping while retaining update accumulation (UA), Reshaping + UA enables both components, and Reshaping w/o UA enables reshaping but discards the programming residual after each transfer. Perfect-I/O analog controls remove the modeled MVM input perturbations while retaining the analog weight representation and programming procedure. I/O b/s denotes a b-bit input DAC with input-noise standard deviation s.

A.1 Primary Llama QA testbeds 

Both primary testbeds use an equal mixture of NQ-Open, TriviaQA, and WebQuestions. Fine-tuning uses 2,000 optimizer steps, sequence length 256, micro-batch size one, digital aggregation over eight micro-batches, LoRA rank r = 8 , and scaling factor α = 16 . The base learning-rate amplitude is 

10 −4 and decays to zero. Muon uses momentum 0.95, while AdamW uses (β1, β 2) = (0 .9, 0.999) 

and weight decay 0.01. The corresponding Q/K/V/O projections and LoRA weights are mapped to analog arrays, while input reshaping is applied to Q/K/V. Calibration uses 64 pre-fine-tuning batches, 

λ = 0 .8, and the eight channels most frequently attaining the largest absolute token activation. The calibration statistics and selected channels remain fixed during fine-tuning. The primary noisy-I/O setting uses 7-bit input DACs and input-noise standard deviation 0.02. Evaluation uses greedy generation on a fixed 512-question QA set with standard answer normalization and best matching over gold-answer aliases. Validation NLL is computed on 100 held-out examples using response-token negative log-likelihood. 

Llama-3-8B. For the original softmax-attention Llama-3-8B, the Q/K/V/O projections and corre-sponding LoRA weights in the first six decoder blocks are mapped to analog arrays. The primary experiments use N = 100 . For the N = 20 stress test, AdamW uses a fivefold learning-rate multiplier relative to the N = 100 setting. 

Llama-3.2-1B-Instruct. For Llama-3.2-1B-Instruct, Q/K/V/O projections and their corresponding LoRA weights in all 16 decoder blocks are mapped to analog arrays. MLPs, embeddings, normaliza-tion layers, attention softmax, and the language-model head remain digital. The analog device uses 

N = 100 with programming increment ∆wmin = 0 .02 .

A.2 Additional testbeds Llama/OpenOrca. We fine-tune the softmax-attention Llama-3-8B on OpenOrca using an instruction–response format. The last eight decoder blocks’ Q/K/V projections and correspond-ing LoRA weights are mapped to analog arrays. Input reshaping uses λ = 0 .8 and eight calibrated outlier channels. Evaluation reports final response-token NLL. The evaluated analog settings are given in Table 6. 

Recovered linear-attention Llama QA. We additionally evaluate a linear-attention Llama-3-8B checkpoint recovered through LoLCATs [41, 42] on the same three QA datasets. The first six decoder blocks’ Q/K/V/O projections and corresponding LoRA weights are mapped to analog arrays, with reshaping applied to Q/K/V. 10 B Additional Results
