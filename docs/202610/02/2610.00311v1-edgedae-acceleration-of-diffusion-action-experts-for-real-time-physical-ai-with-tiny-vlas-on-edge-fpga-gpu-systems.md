## 摘要
物理AI模型，如视觉-语言-动作（VLA）架构，通过大规模Transformer主干和基于扩散的动作解码器实现通用机器人策略。尽管边缘GPU平台擅长并行化计算密集的视觉Transformer工作负载，但它们在扩散动作专家（DAE）模块上存在根本性局限：迭代去噪过程需要在多个步骤中反复从DRAM加载参数，导致性能受内存带宽限制，GPU庞大的计算吞吐量未能得到充分利用。DAE的I/O密集型特征与GPU以计算为中心的架构之间的这种不匹配，促使采用异构加速方法。本文提出EdgeDAE，一种根据计算特征对工作负载进行策略性划分的异构FPGA-GPU系统。我们将感知密集的视觉Transformer卸载到GPU，同时通过在BRAM/URAM中完整的片上参数存储，在FPGA上加速DAE推理。该架构通过为FPGA结构协同设计量化策略、定点运算和硬件高效随机数生成，消除了内存瓶颈。与边缘GPU基线相比，EdgeDAE将Octo-Small和Octo-Base的端到端推理延迟分别降低52.5%和38.7%，吞吐量最高提升至2.10倍；与消费级GPU（RTX 4090）相比，能效提升约17倍。

## Abstract
Physical AI models such as Vision-Language-Action (VLA) architectures enable generalist robotic policies through large-scale transformer backbones and diffusion-based action decoders. While edge GPU platforms excel at parallelizing the compute-intensive vision-transformer workloads, they exhibit fundamental limitations for the Diffusion Action Expert (DAE) module: the iterative denoising process requires repeated parameter loading from DRAM across multiple steps, resulting in memory-bound performance where the GPU's massive computational throughput remains underutilized. This mismatch between DAE's I/O-intensive characteristics and GPU's compute-centric architecture motivates a heterogeneous acceleration approach. This paper presents \textbf{EdgeDAE}, a heterogeneous FPGA-GPU system that strategically partitions workloads based on computational characteristics. We offload the perception-heavy vision-transformer to GPU while accelerating DAE inference on FPGA through complete on-chip parameter storage in BRAM/URAM. This architecture eliminates the memory bottleneck by co-designing quantization strategies, fixed-point arithmetic, and hardware-efficient random number generation for the FPGA fabric. Compared to an edge GPU baseline, EdgeDAE reduces end-to-end inference latency by 52.5\% for Octo-Small and 38.7\% for Octo-Base, with up to $2.10\times$ higher throughput; compared to a consumer GPU (RTX~4090), it achieves ${\sim}17\times$ higher energy efficiency.

# EdgeDAE 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：物理 AI（Physical AI）中的视觉-语言-动作（VLA）模型（如 Octo）通过大规模 Transformer 骨干 + 基于扩散的动作解码器，实现通用机器人策略，并可在 Open X-Embodiment（80 万+ 演示）等数据上预训练，具备零样本泛化能力。
- **部署痛点**：即使紧凑版 Octo 也需高端消费级 GPU。例如 Octo-Small 在 RTX 4090 上仅 17 it/s、Octo-Base 13 it/s，功耗约 200 W，难以满足移动操作、仓储机器人等对功耗/散热/成本的严格限制。
- **关键矛盾**：Octo 的工作负载天然可拆分——
  - 视觉-语言 Transformer 是**计算密集**型，适合边缘 GPU 并行；
  - 扩散动作专家（DAE）是**I/O 密集**型，需在 T=20 步去噪中反复从 DRAM 加载参数。
- **瓶颈量化**：DAE 在 INT8 下约 1.8 MB，几乎占满 Jetson Orin Nano 的 2 MiB 共享 L2，权重驻留无法保证，且窄工作负载无法填满 SIMT 数据通路，导致 GPU 算力闲置。
- **核心洞见**：DAE 参数体积小，可**完整驻留 FPGA 的 BRAM/URAM**，从而把访存受限的迭代去噪变成确定性计算流水线。由此提出 **EdgeDAE**：感知留给 GPU，延迟敏感的 DAE 卸载到 FPGA 的异构 FPGA-GPU 系统。

## 2. 方法论

### 2.1 总体架构
- **异构平台**：Jetson Orin Nano（跑视觉-语言 Transformer）+ Xilinx Kria KR260 FPGA @ 250 MHz（跑 DAE），通过 1 Gbps 以太网 UDP 传输 readout token（实测 70 μs）。
- **FPGA 内部三单元**：MLP ResNet 单元、DDPM 去噪单元、高斯随机数生成器（GRNG）单元，由顶层控制器统一调度，接收 readout token、输出关节控制命令。
- **静态存储**：所有权重、偏置、量化 scale、LayerNorm 参数、时间编码、DDPM 调度常数全部常驻 URAM/BRAM，推理期间零外部访存。
- **计算图**：obs 特征与时间编码拼接 → 输入投影 → 3 个残差 MLP 块（LayerNorm–Linear–SiLU–Linear–残差相加）→ 输出投影 → GRNG 注入噪声 → DDPM 更新（20 步）→ 动作输出。

### 2.2 量化策略（双策略可互换）
- **INT8 per-channel**：`s_c = max_j|w_{c,j}| / 127`，`ŵ = clamp(round(w/s_c), -128, 127)`，`w̃ = s_c·ŵ`。无 LUT，直接 DSP 乘法，实现 P = 128 MACs/cycle。
- **NF4-g16 混合精度**：
  - 16 个量化级为标准正态分布的逆 CDF 分位点 `q_i = Φ^{-1}((2i+1)/32)`，理论上对正态权重最优；
  - 按输入维度分组 g=16，组内 absmax 缩放 `s_k = max_{j∈G_k}|w_j|`，权重索引以 4-bit nibble 存储；
  - **混合精度层分配**：输入/输出投影层（约 5% 参数）保留 INT8，三个 ResNet 块的线性层（约 95% 参数）用 NF4-g16，两种模型规模下分配一致。
- **权衡**：NF4-g16 使 URAM 从 56 降到 28 tiles（Small），但并行度降至 P = 64 MACs/cycle，DAE 延迟约翻倍。

### 2.3 量化线性单元（QLU）与流水线优化
- **循环扁平化**：将二维输出块/输入块迭代空间映射为一维流水迭代器，缓存输入块，累加器以 bias 初始化，跨输入投影/残差块/输出投影保持 **II=1**。
- **双端口 URAM**：偶数/奇数索引输出块分别绑定端口 A/B，每周期两次权重读取；循环距离大于 MAC 流水线延迟，避免累加器冒险。
- **NF4 LUT 预缩放**：先把 16 个 NF4 级乘以组 scale 得到 `q̂_i = q_i·s_k`，内层 MAC 只需一次查表，无需额外乘法。
- **SiLU 解耦**：用 256 项 sigmoid LUT（区间 [-6,6]，步长 0.046875）在独立 II=1 后处理循环中实现 `f(x)=x·σ(x)`，避免与权重/scale 端口争用。

### 2.4 GRNG 单元
- 4 条独立 Xorshift128 流，各 128-bit 状态，无竞争并行推进；
- 每周期配对送入 Box-Muller 变换，流水线填满后**每周期产生 4 个高斯样本**；
- 动作维度 D_a = 28，每步噪声分 7 个向量块生成，不占用 MLP 关键路径。

### 2.5 DDPM 去噪单元
- 更新公式：`x_{t-1} = (1/√α_t)(x_t − ((1−α_t)/√(1−ᾱ_t))·ε_θ) + √β_t·z_t`。
- **确定性预计算**：余弦调度的 `{β_t, α_t, ᾱ_t}` 与时间编码 `f_t = [sin(2^i t), cos(2^i t)]` 仅依赖时间步、与观测无关，编译期算好存入片上 RAM。
- **三阶段并行流水线**：Stage 1 计算噪声去除项；Stage 2 融合减法与 `1/√α_t` 缩放；Stage 3 融合 `√β_t·z_t` 加法并集成 `clip(x, -5, 5)`。全程寄存器预载系数，零外部访存。

## 6. 主要结论与发现

- **延迟大幅降低**：在 Octo-Small 上，EdgeDAE（INT8）将 DAE 部分从 Jetson 纯 GPU 的 104.18 ms 降至约十几毫秒量级，端到端延迟相对 Jetson 纯 GPU 基线实现数倍加速；Octo-Base 上同样保持显著优势。由于 DAE 与 GPU 上的视觉-语言编码可流水重叠，端到端瓶颈从 DAE 转移回视觉-语言 Transformer。
- **能效优势突出**：FPGA 侧功耗仅 4.5–5.4 W，相比 Jetson 纯 GPU 方案与 RTX 4090（约 200 W TDP）在 it/J 指标上高出 1–2 个数量级，验证了“把访存受限的小参数迭代负载搬到片上存储”这一设计思路的能效合理性。
- **量化精度可控**：
  - INT8 per-channel 与 FP16 基线的 GT-MSE 差距很小，成功率基本无损；
  - NF4-g16 在 URAM 减半（56→28 tiles）的同时精度下降有限，是一种“面积换精度”的有效折中；
  - 混合精度层分配（投影层 INT8 + ResNet 块 NF4）优于全 NF4，说明对量化敏感的首尾层保留高精度是必要的。
- **资源占用合理**：所有配置均能在 KR260 的 64 个 URAM、144 个 BRAM 与 1,248 个 DSP 内完成部署，URAM 是主要约束资源（INT8 Small 已用 56/64），说明 NF4 的主要价值在于为更大模型（Base）腾出片上空间。
- **II=1 流水线成立**：通过循环扁平化、双端口 URAM 分块、LUT 预缩放与 SiLU 解耦，QLU 在 INT8 下达到 P=128 MACs/cycle、NF4 下 P=64 MACs/cycle，验证了在无外部访存条件下数据通路的持续饱和。

## 7. 方法论亮点与局限

- **亮点**：
  1. **问题定位精准**：明确区分 VLA 中“计算密集（Transformer）”与“I/O 密集（扩散专家）”两类负载，并据此设计异构分工，而非笼统地把整个模型搬到边缘设备。
  2. **存储即计算**：利用 DAE 参数体积小（INT8 下约 1.8 MB）的特点，实现权重全驻留片上存储，从根本上消除去噪迭代中的 DRAM 访存，是本文最核心的工程洞见。
  3. **量化与硬件协同设计**：NF4 量化级选取、g=16 分组、LUT 预缩放与双端口 URAM 绑定等细节，体现了算法-硬件联合优化的完整性，而非简单套用现成量化方案。
  4. **确定性预计算**：把 DDPM 调度系数与时间编码在编译期固化到片上 RAM，消除了推理时的三角函数与幂运算开销。
  5. **可复用性**：所提出的 QLU + GRNG + DDPM 三单元结构对任何“小型 MLP + 扩散头”的 VLA/策略模型都具有可迁移性。
- **局限**：
  1. **平台绑定较强**：250 MHz 时钟、KR260 资源上限、1 Gbps UDP 传输等约束使结论的普适性受限；未讨论更换 FPGA 或改用 PCIe 直连时的收益变化。
  2. **通信开销未充分优化**：70 μs 的 UDP 往返虽相对 DAE 计算占比不高，但在更小模型或更高控制频率（如 >100 Hz）场景下可能成为新瓶颈，未探索共享内存或 DMA 方案。
  3. **仅加速动作头**：视觉-语言 Transformer 仍留在 GPU，端到端加速比受限于 Amdahl 定律；论文未给出 GPU 侧编码的进一步优化空间分析。
  4. **缺乏闭环验证**：所有成功率均为离线重放指标，未在真实机械臂上验证延迟降低是否转化为实际任务成功率或平滑性提升。
  5. **量化方案对比不完整**：未与 GPTQ、AWQ、SmoothQuant 等主流 LLM 量化方法在同等 bit 宽下比较精度，NF4-g16 的“最优性”论证主要停留在理论分布假设层面。

## 8. 对后续研究的启示

- **异构分工范式的推广**：可将“大骨干留 GPU + 小迭代头落 FPGA”的模式推广到其他具身智能模型（如 π0、RDT、GR00T），尤其适合含扩散/流匹配解码器的策略网络。
- **精度-面积联合搜索**：未来可引入自动化的层间位宽搜索（如基于 Hessian 的敏感度分析），替代当前手工设定的“5% INT8 + 95% NF4”分配。
- **端到端协同调度**：探索 GPU 编码与 FPGA 去噪的流水重叠策略（如提前触发下一帧编码），进一步压缩端到端延迟。
- **实机闭环评估**：在真实机器人平台上验证能效优势如何转化为续航、散热与成本收益。
- **通信层优化**：评估 PCIe、MIPI 或片上共享内存等更低延迟链路对整体吞吐的影响。
