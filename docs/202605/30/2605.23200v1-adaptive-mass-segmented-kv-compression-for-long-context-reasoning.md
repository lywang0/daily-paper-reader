## 摘要
键值（KV）缓存的线性增长是长文本LLM推理中的关键瓶颈。现有的KV压缩方法通过基于重要性分数驱逐令牌来缓解这一问题。然而，我们表明它们对全局Top-k选择的依赖会触发区域擦除：连续推理块的严重驱逐破坏了逻辑连贯性。为了解决这个问题，我们提出自适应质量分段（AMS）KV压缩，这是一个将范式从令牌级竞争转变为区域感知配额分配的框架。AMS基于注意力质量的空间分布自适应划分KV缓存，确保结构重要的推理段获得有保证的内存配额。为了确保迭代解码过程中的稳定性，引入了基于EMA的平滑机制以防止分段边界抖动。关键在于，AMS是一个通用的即插即用层，与现有的评分器正交。它可以无缝集成到代表性方法中，如TOVA、Expected Attention、KeyDiff、R-KV和TriAttention。AMS还与现代分页KV服务框架（如vLLM）系统兼容，支持高效收集和紧凑的KV执行，而无需引入额外的稳态注意力开销。在包括数学推理（MATH500、AIME、GSM8K）、代码补全、开放域问答和稀疏检索等一系列任务上的大量实验表明，AMS持续缓解结构碎片化并提升模型性能。

## Abstract
The linear growth of the Key-Value (KV) cache is a critical bottleneck in long-form LLM inference. Existing KV compression methods mitigate this by evicting tokens based on importance scores. However, we show that their reliance on global Top-k selection triggers Region Wipe-out: the severe eviction of contiguous reasoning blocks that derails logical coherence. To address this, we propose Adaptive Mass-Segmented (AMS) KV Compression, a framework that shifts the paradigm from token-level competition to region-aware quota allocation. AMS adaptively partitions the KV cache based on the spatial distribution of attention mass, ensuring structurally vital reasoning segments receive guaranteed memory quotas. To ensure stability during iterative decoding, an EMA-based smoothing mechanism is incorporated to prevent jitter in segment boundaries. Crucially, AMS is a universal plug-and-play layer that is orthogonal to existing scorers. It can be seamlessly integrated into representative methods such as TOVA, Expected Attention, KeyDiff, R-KV and TriAttention. AMS is also system-compatible with modern paged-KV serving frameworks such as vLLM, supporting efficient gather-and-compact KV execution without introducing additional steady-state attention overhead. Extensive experiments across a diverse suite of tasks, including mathematical reasoning (MATH500, AIME, GSM8K), code completion, open-domain QA, and sparse retrieval, demonstrate that AMS consistently mitigates structural fragmentation and boosts model performance.

- **核心问题**：长上下文LLM推理中，KV缓存随序列长度线性增长，成为推理瓶颈。现有解码时KV压缩方法（如H₂O、TOVA等）基于全局Top-k选择保留重要token，但该范式会引发**区域擦除（Region Wipe-out）**：连续的推理块（如中间推导步骤）被整体驱逐，破坏逻辑连贯性，导致问题漂移、过早推翻结论、重复崩溃等故障。
- **研究动机**：揭示全局token竞争策略的结构缺陷，提出区域感知的分配范式，在有限KV预算下保护推理轨迹的连续性。

### 2. 方法论

- **核心思想**：从“token级竞争”转向“区域感知配额分配”。在评分前先按注意力质量的空间分布自适应划分KV缓存区域，为每个区域分配保留配额，保证重要推理段不会被完全擦除。
- **关键技术细节**：
    - **头级质量质量分布**：基于最近窗口注意力使用率计算每个位置的质量分数，归一化为非负质量分布 \( m_i \)。
    - **自适应质量分段**：按累积质量阈值将序列切分为段，高注意力密度区域切分更细，低密度区域合并更长；并应用最大/最小长度约束进行分割/合并。
    - **分段配额分配**：每个段先获得最小保证配额 \( q_{\min} \)，剩余预算按段内质量比例分配，并受段长度约束；同时保留固定数量的起始token（sink）和最新token（must-keep）。
    - **段内选择**：使用现有评分器（如TOVA、Expected Attention）在每个段内独立选择Top-k token，最后合并must-keep并调整至目标预算。
    - **EMA平滑稳定性**：维护历史质量信用的指数移动平均（EMA），用于平滑分段边界和配额分配，减少跨压缩事件的抖动。
- **公式与算法流程**（文字说明）：

### 6. 主要结论与发现

- AMS显著优于基于全局Top-k的基线，尤其在低KV预算下（MATH500上AMS-Expected比AdaKV-ExpE2提升最高+16.0点）。
- AMS作为即插即用层可提升多种评分器（TOVA、Expected Attention、TriAttention、KeyDiff、R-KV），且不改变评分器本身。
- AMS有效缓解区域擦除、中段丢失、重复崩溃等问题，提高推理轨迹稳定性和逻辑连续性。
- AMS在内存和延迟上与现有收集型压缩方法相当或更优，且可兼容vLLM分页KV系统。

### 7. 优点

- **创新性**：提出区域意识配额分配范式，替代传统的全局token竞争，直接解决区域擦除问题。
- **通用性**：是评分器无关的分配层，可轻松集成到现有KV压缩方法中，无需修改模型或评分逻辑。
- **稳定性机制**：EMA平滑减轻重复压缩引起的分配抖动。
- **系统兼容性**：支持vLLM分页KV，不引入额外注意力开销，实际延迟与内存表现良好。
- **实验全面**：跨多种任务、骨干、模型规模、预算水平验证，消融实验充分，诊断分析深入。

### 8. 不足与局限

- **依赖性**：质量分布基于注意力使用率，可能不完全反映长程语义效用，未来可探索任务感知或学习型效用信号。
- **实验覆盖**：主要在DeepSeek-R1-Distill-Qwen系列上进行，更多架构（如LLaMA、Mistral）及多轮交互、生产级服务系统尚未充分验证。
- **实际部署效率**：虽然AMS与vLLM兼容，但实际端到端效率仍取决于后端实现、批处理策略和硬件；论文未在真实服务集群上做压测。
- **极少预算下的退化**：虽然AMS在低预算下提升显著，但极端预算（如Tkeep=128）下仍远不及无损Full KV，压缩损失依然存在。
- **社会影响**：降低推理成本可能使长文本生成更易部署，但也可能被用于生成误导性内容，需配合相应安全措施。
